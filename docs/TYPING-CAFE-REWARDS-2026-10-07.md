# 타자친구 · 카페 노트와 활동 보상

## 참고와 디자인

- 아이러브커피 공식 소개: https://game.kakao.com/games/2oQDJ0O1 — 파스텔 빈티지 테마, 카페 꾸미기 흐름을 참고했다.
- Bongo Cat 공식 소개: https://store.steampowered.com/app/3419430/Bongo_Cat/ — 입력 활동에서 꾸미기 보상으로 이어지는 흐름을 참고했다.
- 타자친구는 직접 만든 커피/선물 아이콘, 크림 주문 카드, 세이지 탭, 소장 현황과 완료 가능한 보상 우선 정렬을 사용한다.

## 새 보상

| 매일 주문 | 조건 | 스탬프 |
|---|---|---:|
| 오늘의 첫 주문 | 입력 100회 | 1 |
| 따뜻한 한 잔 | 유효 활동 5분 | 2 |
| 느긋한 작업 시간 | 유효 활동 15분 | 3 |

로컬 날짜가 바뀌면 주문 진행과 당일 수령 내역만 초기화한다. 입력 없는 시간의 활동 계산은 기존 30초 유예 규칙을 따른다. 기존 사용자의 과거 누적 활동을 오늘의 주문으로 소급 지급하지 않는다.

| 영구 소장 테마 | 비용 | 적용 위치 |
|---|---:|---|
| 딸기 우유 불빛 | 3 스탬프 | 펫 아래 입력 반응 네모 |
| 허니 라떼 불빛 | 5 스탬프 | 동일 |
| 라벤더 티 불빛 | 8 스탬프 | 동일 |

스탬프는 수령 버튼으로 적립하고 교환할 때만 차감한다. 소장한 테마 재장착과 기본 세이지로 돌아가기는 무료다. 기존 12개 누적 선물과 별개로 추가된 영구 보상 3개다.

## 저장과 UI

collection 저장에 day/daily_actions/daily_ms/daily_claims/stamps/owned_lights/light_style 추가. 기존 저장 형식과 누적 선물은 유지한다. 중복 수령/중복 구매/잔액 부족을 검사하고 날짜 역행으로 같은 보상을 다시 받을 수 없도록 한다.

설정 세 번째 탭 ‘카페 노트’에서 주문 진행 → 수령 → 교환/장착. 상단 선물 배지는 받을 수 있는 주문 보상도 포함한다. 액세서리 선물이 없고 주문 보상만 있으면 상자 버튼이 카페 노트를 연다. 튜토리얼에도 카페 노트 안내를 추가했다.

정확한 지급 경계, 중복 수령, 잔액 부족, 구매/장착, 저장 재로드, 날짜 변경/역행, UI 버튼 실제 콜백과 게임 불빛 색상 적용을 검사했다. 렌더 확인 파일: builds/review/cafe-orders.png 및 cafe-shop.png.
