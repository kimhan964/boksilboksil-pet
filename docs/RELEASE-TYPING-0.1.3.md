# 복슬복슬 타자친구 0.1.3

Windows용 독립 타자 펫 게임입니다. ZIP을 전부 풀고 `TypingFriends.exe`를 실행하세요.

## 액세서리

- VARCO로 로즈 리본, 삐에로 모자, 작은 왕관, 세이지 베레모, 달빛 마법사 모자, 새싹 핀을 제작했습니다.
- 기존 리본을 새 이미지로 교체하고 5개 보상을 추가했습니다. 색상 포함 총 12개 선물입니다.
- 16마리의 머리·귀 위치에 맞춰 착용하며 타자칠 때 크기나 위치가 변하지 않습니다.
- 입력 횟수와 누적 활동 시간 조건을 모두 채우면 선물·꾸미기에서 받고 장착할 수 있습니다.
- 전신 의상은 추가하지 않았습니다. 기존 저장과 해금 진행은 유지됩니다.

## 설정 시작 오류 수정

기본 창을 초기화하는 동안 설정 UI를 추가하여 실패하던 시작 순서를 수정했습니다. 설정은 상단 버튼 또는 펫 우클릭으로 열며 위치와 크기를 자유롭게 조절합니다.

## 검증 범위

6종 × 16마리 착용 렌더와 잘림·투명 배경, 해금·저장, 48개 타자 셀, Godot 설정 버튼 입력·드래그 검사를 통과했습니다. 실제 시작 경로도 별도로 검사했습니다. Windows 실제 마우스 클릭 자동 검증은 도구 오류로 수행하지 못했습니다.
