# 잡기 행동 전환 연결 수정

## 원인

이전 버전은 3초에 `carry` 고정 그림을 새 `struggle-v1` 첫 그림으로 교체했다. 놓을 때는 진행 중인 발 자세를 버리고 예전 `carry/land` 그림으로 돌아갔다. 각각의 주기가 부드러워도 경계에서 자세·그림 크기·회전 기준이 달라졌다.

## 현재 방식

- 들기 시작: 서 있는 자세 → 차분히 들린 자세, 0.24초.
- 3초 이상 들기: 차분한 자세 → 버둥거림 첫 자세, 0.32초. 마우스를 움직이지 않은 긴 누르기는 서 있는 자세에서 직접 연결한다.
- 놓기: 낙하는 즉시 시작한다. 발은 현재 동작의 다음 연결 자세까지 이어 움직이고(보통 최대 0.35초), 0.28초 연결 동작을 거쳐 착지 자세로 간다.
- 잠깐 들었다 내려놓기: 들기 동작의 역방향 연결로 선다.
- 해롱거림 끝: 마지막 0.36초 동안 다시 서는 자세로 연결한다.
- 마우스 버튼을 놓는 프레임에는 몸통 회전과 기준점을 보존한다. 경계 시각의 반올림으로 발 자세가 한 칸 뛰는 문제도 수정했다.
- `내려줘~!` 말풍선은 0.14초 동안 나타난다.

16종 × 새끼/성체 × 연결 8종 × 17장 = 연결 이미지 4,352장. 기존 직접 생성 전신 그림의 실제 게임 배율/기준점을 추출해 동일한 화면 좌표로 맞추고 오프라인으로 연결했다. 전신 원화는 보존한다. 실행 중 두 캐릭터 그림을 겹쳐 표시하지 않으며 파츠 회전을 사용하지 않는다.

## 파일

- `assets/hold-transitions-v1/<species>/<age>/`: 연결 이미지
- `scripts/hold_transition_art.gd`: 연결 시점과 상태 선택
- `tools/export_hold_transition_poses.gd`: 실제 게임의 원래 배율/기준점 추출
- `tools/build_hold_transitions.py`: 기존 전신 이미지의 연결 프레임 제작
- `design/hold-transitions-v1/`: 양 끝 그림, 검수판, 제작 기록
- `design/hold-transitions-v1/otter-entry-comparison.png`: 수달 실제 게임 수정 전후 비교

이 수정의 범위는 위 잡기 행동 흐름이다. 식사·수면 등 다른 행동 전체의 전환을 새로 제작했다는 뜻이 아니다. 기준 프레임 수만으로 완료 판단하지 말고 `hold-transitions-native/` 캡처의 시작/끝과 중간 연결 모습을 함께 확인한다.
