1. 2D 완성형 전신 이미지만 사용한다. 3D, 파츠 분리, 본 리깅, 눈·귀·몸 조립은 금지한다.
2. 새끼와 성체는 별도 원화를 사용한다. 성장 차이는 머리·몸·팔다리 비율로 표현한다.

### 1단계 · 대표 원화 쌍 제작

대표 원화에서 고정할 항목:

- 종, 얼굴 윤곽, 눈 수와 위치, 귀·꼬리·무늬.
- 털 기본색과 그림자색.
- 귀 안쪽, 볼, 배·주둥이, 발끝 색.
- 목 장식의 종류와 색.
- 짙은 갈색 외곽선과 내부선 굵기.
- 우상단 광원, 2단 셀 채색, 같은 카메라 거리와 3/4 시점.

산출물:

- design/all-species-v3/masters/{species}/baby.png
- design/all-species-v3/masters/{species}/adult.png
- design/all-species-v3/masters/representative-review.png
- design/all-species-v3/masters/character-spec.json

통과 조건:

- 한 행동 안에서 프레임마다 털색과 명암이 변하지 않는다.
