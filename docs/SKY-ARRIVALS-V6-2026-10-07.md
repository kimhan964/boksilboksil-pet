# 하늘에서 도착하는 놀이감과 자명종

## 게임 동작

- 실뜨개 공(교감 4), 리넨 생쥐(교감 10), 동물 귀 자명종(교감 18)을 순차적으로 자동 전달한다. 집 꾸미기는 총 21종이다.
- 해금 후 여유 있는 상태에서 약 5초 대기, 화면 위에서 1.4초 낙하·작은 착지 반동, 동물의 접근·이용, 이후 최소 6초 휴지 순서다. 기존 도토리·바구니·식물 전달이 먼저 진행 중이면 기다린다.
- 실뜨개 공 곁에서는 기존 폴짝 놀이, 생쥐 곁에서는 기존 킁킁 동작을 사용한다. 놀이감은 좌우 3px·상하 3px 정도 움직이며 작은 각도 반응을 보인다. 별도의 새 동물 프레임을 만든 것은 아니다.
- 자명종은 이용 시작에 약 1.4초 가볍게 떨리고 동물이 놀란 표정을 보인 뒤 살펴본다. 알람 소리는 추가하지 않았다.
- 작은 물건과 시계가 동물 뒤에 가려지지 않게 앞옆으로 접근한다. 일반 가구의 앞쪽 접근과 보행 공간은 유지한다.
- 물건끼리 겹치지 않는 가까운 착지 지점을 선택한다. 여유 공간이 없으면 새 창을 남기지 않고 15초 뒤 재시도한다.
- 식사·물 마시기·휴식·마우스 들기·배치·다른 접근 또는 이용 중에는 다음 전달이 대기한다. 낙하 도중에는 물건 입력을 차단하고 마우스로 동물을 들면 낙하도 잠시 멈춘다.
- 각 물건은 최초 자동 도착 후 배치·소유 상태로 저장한다. `arrival_seen`을 저장해 재시작 후나 치운 뒤 자동으로 중복 생성하지 않는다. 사용자가 먼저 직접 배치해도 자동 낙하 대상에서 제외한다. 반복적으로 같은 물건을 하늘에서 재생성하는 기능은 아니다.
- 기존 가구의 색상·마감 선택과 자명종 동물 디자인 선택을 지원한다. 음식과 물은 계속 식탁에서 이용한다.

## 자산과 검증

- 신규 놀이감은 기본 제공 image_gen으로 생성했다. 최종 PNG: `assets/furniture-v6/`; 최종 프롬프트: `docs/SKY-TOYS-PROMPTS.json`.
- `tests/sky_arrivals_test.gd`: 위쪽 시작, 낙하 중 접근 금지, 들기 중 정지, 동시 전달 방지, 착지 입력 복원, 접근과 놀이/킁킁/놀람 동작, 중복 방지, 저장 복원, 자동 해금 도착 검사 통과.
- 소스 D3D12와 로컬 0.30.3 OpenGL에서 렌더·동작 검사 통과. 로컬 설치에서 기존 집 꾸미기와 앞쪽 접근 회귀 검사도 통과했다.
- `builds/sky-arrival-review/scenes.jpg`는 엔진이 렌더한 물건·동물 창 이미지를 실제 좌표로 합친 검수 이미지이며 OS 화면 캡처는 아니다. 첫 검수에서 생쥐에 공이 등장하는 기존 가구 놀이 동작과 물건 가림을 발견하여 킁킁 동작 및 앞옆 위치로 수정했다.
- 로컬 `복슬복슬펫/0.30.3/DesktopFriends.pck`에 적용했다. GitHub 배포 파일은 이번 작업에서 갱신하지 않았다.
