## 후속 상세 확인: 현재 적용본과 짧은 이동

**결론은 수정 필요다.** 현재 7종·10개 새끼/성체 걷기 조합의 전신 600장과 발 확대판을 다시 확인했다. 현재 자산 10개의 해시는 앞선 점검 자료와 모두 일치한다. 아래 기존 문제 목록은 지금 적용본에도 유효하다.

- 화면 연결을 초기화해 실제 실행 중인 점검판과 곰·너구리 표시를 확인했다. 앞선 창 연결 실패는 복구됐다. 다만 도구가 전달하는 화면은 순간 캡처이며 **정상 속도의 연속 영상을 직접 시청한 것으로 계산하지 않는다.**
- 수달·다람쥐 새끼/성체와 너구리 성체를 대상으로, 보폭의 75% 거리에 목표를 둔 짧은 이동→정지를 양방향으로 새로 실행했다. D3D12 실제 게임 렌더 **오른쪽 714장 + 왼쪽 716장 = 1,430장**을 저장·분석하고, 10개 방향별 접촉/정지 비교판을 시각 확인했다.
- 현재 구현은 작은 거리에 맞춰 발걸음을 압축하지 않고 한 보폭을 끝낸 접촉 자세에서 멈춘다. 이번 지지 발 가로 변화는 약 **0.462~0.722px**, 정지 경계 머리 변화 최대 **가로 0.162px / 세로 0.068px**였다. 실루엣 기반 보조 측정이며 해부학적 관절 추적은 아니다.
- 새 캡처에서 공백·창 경계 잘림·표시 배율 변경·재생 도중 프레임 인덱스 건너뜀은 없었다. 우향 수달 성체와 양방향 너구리는 기록이 1번에서 시작해 0번을 관측하지 못했다. 이를 '60장 모두 확인'으로 처리하지 않았다. 다른 7개 방향별 기록에서는 0~59번을 관측했다.
- 짧은 이동에서 큰 접지 붕괴가 재현되지 않아도 **발바닥 회전, 발가락 윤곽 변형, 지지하는 쪽으로 몸의 무게가 이동하지 않는 문제**는 그대로 남는다. 발이 교대하는 순서만 맞추는 것으로 해결되지 않는다.
- 별도 다람쥐 새끼 `swing-low` 후보의 양방향 실제 접촉/정지 비교판도 확인했다. 발 회수 전반 이동은 현재 80.1/34.0%에서 후보 56.8/54.8%로 고르게 개선됐지만, 중간 자세의 색과 몸통 반응 보완이 남았다. **후보는 미적용 상태다.**
- 이번 작업은 검사와 기록 정리다. 게임 이미지·일반 게임 설정은 교체하지 않았다. 새 걷기는 점검판용이고 일반 게임의 `smooth_walk_enabled=false` 상태 및 의상 착용 시 적용 제외 조건이 남아 있다.

### 이번 검사에서 고친 검사 도구

짧은 이동 검사 도구가 예전 제작 폴더의 발 추적 자료를 읽을 수 있었다. `review_short_stride.py`에 현재 자산의 해시를 검증하고 실제 이미지에서 발을 다시 측정하는 `--live-audit` 옵션을 추가했다. 위 1,430장 결과는 이 옵션을 사용했다. 게임 모션 자체를 수정한 것으로 보고하지 않는다.

증거: `design/walk-v12/naturalness-check-current/short-summary.json`, 같은 폴더의 전신/발 확대판 및 `short-right/`, `short-left/`. 원본 기록은 `walk-native-naturalness-short-right-report.json`, `walk-native-naturalness-short-left-report.json`이다.

### 검사 범위 밖에 남은 항목

이번 판단은 새 걷기 10개 조합에 한정한다. 토끼 성체 승인본, 토끼 새끼, 고슴도치·고양이·강아지·햄스터·판다·레서판다·양·코알라 양 나이, 너구리·곰·부엉이·펭귄 새끼의 새 걷기는 이번에 자연스럽다고 승인하지 않았다. 식사·수면·표정·의상·잡기/낙하 등 다른 행동도 별도 검수가 남아 있다. 게임 시간 기반 캡처로 전체 데스크톱의 GPU 프레임 지연까지 판단하지 않는다.

## 판정

**현재 새 걷기는 최종 자연스러움 통과 전이다.** 프레임 누락이나 표시 크기 변경보다, 발 회수의 시간 배분·발끝 형태 변화·약한 체중 이동이 눈에 띈다. 발 위치를 보정해 떨림이 줄어도 몸통·팔·꼬리가 함께 반응하지 않으면 정지 그림의 발만 움직이는 인상이 남는다.

이번 점검에서는 게임 자산을 교체하지 않았다. 너구리 성체 후보는 별도 실행으로 확인한 뒤 원래 자산을 복원했다. 이전 곰 성체·여우 새끼 개선본은 유지한다.

## 실제 확인 범위와 한계

- 수달·다람쥐·여우 새끼/성체, 너구리·곰·부엉이·펭귄 성체: **7종, 10개 걷기 조합**.
- 현재 적용된 각 60장, 총 **600장 전신과 발 확대판**을 시각 비교했다. 자산 해시와 제작 시 발 추적 자료의 일치도 확인했다.
- Godot D3D12에서 좌우 시작→세 주기 걷기→정지를 다시 실행했다. 오른쪽 3,351장 + 왼쪽 3,349장 = **6,700장**.
- 너구리 성체 수정 후보는 별도 오른쪽 335장 + 왼쪽 334장 = **669장**. 이번 추가 실행 기록 합계 **7,369장**.
- 현재 10개 모두 양방향에서 60개 프레임을 관측했다. 빈 프레임·창 경계 잘림·걷기 중 표시 배율 변화·관측상 프레임 인덱스 건너뜀은 없었다.
- 반복 경계의 머리 가로 변화 최대 약 0.169px, 정지 경계 약 0.174px. 이번 제한된 시작/정지 조건에서 큰 튐은 잡히지 않았다.
- Windows 화면 도구가 이미 사라진 창 번호를 반환했고 재조회도 실패했다. **이번에는 정상 속도 연속 화면의 직접 시청을 완료하지 못했다.** 판정 근거는 실제 게임 렌더 캡처의 시간/위치 분석과 프레임별 시각 비교다.
- 캡처 시간은 게임 내부 시간이다. GPU 지연·전체 데스크톱의 버벅임까지 없다고 판정한 결과가 아니다. 저장 GIF는 비교용으로 표본을 줄였으므로 60Hz 표시 품질의 근거로 쓰지 않는다.
- 토끼 승인본, 나머지 종/나이, 식사·수면·표정·의상·상호작용은 이번 걷기 검사 범위 밖이다. 전체 제작 목표는 계속 남는다.

우향 실제 캡처 기준. 머리 윤곽 중심은 자세 변화도 포함하는 보조 지표다. 수치가 작다고 자연스럽다는 뜻이 아니며, 표시 윤곽 높이 변화는 런타임 배율 변경과 다르다. 너구리는 세로 반응이 약 0.15px에 불과하고 전신 비교에서도 몸 반응이 거의 없어 발만 움직이는 인상이 강하다. 이를 해결하려고 모든 동물의 몸을 일괄적으로 크게 흔들어서는 안 된다.

## 60장과 60fps의 차이

현재 10개 모두 한 주기 **60장 / 1.6초 = 초당 37.5개 자세**다. 주요 전신 원화는 수달 성체 5개, 나머지 4개이고 나머지 이미지는 그 사이를 보간한다. 따라서 60장의 파일이 있어도 발을 떼거나 체중을 받는 자세가 원화에 빠져 있으면 올바른 동작이 새로 생기지 않는다.

실제 캡처에서는 각 자세가 한 번 또는 두 번의 표본에 걸쳐 유지됐다. 이 불균등한 유지 간격이 미세한 끊김에 영향을 줄 가능성은 있지만, 이번 자료만으로 심한 어색함의 주원인이라고 단정하지 않는다. 게임 시간 간격은 대체로 16.67ms였고 일부 약 32.77ms가 있었지만 인덱스 누락은 관측되지 않았다.

수정 순서는 **주요 자세·접지·체중 이동 → 발끝 보간 품질 → 재생 간격**이다. 자세를 고친 대표 한 개에서 주기 1.6초를 유지한 96장과 현재 60장을 비교하면, 60Hz 기준 그림 교체 간격만 따로 시험할 수 있다. 속도를 올려서 프레임 수 차이를 숨기거나 동일 그림을 복제해 부드러워졌다고 판정하지 않는다.
