# 집 꾸미기와 교감 중심 생활 개편

## 하나의 해금 기준

모든 동물의 누적 교감 합계를 ‘우리 집 교감’으로 사용한다. 교감은 소비하지 않는다. 성장 경험치와 동물별 교감 기록은 유지한다. 기존 행동 횟수 또는 교감으로 이중 해금하던 시스템, 음식 해금, 돌보기 행동 잠금은 제거했다.

| 우리 집 교감 | 가구 |
| --- | --- |
| 0 | 식탁, 소파, 놀이 러그 |
| 6 | 책장 |
| 12 | 리넨 램프 |
| 20 | 독서 의자 |
| 30 | 데이베드 |
| 42 | 화장대 |
| 56 | 음악 장식장 |
| 72 | 창가 벤치 |
| 90 | TV장 |
| 110 | LP 테이블 |

새 가구는 해금 알림 후 ‘집 꾸미기’에서 직접 배치한다. 가구를 자동으로 떨어뜨리거나 기존 생활 도구와 중복 제공하지 않는다. 기본 장난감은 이전의 순차 등장 기능을 유지한다.

## 기본 생활

- 식사·물 마시기: 식탁. 식탁이 없으면 가구 배치 창을 안내하며 연못이나 바닥 그릇으로 대체하지 않는다.
- 휴식: 소파, 해금한 침대와 휴식 가구.
- 교감: 쓰다듬기, 따라오기, 공놀이, 성격 행동, 표정과 반응은 처음부터 이용한다.
- 식사 메뉴 32종은 처음부터 선택 가능하다.
- 동물을 가구에 끌어 놓기, 가구 클릭, 자율 방문을 유지한다.
- 연못은 생성하지 않는다. 기존 바닥 그릇·침대·쉼터·조명은 호환 코드만 남기며 표시·목적지·선물 전달에서 제외한다.

## 저장 전환

저장 버전 7. 기존 동물, 성장, 교감, 배치 좌표를 유지한다. 이전에 배치한 가구는 교감이 부족해도 소유한 가구로 인정하며 치웠다가 다시 배치할 수 있다. 최초 전환 시 기본 가구 중 없는 가구만 추가하고 새 도움말을 보여준다. 이후 사용자가 치운 기본 가구를 재실행 시 강제로 복원하지 않는다. 테스트 저장은 사용자 저장과 분리한다.
