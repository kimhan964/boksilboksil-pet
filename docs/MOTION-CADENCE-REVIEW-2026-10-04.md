# 걷기 시간·코알라 깜빡임 수정 — 2026-10-04

## 판정

**재생 속도·주기 진행·코알라 깜빡임을 수정했다. 걷기 원화의 자연스러움은 아직 통과가 아니다.**

사용자의 최신 지적은 여러 동물의 비정상적으로 빠른 발, 코알라 깜빡임, 실제 플레이 화면에서 확인하라는 요구다. 이번 수정은 새 원화 제작 완료로 기록하지 않는다.

## 실제 게임에서 확인한 것

- 수정한 v12 점검판을 실행하고 화면의 동물 선택 메뉴에서 코알라 성체를 골랐다. 바탕화면의 실제 코알라 창에서 좌우 이동과 정지 상태를 여러 차례 관찰했다. 도구가 제공하는 것은 순간 화면이므로 연속 60Hz 영상을 육안으로 시청했다고 주장하지 않는다.
- 실제 점검판의 기존 동물 왕복 거리는 72px였으나 코알라 성체의 코드상 한 주기 이동 거리는 62.48px였다. 따라서 1.152주기에서 멈추고 방향을 바꾸었다. 자동 캡처의 전용 경로는 한 주기 거리를 사용해 이 차이를 놓칠 수 있었다. 이제 화면의 왕복도 동일한 주기 거리의 3배를 쓴다.
- 기존 도착 판정은 목표보다 0.5px 일찍 멈췄고, 계산상 이동량과 실제 저장된 좌표의 차이도 반복 왕복에서 쌓였다. 기본 도착 오차를 0.001px로 줄이고, 발 위상은 실제 저장된 이동량으로 진행한다. 특수 행동의 명시적 도착 허용치와 토끼 승인본의 경로는 유지한다.

## 수정

1. 기존 걷기의 종별 정상 재생 주기를 아래 값으로 낮추고, 이동 속도도 같은 비율로 조절했다. 따라서 속도 변경 자체로 발과 이동의 기존 비율이 달라지지는 않는다. **기존 보폭이 해부학적으로 올바르다는 뜻은 아니다.**
2. 따라가기·공 쫓기에서 걷기를 1.5배까지 가속하던 상한을 1배로 제한했다. 느린 행동 배율은 남아 있다.
3. v12 걷기는 한 걸음이 시작될 때 시간을 고정한다. 행동 배율이 중간에 바뀌어도 발이 뒤로 튀거나 갑자기 빨라지지 않는다. 원본 제작 메타데이터의 1.6초는 이력으로 보존하고 실제 재생 시간은 별도로 적용한다.
4. 코알라 v4의 홀수 중간 프레임은 귀·배의 흰색과 얼굴 형태가 원본과 달랐다. 일관된 짝수 전신 16장만 같은 전체 주기에 재생하도록 임시 수정했다. **60장 재제작으로 표시하지 않는다.** 프레임마다 가로·세로 크기를 다시 계산하던 보정도 이 경로에서 제외했다.
5. 기존 동물도 고정된 투명 창 안에서 움직이게 했다. 캐릭터 이동마다 운영체제 창을 옮기는 동작을 줄였다. 확대된 창에 맞춰 소품 잡기, 클릭 효과, 메뉴 위치의 좌표도 수정했다.

## 정상 속도의 한 시퀀스 시간

| 대상 | 초 |
|---|---:|
| 토끼 기존 동작 | 1.80 |
| 수달 / 너구리 / 양 | 2.20 |
| 다람쥐 / 햄스터 | 2.00 |
| 고슴도치 / 부엉이 | 2.30 |
| 여우 / 강아지 | 2.05 |
| 곰 / 판다 | 2.40 |
| 고양이 / 레서판다 | 2.10 |
| 코알라 | 2.45 |
| 펭귄 | 2.25 |

토끼 성체 승인본 v9에는 이 표를 적용하지 않는다. 기존 동작은 실제 이동량에 발 위상이 묶여 있어 출발·정지 가감속 동안 주기가 늘어난다. 예를 들어 코알라 정속 구간은 실측 2.45초, 출발을 포함한 첫 한 주기 이동은 약 2.58초였다. v12의 전체 발 시퀀스는 2.00~2.40초로 측정됐다. 숫자를 정했다고 올바른 발 교대 주기가 만들어지는 것은 아니다.

## 검증 근거

- 기존 16종 × 새끼·성체 32개: 변경 초기 D3D12 캡처 6,217장. 모두 프레임별 크기 보정이 있어 고정 배율 검사는 실패했다. 전체 자연스러움 통과로 처리하지 않았다.
- 코알라 수정 후: D3D12 오른쪽 439장·왼쪽 440장, OpenGL 438장. 공백·창 경계 잘림 없음. 각 나이의 걷는 동안 표시 배율 하나, 한 보폭에서 창 위치 하나, 의도한 원본 16장만 관측했다.
- 코알라 수정 전 새끼 배율 0.3684~0.4069, 성체 0.4040~0.4326. 수정 후 각각 0.381637·0.397990으로 고정. 그림 안의 실루엣 변화까지 없다는 뜻은 아니다.
- 현재 v12 7종·10개 조합: 1,937장, 각 60장 모두 관측, 공백·잘림·배율 변화 없음. 실측 주기가 설정과 일치했다.
- 30·60·144Hz 속도 검사 252건, 걸음 도중 배율 변경 3건, 코알라 8회 왕복 × 3개 주사율 24건 통과. 도착 검사 630건 및 토끼 v9 접지 검사 통과.
- 자료: `design/walk-cadence-review/`, `measured-cadence.json`, `runtime-cadence.json`, 원본 캡처 보고서 `walk-native-*cadence*-report.json`.

## 남은 수정 — 다음 작업의 우선순위

- [ ] **코알라 양 나이:** 현재 원본은 같은 쪽 발을 반복해 드는 구간이 있다. 깜빡임을 줄인 16장 임시 재생을 최종 걷기로 승인하지 않는다. 한쪽 접지→반대쪽 회수→반대 접지→회수의 전신 원화부터 다시 만든다.
- [ ] 발이 움직인 거리를 원화에서 측정해 보폭을 정한다. 기존 코알라의 62.48px는 과거 코드의 보폭이며 접지로 검증된 값이 아니다. 발의 미끄러짐이 남는다.
- [ ] 준비 중인 다른 종도 홀짝 프레임의 색·형태 차이, 접지 순서, 체중 이동을 실제 화면과 전신 프레임으로 검사한다.
- [ ] v12 10개 조합의 발바닥 회전·회수 경로·몸통 반응·색 일관성 문제를 이전 상세 점검표대로 보완한다.
- [ ] 임의 목적지·먹기·물 마시기·의상·잡기/놓기 전환은 각각 실제 플레이 검수가 필요하다.

후속으로 VARCO에서 코알라 성체 전신 자세 4장과 기본 이미지 생성 도구에서 전신 4자세 시트 1장을 제작했다. VARCO 후보는 발 이동 11~13 원본 픽셀과 거의 고정된 몸통, 시트 후보는 발 겹침과 길어진 다리 때문에 모두 미적용으로 남겼다. `design/walk-v12/koala/adult/cadence-generation.json`, `cadence-sheet-imagegen-review.json`에 원본·프롬프트·판정을 보존했다. 기존 게임 이미지 파일은 덮어쓰지 않았다.

## 최종 반영과 실행

- 최종 코알라 세 주기 이동/정지 D3D12 캡처 1,027장(새끼 514·성체 513)에서 공백·잘림·배율 변경·의도하지 않은 홀수 프레임 없음.
- 최종 패키지를 다시 실행하고 실제 선택 메뉴에서 코알라 성체 및 새끼를 각각 골라 바탕화면의 렌더 화면을 확인했다. 최종 점검판은 코알라 새끼로 실행 중이다. 중복 실행은 정리하고 프로세스 한 개를 확인했다.
- 사용자 폴더의 일반 게임 `DesktopFriends.pck`와 `전체동물-움직임점검-v12/DesktopFriends.pck`를 갱신했다. 일반 게임 패키지는 갱신했으나 이번 직접 화면 조작은 v12 점검판에서 했다. 저장 데이터는 수정하지 않았다. 이전 패키지는 `점검자료-2026-10-04/속도수정-전/`에 보존했다.
- 이 결과는 정상 속도 연속 영상의 육안 감상이나 모든 동물의 자연스러움 승인과 구분한다. 코알라 전신 원화의 제대로 된 발 교대/접지 재제작이 가장 먼저 남는다.
