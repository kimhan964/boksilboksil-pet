# 타자친구 설정 UI · 2026-10-07

- 제목·버튼: 주아체(Jua). 본문·상태 설명: 고운돋움(Gowun Dodum).
- Google Fonts 원본 TTF와 SIL OFL을 `games/typing-pet/assets/fonts`에 보관했다. OS 설치 없이 FontFile.data로 읽어 PCK에서도 같은 글씨체를 사용한다.
- 출처: https://github.com/google/fonts/tree/main/ofl/jua 및 https://github.com/google/fonts/tree/main/ofl/gowundodum
- 크림 배경, 세이지 버튼, 로즈 포인트, 둥근 테두리, 발바닥 제목 장식. 글씨 중앙 정렬.
- 설정은 ‘오늘 함께할 친구’, ‘내 책상에 쏙’, ‘작은 반응들’ 카드로 묶었다. 입력 불빛·선물 반짝임은 켜짐/꺼짐을 글자로도 표시한다.
- 꾸미기는 장착 중 카드의 연두색 테두리, 수령 가능한 카드의 크림 로즈 배경, 가운데 아이콘과 읽기 쉬운 제목으로 구분한다.
- 설정 창은 560×720을 기준으로 작은 화면에서 높이를 줄이고 내부 스크롤을 유지한다. 선물 팝업은 창 가운데 정렬한다.
- 작은 펫 미리보기와 생성 액세서리에 mipmap을 적용한다. 원본 동물 프레임은 변경하지 않는다.
- `tests/check.gd -- --capture`로 버튼 입력·드래그·크기 설정·선물·저장 회귀 검사 및 settings/unlocked/locked/gift 렌더 확인.
- 네이티브 클릭 자동화의 기존 도구 제한은 그대로다. 렌더와 Godot 입력 검사 결과를 실제 OS 클릭 검증으로 표현하지 않는다.

## 후속 조정

- 상단 설정/선물 및 하단 종료/닫기 버튼의 폭을 동일하게 맞추었다. 크기는 왼쪽부터 작게 85%, 보통 100%, 크게 120%로 고정한다.
- 프리셋은 0.2초 보간, 슬라이더는 1% 단위. 확대 중 알파 클릭 영역 재추출과 매 프레임 파일 저장을 제거했다. 슬라이더 놓기/5초 자동 저장 시 최종값을 저장한다.
- 직접 배치한 펫은 아래쪽 중심을 고정하고 부동소수점 기준점을 보존해 연속 변경의 좌표 반올림 누적을 방지한다. 화면 구석 배치 시 선택한 구석을 유지한다.
- 글씨 크기 90~130%를 펫 크기와 별도 저장한다. 설정 본문/버튼/메뉴와 상단 APM에 적용하며 설정 창 폭도 맞춰 늘린다.
- 선물은 수령 전까지 개수 배지/도착 문구를 유지한다. 효과 옵션이 켜져 있으면 상자 바운스와 은은한 빛을 반복한다. 효과를 꺼도 문구/개수는 보인다.
- 추가 검사: 130% 글씨 렌더, 프리셋 중간값/정확한 도착값, 연속 확대의 중심점 오차 1픽셀 미만, 클릭 영역 캐시 재사용, 30초 후 선물 표시 유지.

## 최소 글씨와 첫 실행 안내

- 90% 글씨 옵션에서도 모든 설명/버튼 글씨는 최소 12px. 펫 축소 시 상단 UI 배율은 100% 아래로 내려가지 않는다. UI 크기를 포함한 이동/확대 경계도 다시 계산한다.
- 별도 활성화 없이 펫 또는 APM 영역을 드래그한다. 설정에 ‘자유 이동 · 항상 켜짐’ 안내를 표시한다.
- 탭과 설정 카드에 발바닥/이동/글자/선물 아이콘을 추가했다. 하단은 종료/도움말/닫기를 같은 폭으로 배치한다.
- `tutorial.gd`의 네 단계: 입력/APM → 드래그 이동 → 펫/글씨 크기 → 선물/꾸미기.
- 저장에 `tutorial_seen`을 추가했다. 첫 실행(또는 안내가 없었던 기존 저장)은 자동 표시, 완료/닫기 시 저장, 설정 도움말로 언제든 재열기. startup-check에서는 자동 안내를 띄우지 않는다.
- 검증: 최소 크기 글씨, 안내 4장 렌더, 완료/재열기, 별도 검증 파일의 저장/로드. 실제 사용자의 저장을 테스트로 수정하지 않는다.
