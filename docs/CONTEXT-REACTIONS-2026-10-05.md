# 상황별 감정 반응 인수인계

## 적용
기존 16종 × 새끼/성체의 전신 감정 이미지 4종(미소, 놀람, 토라짐, 졸림)을 20개 생활 상황에 연결했다. 새 이미지 생성 작업이 아니라 기존 이미지에 상황별 몸짓, 문구, 재생 조건을 추가한 작업이다.

| 상황 | 반응 |
|---|---|
| 쓰다듬기 | 미소, 손길 쪽으로 살짝 기울기 |
| 식사 완료 / 좋아하는 음식 | 만족하는 미소, 고개 끄덕임. 좋아하는 음식은 더 큰 반응 |
| 손으로 먹여주기 | 미소와 감사 반응 |
| 물 / 차 | 편안한 미소, 작게 몸을 낮추며 이완 |
| 도토리·놀이 러그 / 공 가져오기 | 즐거운 통통 몸짓. 동물마다 놀이 문구가 다름 |
| 새 도구 도착 / 빈 간식 그릇 | 세기가 다른 놀람과 호기심 |
| 소파·벤치 / 잠에서 깨기 | 편안한 미소와 작게 기대는 몸짓 |
| 독서 / 식물 돌보기 | 고개를 갸웃하며 만족 |
| 단장 | 살짝 몸을 세우며 뿌듯한 미소 |
| 음악 | 작은 좌우 흔들림 |
| 피로 | 졸린 표정과 고개 끄덕임 |
| 2초 이상 들린 뒤 내려놓기 | 잠깐 토라짐, ‘다음엔 조금만 안아줘’ 등. 낙하·해롱이 있다면 그 뒤 |
| 짧게 들어 내려놓기 / 마우스 가까이 | 살짝 기대며 감사·반가움 |

## 코드와 우선순위
- `context_reactions.gd`: 20개 이벤트와 문구, 강도, 반복 제한, 단일 대기 슬롯.
- `main.gd`: 실제 행동 완료 신호를 식사/물/가구/놀이 등의 이벤트로 변환.
- `desktop_pet_motion.gd`: 쓰다듬기, 공 회수, 피로, 행동 경계에서 반응 재생.
- `desktop_pet.gd`: 내려놓기와 마우스 근접.
- `expression_behavior.gd`: 상황별 고개 끄덕임/기대기/이완/흔들림. 크기 변형 없음. 기존 종별 템포와 기울기를 사용.
- `desktop_pet_view.gd`: 해당 상황의 문구 표시, 기존 머리 기준 말풍선 배치 사용.
- 대기 반응은 보통 0.22초 이후, idle 또는 ball_ready에서만 시작한다. 걷기·먹기·가구 사용·들기·낙하·해롱·성격/교감 행동은 끊지 않는다.
- 기본 동일 이벤트 제한 12초, 반응 종료 후 최소 3초 간격. 피로 65초, 근접 인사 40초, 짧은 내려놓기 18초.
- 대기 반응은 10초 뒤 폐기한다. 반복 이벤트가 계속 들어와도 시작 시각을 밀지 않는다. 새 직접 행동으로 취소하면 대기 반응도 비운다.
- 들림 이후 토라짐 > 새 선물 > 일반 반응 순. 밀린 반응을 줄줄이 재생하지 않는다.
- 공 준비 상태에서 반응할 때 공을 보존하고, 반응 뒤 ball_ready로 돌아간다.
- 직접 쓰다듬기에는 즉시 반응하며 기존 클릭 보상 제한을 유지한다.

## 확인 결과
- `context_reactions_test.gd`: 16종 × 2성장 × 20상황 = 640건 통과. 식사 중 비간섭, 만료/취소/우선순위, 반복 제한, 공 유지, 실제 가구·식사 완료 신호 연결 검사.
- `expression_behavior_test.gd`: 7,808개 표정 시점 검사, 크기 오차 약 0.0000073px, 효과 머리 기준 오차 0px.
- `furniture_drop_test.gd`: 끌어놓기 640건 통과.
- `tool_delivery_test.gd`, `living_space_test.gd` 통과.
- 실제 D3D12 게임에서 좋아하는 음식 반응을 재생하고 미소/문구/발 위치 화면 확인. 오래 들린 뒤 반응은 실행 로그로 react 진입 확인. 모든 상황을 모든 종으로 실제 마우스 플레이 검수한 것은 아니다.
- `verify_visual_package.gd`: 새 상황 모듈 포함 26개 코드 파일과 기존 미술 자산을 원본과 비교한다.

## 후속 작업 시 주의
감정 때문에 현재 행동을 강제로 react로 덮어쓰지 말고 기본적으로 이벤트를 queue한다. 행동을 처음부터 다시 시작하게 하거나 공/가구 방문 상태를 잃게 만들지 않는다. 새 몸짓도 발의 월드 위치나 캐릭터 배율을 변경하지 않는다.
