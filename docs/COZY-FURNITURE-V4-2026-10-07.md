# 색감 정리와 가구 6종 확장

## 디자인과 자산

크림·밝은 원목·세이지·더스티 피치를 공통 기준으로 삼았다. 새 가구는 작고 둥근 형태, 섬세한 동물 포인트와 투명 배경으로 제작했다. 기본 제공 image_gen 도구로 한 가구씩 생성했으며 최종 프롬프트는 `docs/FURNITURE-V4-PROMPTS.json`, 원본 PNG는 `assets/furniture-v4/`에 보관했다.

| 가구 | 교감 | 이용 행동 |
|---|---:|---|
| 곰 귀 원목 벽시계 | 8 | 시계 관찰 |
| 토끼 책꽂이 벽 선반 | 16 | 기존 독서 동작 |
| 잎새 세라믹 화분대 | 24 | 잎새 관찰 |
| 발바닥 원목 서랍장 | 38 | 기존 털 단장 동작 |
| 포근한 전기 벽난로 | 64 | 기존 휴식 동작 |
| 작은 물고기 수조장 | 84 | 물고기 관찰 |

수조는 관상 장식이며 물 마시기는 계속 식탁에서 한다. 시계 그림의 바늘과 수조 물고기는 정적인 이미지다. 새 동물 동작 프레임을 생성한 것은 아니며 기존 행동을 새 가구의 목적지와 연결했다.

## 색감 적용

`cozy_palette.gdshaderinc`를 동물과 가구의 최종 렌더에 공통으로 적용한다. 채도는 원본 대비 90%, 약한 따뜻한 색조를 적용하며 알파와 크기는 바꾸지 않는다. 가구는 추가로 HSV 채도 상한 0.43을 적용해 기존 강한 주황 원목과 붉은 의자를 새 가구의 차분한 톤에 맞췄다. 미리보기와 실제 가구에 같은 재질을 사용한다. 원본 이미지는 보존했다.

## 배치와 저장

가구 목록은 12종에서 18종으로 확장했다. 공동 교감으로 해금되고 기존 소유·성장·배치를 보존한다. 벽시계와 벽 선반은 바닥 모드에서도 위아래 이동 및 저장이 가능하다. 보행 공간보다 너무 낮게 배치하면 위로 올려 동물의 앞쪽 통행 공간을 확보한다. 모든 새 가구는 클릭하거나 동물을 끌어 놓으면 이용하며 좌우 반전도 지원한다.

## 검증과 설치

- `tests/cozy_furniture_test.gd`: 18개 자산·해금·배치 UI, 새 가구 6종의 이용, 두 공간 모드, 벽 장식 수직 이동·저장, 반전 검사 통과.
- `tests/furniture_front_test.gd`: 확장된 목적지의 앞쪽 접근과 16종 통행 검사 통과.
- `tests/home_progression_test.gd`: 기존 집 꾸미기·돌봄·저장 이행 회귀 검사 통과.
- 소스 D3D12 렌더를 저장해 18종 가구와 배치 창을 확인했다. 검수 이미지: `builds/cozy-furniture-review/all-furniture.jpg`.
- 로컬 `복슬복슬펫/0.30.3/DesktopFriends.pck`에 적용했고 해당 설치의 OpenGL 렌더 및 집 꾸미기 회귀 검사도 통과했다. OS 실제 마우스 조작과 창 겹침 전체를 검증한 것은 아니다.
- GitHub 배포 파일은 이번 작업에서 갱신하지 않았다.
