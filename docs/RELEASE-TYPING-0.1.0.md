# 복슬복슬 타자친구 0.1.0 · 독립 게임

데스크톱 펫과 별도의 게임으로 분리했습니다.

## 다운로드와 실행

`BoksilTypingFriends-0.1.0-Windows.zip`을 전부 압축 해제한 뒤 **TypingFriends.exe**를 실행하세요. 기존 데스크톱 펫을 설치할 필요가 없습니다.

- 16마리의 완성된 타자 그림 48장, 왼손·오른손 입력 반응
- 중앙 정렬된 크림·세이지 UI, 위쪽 APM·활동 시간, 아래쪽 네모 불빛
- 클릭 통과와 분리된 설정 버튼, 친구·직접 위치 이동·70~150% 크기·일시정지·불빛/선물 효과 설정
- 도착하는 리본 선물 상자의 통통 튀기·반짝임·상자 열기 효과
- 액세서리 4종 + 톤 스킨 3종의 영구 해금·수령·장착·저장
- 브루드 워용 APMAlert 공개 수학식 기반 APM, 시작부터 숫자를 표시하는 초반 안정화
- 전용 저장 폴더 `BoksilTypingFriends`, 데스크톱 펫과 독립 실행

브루드 워 게임 자체의 APM과 입력 대상은 다릅니다. 키보드와 마우스 클릭 횟수를 집계하며 입력 내용은 저장하지 않습니다. 톤 스킨은 은은한 색상 변형입니다.

이 배포본은 타자친구 전용입니다. 기존 **복슬복슬펫**은 별도 게임으로 유지됩니다. 이전 데스크톱 배포본은 이 저장소의 기존 Releases에서 받을 수 있습니다.

수치·저장·해금·48개 프레임·16종 핀 접점·3개 크기의 엔진 입력 검사와 D3D12 화면 검수를 통과했습니다. 실제 OS 마우스 조작 자동화는 도구 연결 오류로 확인하지 못했습니다.

상세 기획·해금 조건·출처·검증 방법은 ZIP 안 `README.md`에 있습니다. `SHA256SUMS.txt`로 파일 무결성을 확인할 수 있습니다.
