# 복슬복슬 타자친구 0.1.1 · 설정 클릭과 위치 이동 수정

`BoksilTypingFriends-0.1.1-Windows.zip`을 전부 풀고 `TypingFriends.exe`를 실행하세요. 이전 버전은 종료한 뒤 실행해 주세요. 전용 저장 폴더는 그대로 사용하므로 선물과 진행 기록이 유지됩니다.

- 설정 영역을 불투명 네이티브 창으로 변경하고 펫 창과 겹치지 않게 배치했습니다.
- 펫 창의 입력 통과 플래그를 매 프레임 바꾸지 않고, 고정된 Windows 입력 영역을 사용합니다.
- 이제 별도 이동 모드 없이 동물을 바로 잡아 끌어 위치를 변경할 수 있습니다. 상단 APM 영역도 이동 손잡이로 사용할 수 있습니다.
- 펫과 설정 영역이 함께 이동하고 위치를 저장합니다. 모서리 선택·70~150% 크기 조정도 유지합니다.

설정 버튼 입력, 3개 배율의 창 비겹침, 드래그에 따른 창 좌표 변경·저장, 48개 프레임과 16종 고정 입력 영역 검사를 통과했습니다. 실제 Windows 마우스 자동화는 도구 연결 오류로 확인하지 못했습니다.
