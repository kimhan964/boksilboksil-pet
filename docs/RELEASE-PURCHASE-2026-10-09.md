# 복슬복슬펫 0.33.3 · 계정 창과 구매 동물 다운로드 수정

ZIP을 새 폴더에 모두 풀고 DesktopFriends.exe를 실행하세요. ‘계정 연결’에서 구매·수령한 계정으로 로그인하고 PC 연결을 승인하면 그 동물만 사용할 수 있습니다. 받은 선물은 홈페이지에서 먼저 ‘내 계정에 받기’를 완료하세요.

- 계정 연결 창을 독립된 Windows 창으로 변경해 글씨·버튼 잘림을 수정했습니다.
- 홈페이지 보관함 다운로드는 등록된 동물과 결제를 확인합니다.
- 추가 동물 팩은 서버에서 해당 종의 이용권을 다시 확인한 뒤 인증된 경로로 받습니다. 미구매·타인·미수령·환불·테스트 이용권은 차단합니다.
- 기존 성장·가구 저장을 유지합니다. 기본 포함된 토끼도 이용권이 필요하며, 이용권 확인에는 인터넷 연결이 필요합니다.

검수: 실제 Windows EXE 시작 창의 안내문·세 버튼 표시 확인, 패키지 구매 권한 검사 PASS, 홈페이지 자동 검사 68개 PASS, Worker 빌드 PASS. 실제 결제·실사용자 계정 연결은 수행하지 않았습니다.

이전 공개 GitHub 동물 팩의 과거 직접 주소는 그대로 공개되어 있습니다. 이번 수정은 공식 홈페이지·게임의 구매 권한 검사 경로를 적용합니다.
