# UI와 행동별 해금 정리 — 2026-10-05

## 화면 기준

- 크림색 바탕, 세이지색 선택/진행도, 차분한 회갈색 글자. 캐릭터 그림이 주인공이며 알림은 작고 조용하게 표시한다.
- 펫 우클릭 메뉴: **함께하기 / 돌보기 / 내 공간 / 성장·선물**.
- 상단은 현재 동물과 성장 단계·교감 점수, 본문은 행동 버튼과 다음 해금 조건, 하단은 친구 변경·종료.
- 성장·선물은 아직 열리지 않은 생활을 먼저, 이미 열린 생활을 아래에 표시한다. 진행 막대는 행동 횟수와 기존 교감 점수 중 높은 달성률을 사용한다. 둘을 합산하지 않는다.
- 전체 동물 확인판의 시작 창은 동물 선택·생활 메뉴를 우선 표시하고, 프레임 비교·반복 재생은 ‘동작 점검’으로 접는다.

## 해금 조건

아래 행동 횟수 **또는** 기존 교감 점수 중 하나를 충족하면 열린다. 기존 점수와 행동 기록을 그대로 사용하므로 이미 열린 기능을 다시 잠그지 않는다. 동물별로 따로 기록한다.

| 열리는 생활 | 완료할 행동 | 기존 교감 기준 |
|---|---|---:|
| 도토리 오뚝이 | 처음부터 제공 | 0 |
| 음식 그릇·먹여주기·소품 꾸미기 | 쓰다듬기 3회 | 3 |
| 물 마시기·연못 | 직접 먹여주기 1회 | 6 |
| 킁킁·폴짝 놀이 | 도토리 놀이 2회 | 8 |
| 마우스 따라오기 | 쓰다듬기 5회 | 10 |
| 장난감 바구니·공 던지기 | 도토리 놀이 3회 | 12 |
| 간식 찾기 | 직접 먹여주기 3회 | 16 |
| 소품에 부비기 | 따라오기 2회 | 18 |
| 전용 침대·잠자리 | 가구에서 휴식 2회 | 20 |

| 성격 행동 | 폴짝 놀이 3회 | 36 |

| 전용 집·쉼터 | 가구에서 휴식 6회 | 50 |

### 기록과 보상

- 메뉴 클릭이 아니라 기존 행동 완료 신호에서 기록한다. 쓰다듬기는 기존 교감 신호를 사용한다.
- 같은 행동의 보상 간격: 일반 행동 8초, 식사·물·가구 행동 45초. 쿨다운 중 반복은 횟수와 점수 모두 증가하지 않는다.
- 소파·데이베드·램프·창가·TV의 이용 완료 → 가구 휴식.
- 턴테이블·레코드 플레이어 → 음악 감상. 러그·독서·단장·티타임도 각각 완료 기록, 교감·성장 +1.
- 장식 가구 배치는 처음부터 가능하다. ‘소품 꾸미기’ 해금은 기존 그릇/소품 편집 기능이며 가구 배치 전체를 막지 않는다.
- 먹이 32종의 기존 교감 **및** 직접 먹여주기 조건은 별도 유지한다. 새 메뉴 알림은 음식 종류를 묶어서 표시한다.
- 새끼·중간·성체 성장 기준 0/12/36은 유지한다. 해금 횟수와 성장 단계는 별개다.

## 해금 효과 순서

1. 완료된 행동을 저장하고 새로 열린 기능만 판정한다.
2. 메뉴를 갱신한다. 실제 소품은 기존 순차 낙하·접근·이용 흐름으로 전달한다.
3. 작은 알림에 열린 생활 이름과 원인이 된 행동을 표시한다. 성장·선물 메뉴로 안내한다.
4. 알림은 5초 노출, 다음 알림까지 최소 7초. 동물을 들거나 떨어지는 중, 어지러운 중, 메뉴/오브젝트 드래그 중에는 새 알림을 미룬다.
5. 알림은 클릭을 가로채지 않으며 약한 기쁨 반응만 예약한다. 행동 도중 억지로 반응을 끼워 넣지 않는다.
6. 동물을 바꾸면 이전 동물의 대기 알림과 표시 중 알림을 지운다.
