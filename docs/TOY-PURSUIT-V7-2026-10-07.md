# 물건별 놀이와 생쥐 추적

- 생쥐 장난감: 접근 → 킁킁 확인 → 장난감이 약 72px 이동 → 동물이 각 종의 기존 걷기 프레임으로 추적 → 멈춰서 다시 확인. 두 차례 반복 후 행복한 표정으로 완료한다.
- 실뜨개 공: 접근하여 톡 건드리는 듯한 킁킁 동작 → 공이 약 54px 굴러감 → 동물이 따라가서 확인. 공의 회전 각도는 이동 거리/반지름으로 계산하고 중심을 기준으로 회전한다. 두 차례 반복 후 완료한다.
- 자명종의 짧은 떨림과 놀람·관찰, 기존 도토리 장난감의 상호작용은 유지한다.
- 물건은 2.8초 구간에 부드럽게 가속·감속한다. 움직이는 동안 추적 목적지를 갱신하며 매 프레임 `visit()`을 다시 호출하지 않는다. 따라서 걷기 주기와 이동 속도를 매번 초기화하지 않는다.
- 기존 16종 걷기/킁킁/표정 프레임을 사용한 게임 동작 연출이다. 이번 작업에서 새 동물 이미지 프레임을 생성한 것은 아니다.
- 좁은 공간에서 다른 물건과 충돌할 경로가 있으면 반대 방향을 시도하고, 양쪽 모두 막히면 이동 대신 확인 후 마친다. 동물 잡기, 장난감 끌기, 다른 행동 시작, 종 변경 또는 제거 시 추적을 중단한다.
- 놀이 후 장난감의 최종 배치 위치를 저장한다. 완료에 `home_play` 교감을 한 번 기록한다. 하늘 낙하·해금·중복 방지와 가구별 색상·질감 선택은 유지한다.
- `tests/toy_play_test.gd`: 16종 × 생쥐/공 2종의 실제 추적·장난감 이동·완료 제한·프레임 간 위치 급변·잡기 취소 검사 통과. 소스와 로컬 설치본에서 실행했다.
- 소스 D3D12로 `tests/toy_play_render.gd` 재생 렌더를 기록했다. 60Hz 시뮬레이션에서 0.2초 간격으로 각 물건 60장을 캡처했다. 검수 GIF는 5fps이며 실제 게임 재생 프레임 수를 뜻하지 않는다.
- GIF는 엔진이 렌더한 동물과 장난감 창을 좌표에 맞춰 합성한 검수 자료이며 OS 화면 녹화가 아니다: `builds/toy-pursuit-review/toy_mouse.gif`, `toy_ball.gif`.
- 로컬 0.30.3 설치본 OpenGL 추적 검사와 하늘 도착·앞쪽 접근 회귀 검사 통과. `DesktopFriends.pck`에 반영했고 GitHub 배포 파일은 이번 작업에서 갱신하지 않았다.
