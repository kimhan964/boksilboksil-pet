# 집 안 가구와 전신 행동 업데이트 — 2026-10-05

## 적용 범위

기존 가구 4종을 유지하고 6종을 추가해 총 10종으로 확장했다. 16종 동물의 새끼/성체를 별도 기준 그림에서 생성했다. 종마다 몸통·귀·꼬리·부리·날개·발굽과 기존 액세서리를 보존하는 전신 이미지 방식이다.

| 가구 | 동작 |
| --- | --- |
| 토끼 귀 미니 소파 | 무릎 굽히기 → 발을 앞으로 앉기 → 기대어 쉬기 → 일어나기 |
| 고양이 발 미니 식탁 | 앉아 컵 잡기 → 입으로 올리기 → 마시기 → 내리기. 우클릭으로 물/식사도 선택 |
| 다람쥐 도토리 책장 | 책 꺼내 앉기 → 펼치기 → 페이지 넘기기 → 덮기 |
| 졸린 곰 리넨 램프 | 하품 → 몸을 웅크리기 → 낮잠 → 기지개 |
| **여우 꼬리 독서 의자** | 의자 높이에 앉아 책을 펼치고 페이지 넘기기 |
| **발바닥 리넨 데이베드** | 매트리스 높이로 올라가 옆으로 웅크리고 낮잠 |
| **고양이 거울 화장대** | 거울 앞에서 양쪽 볼과 가슴 단장 |
| **곰 음악 장식장** | 곁에 앉아 좌우로 느리게 리듬 타기 |
| **포근한 발바닥 놀이 러그** | 앉아 털실 밀기 → 잡아당기기 → 품에 안기 |
| **잎새 창가 벤치** | 앉아서 기대고 눈을 감으며 쉬기 |

## 실제 이미지 수와 재생 방식

- 16종 × 2나이 × 7행동 × 6개 핵심 자세 = **1,344개 활성 전신 자세**, 224개 행동 묶음.
- 새로 그린 행동당 6장이다. 60 Hz 게임 업데이트나 타이밍 반복을 60개 고유 원화라고 표현하면 안 된다.
- 기존 60프레임 걷기/토끼 낮은 깡총걸음 자산은 이번 작업에서 변경하지 않았다.
- 쉬기 8초, 차 7.2초, 책 8.4초, 낮잠 10.8초, 단장 6.8초, 음악 7.2초, 놀이 6.4초. 시작과 끝에 앉고 일어나는 자세를 배치한다.
- 프레임마다 몸의 면적에 맞춰 확대/축소하지 않는다. 한 묶음의 카메라 배율을 고정하고 발 기준점을 등록한다. 별도 놀이 시트도 묶음 단위로만 기준 크기를 맞춘다.
- 파츠 변형이나 프레임 간 잔상 합성 없이 완성된 전신 그림을 재생한다.
- 추가 옷(망토/조끼/스웨터)을 착용하면 기존 의상 행동을 유지한다. 새 가구 전용 원화는 기본 복장에 적용된다. 기본 캐릭터의 목도리·리본·가방은 새 원화에도 포함된다.
- 음악 감상은 시각 동작이다. 이번 업데이트에 음악 음원은 추가하지 않았다.

## 파일과 재생 경로

- `assets/home-v2/references/{species}-{age}.png`: 승인된 기존 idle 원화에서 추출한 기준 그림.
- `assets/home-v2/{species}/{baby,adult}.png`: 6열 × 7행 원본 생성 시트.
- 같은 폴더의 `*-prompt.txt`: 실제 생성 요청문. 원본 생성 파일은 Codex 생성 폴더에도 보존.
- `{age}-play.png`: 겹친 털실이 있던 놀이 행을 대체한 3열 × 2행 원본. 고슴도치·다람쥐·고양이 양 나이, 레서판다·코알라 새끼, 총 8개 행을 교체했다.
- `manifest.json`: 이미지 경계, 발 기준점, 공통 카메라 크기, 대체 행 경로.
- `tools/index_home_sheets.py`: 픽셀을 다시 그리거나 변형하지 않는 아틀라스 인덱서. 안전한 프레임 사이 여백이 없으면 오류로 제외한다.
- `scripts/home_animation.gd`: 7개 행동의 자세 순서·시간·이미지 캐시.
- `scripts/furniture_room.gd`: 찾아가기, 필요 수치에 따른 자율 이용, 배치/저장, 식탁 물·음식 연결.
- `scripts/furniture_window.gd`: 드래그, 클릭 이용, 우클릭 메뉴. 빠른 드래그도 눌렀던 이벤트 좌표부터 계산한다.
- `scripts/desktop_pet_view.gd`: 소파/의자/데이베드/벤치 앉는 높이와 시작/종료 높이 보간.
