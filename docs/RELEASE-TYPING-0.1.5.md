# 복슬복슬메이트 0.1.5 · 최적화

Windows 64비트 공개 미리보기. ZIP 전체를 풀고 `TypingFriends.exe`를 실행하세요. 기존 버전을 종료한 후 새 폴더에서 실행하면 저장·해금 내역을 이어갑니다.

## 변경 사항

- 캐릭터는 실행용 512px, 액세서리는 너비 최대 192px로 미리 준비. 최대 게임 표시 크기보다 높은 해상도를 유지하며 원본은 소스 저장소에 보존.
- 최근 2종 펫의 텍스처만 캐시하여 같은 친구 재선택 시 디코딩 반복 방지.
- 설정 미리보기는 게임 텍스처를 공유하고 UI 아이콘도 재사용.
- APM·선물 상태 표시 갱신을 초당 10회로 조절. 입력 수집과 펫·불빛 애니메이션은 기존 60fps 처리 유지.
- 같은 이미지·불빛 스타일의 반복 설정, 효과가 없는 선물 버튼의 무조건 다시 그리기 제거.
- 사용하지 않는 구버전 액세서리와 아이콘 제작 원본을 실행 PCK에서 제외.

## 측정

같은 PC, Godot headless 검사 `tests/performance.gd`, 기존 원본 로딩과 새 배포 PCK 비교. 단일 실행 수치이므로 하드웨어·디스크 캐시에 따라 달라집니다.

| 항목 | 0.1.4 | 0.1.5 |
|---|---:|---:|
| 48장 캐릭터 RGBA + mipmap 합계 | 402,435,456 bytes | 67,108,800 bytes |
| 16종 순차 디코딩 | 939ms | 160ms |
| 같은 펫 12회 로딩 | 659ms | 10ms |
| PCK 데이터 파일 | 약 68.2MiB | 약 22.1MiB |

텍스처 합계는 전체 프로세스 메모리나 동시 상주 메모리를 의미하지 않습니다. FPS·전체 CPU 개선율은 측정하지 않았습니다.

캐릭터·액세서리·기존 저장 형식과 해금 조건을 유지합니다. 렌더 및 크기·설정 입력·저장·장착 검사 통과. 웹사이트의 동물별 구매 권한 검증은 아직 포함되지 않습니다.
