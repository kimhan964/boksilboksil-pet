# 투명 영역 클릭 통과와 가구 앞뒤 순서 수정

## 원인

1. 동물은 깜빡임을 줄이기 위해 화면 전체를 덮는 고정 투명 창에 그려진다. Godot의 Windows `mouse_passthrough` 불리언은 `HTTRANSPARENT`를 사용하므로 다른 프로세스/바탕화면에 대한 입력 통과를 보장하지 않는다. 엔진 이슈: https://github.com/godotengine/godot/issues/120881
2. 가구를 클릭하거나 이동하면 Windows 창 순서가 달라진다. 기존 복구 코드는 창 목록이 같으면 복구를 생략했고, 걷기/방문 중에는 복구를 미뤘다. 그림 자체의 좌표 문제가 아니라 가구 창이 동물 창 위로 올라오는 문제였다.

## 수정

- `scripts/native_mouse.gd`에서 Windows용 네이티브 클릭 통과를 적용. 동물 바깥은 바탕화면/다른 앱으로 입력을 넘기고, 동물 위 및 잡고 있는 동안에는 동물 입력을 받는다.
- 투명 주 창, 공, 들고 있는 음식, 선물 안내, 사용 중인 숨겨진 소품에도 적용.
- 기존 전체 화면 렌더링과 원화/걷기 자산은 유지. 표시 영역을 잘라서 클릭 영역을 만드는 방식은 사용하지 않는다.
- 가구 클릭/드래그 종료/행동 시작에 창 순서 복구를 요청. 창 목록이 같아도 복구하고, 가구로 걸어가는 중에도 다음 프레임에 복구한다.
- Godot가 창 스타일을 재생성하면 네이티브 클릭 통과 플래그를 다시 적용한다.
- 새 의존성은 MIT 라이선스 `Godot-WinMousePassthrough`, 고정 커밋과 DLL 해시는 `addons/windows_mouse_passthrough/PROVENANCE.md`에 기록.
- DLL은 PCK만으로 배포하지 말고 실행 파일 옆 `addons/windows_mouse_passthrough/bin/`도 함께 배포해야 한다. 패키지 도구가 이를 복사한다.
