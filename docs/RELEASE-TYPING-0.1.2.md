# 타자친구 0.1.2 · 설정 버튼 입력 구조 수정

`BoksilTypingFriends-0.1.2-Windows.zip`을 전부 풀고 TypingFriends.exe를 실행하세요. 이전 실행은 종료해 주세요. 저장 데이터는 유지됩니다.

0.1.1에서도 설정 버튼이 눌리지 않는다는 사용자 보고를 반영했습니다.

- 클릭을 통과시키던 1픽셀 기본 창을 제거하고 상단 설정 버튼을 기본 OS 입력 창에 배치했습니다.
- 기본 창은 불투명·포커스 가능·클릭 통과 없음으로 설정합니다.
- 버튼을 누르는 즉시 설정을 엽니다. GUI 버튼 신호 외에도 창 입력에서 설정/선물 버튼 클릭을 처리합니다.
- 이미 설정이 열린 경우 중복으로 화면을 재생성하지 않습니다.
- `-- --settings` 실행 옵션으로 설정을 바로 열 수 있습니다.

기본 창 플래그·버튼 입력·창 배치·드래그·해금 회귀 검사는 통과했습니다. 실제 Windows 마우스 자동 검증은 도구 오류로 미확인입니다. 이전 버전의 엔진 입력 검사가 사용자 환경의 문제를 재현하지 못했으므로 실제 클릭 성공을 검증 완료로 표시하지 않습니다.
