# 전용 소품 그림체와 자동 도착 인수인계 — 2026-10-09

## 현재 반영 범위

게임 소스와 로컬 검수 패키지에 반영했다. GitHub·홈페이지의 공개 0.33.3 다운로드는 이번 변경을 포함하지 않는다. 기존 공개 빌드 및 사용자 저장을 덮어쓰지 않았다.

## 자동 도착 정책

- 기본값은 자동 도착 합계 최대 5개다. 기본 소품과 가구 장난감이 동일한 제한을 공유한다.
- 대상: 도토리 오뚝이, 장난감 바구니, 동물 전용 놀이감, 공, 생쥐, 자명종.
- 집 꾸미기·놀이감 화면의 `하늘에서 소품 받기`에서 끄기(0) 또는 최대 1~5개를 선택한다.
- 추가 소품은 놀이감의 `꺼내기`, 가구는 배치 메뉴로 직접 배치한다. 수동으로 꺼낸 소품은 하늘에서 다시 내려오지 않는다.
- 제한과 이미 자동으로 받은 항목은 저장되므로 재실행·동물 변경으로 자동 도착이 반복되지 않는다.
- 제한은 자동 도착의 누적 개수다. 사용자가 수동 배치한 전체 물건 개수를 제한하지 않는다.
- 기존 배치와 해금 상태를 보존한다. 구형 저장의 배치/도착 기록을 이미 처리한 항목으로 이관한다. 이미 배치된 물건이 5개를 넘어도 삭제하지 않는다.
- 끄기는 이후 자동 도착을 막는다. 이미 낙하 중인 가구는 착지를 마친다.

구현: `scripts/pet_state.gd`, `scripts/main.gd`, `scripts/furniture_arrivals.gd`, `scripts/furniture_room.gd`.

## 동물별 그림체 정리

16종 각각 전용 놀이감(plant), 위안 소품(lamp), 침대(cushion), 집(shelter), 총 64개를 검토·연결했다.

대상: 토끼, 수달, 다람쥐, 고슴도치, 라쿤, 여우, 곰, 부엉이, 고양이, 강아지, 햄스터, 판다, 레서판다, 양, 코알라, 펭귄.

48개를 내장 image_gen으로 다시 생성했다. 기존 따뜻한 그림체의 침대·집 16개는 기존 cozy-props 원본을 재사용했다. 두꺼운 검은 윤곽과 선명한 파랑·빨강을 부드러운 갈색 선, 크림·세이지·더스티 로즈·안개색 물로 맞췄다. 라쿤 물통도 이 범위에 포함된다.

- 게임용: `assets/species-props-v2/{animal}-{kind}.png` 64개
- 생성 프롬프트·참조: `assets/species-props-v2/PROMPTS.json`
- 추출 원본 위치: `assets/species-props-v2/manifest.json`
- 재추출 도구: `tools/prepare_species_prop_art.py`
- 연결: `scripts/decor_art.gd`의 새 개별 텍스처 우선 반환
- 패키징: `tools/build_small_packs.py`; 생성용 atlas는 배포 리소스에서 제외

원본 색을 코드 필터로 보정하지 않았다. 추출은 투명 영역과 독립 실루엣을 처리하며 원본 픽셀 색을 보존한다. 기존 원본 이미지와 상호작용 기준점을 보존한다. 일부 구형 침대·집은 현재 가구 시스템에서 숨겨지는 항목이므로 64개가 일반 플레이에서 동시에 등장한다는 의미는 아니다.
