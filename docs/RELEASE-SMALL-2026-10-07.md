# 복슬복슬펫 0.33.0 · 소형 설치판

## 다운로드

`BoksilboksilPet-0.33.0-Windows-Small.zip`을 받아 새 폴더에 전부 풀고 `DesktopFriends.exe`를 실행하세요. **기본 ZIP 약 183MB**로 이전 약 1.84GB보다 약 90% 작습니다.

토끼와 공통 가구·먹이·UI는 기본 포함됩니다. 다른 동물을 선택하면 해당 종의 동작 팩만 한 번 다운로드합니다. 동물 팩은 종당 약 43–60MB이며, 받은 동물은 인터넷 없이 사용할 수 있습니다. 동물 이용권이 필요한 구성에서는 기존 이용권 확인을 유지합니다.

오프라인 설치: 원하는 `pet-동물.pck`를 받아 EXE 옆 `animal-packs` 폴더에 넣으세요. 모든 동물을 받으면 기본 ZIP과 추가 팩 전체 합계는 약 955MB입니다. 전체 용량을 기본판의 183MB와 구분해 주세요.

## 최적화

- 미사용 과거 동물·걷기·타자 게임 자료 등 557MB를 배포 패키지에서 제외했습니다. 작업 원본은 보존합니다.
- 이미지 1,887장을 무손실 WebP로 저장하고 투명 여백을 줄였습니다. 게임에서는 원래 캔버스를 복원하므로 크기·색·좌표는 유지합니다.
- 토끼 깡총걸음과 다른 15종의 걷기, 새끼·성체 각각 60프레임을 유지합니다.
- 새 수달 표정, 가구 앞 이동, 들기·버둥거림, 가구·장난감 상호작용을 유지합니다.
- 다운로드 진행·재시도·취소, 크기·SHA256 검사, 중단 파일 정리와 오프라인 캐시를 추가했습니다. 실패하면 현재 펫과 저장된 선택을 유지합니다.

## 검증

원본 소스 밖에서 실행한 PCK로 1,887장의 RGBA·캔버스, 16종 두 성장 단계의 행동, 60프레임 걷기, 수달 8표정, 가구 배치 1,344개 경우, 가구 앞 이동·장난감 검사를 통과했습니다. 실제 Windows 게임 화면과 다운로드 별도 창을 확인했고, 가구 앞뒤 순서 40회에서 위반이 없었습니다.

추가 동물 팩과 ZIP의 SHA256은 `SHA256SUMS.txt`에 있습니다. 기존 플레이 저장은 유지됩니다. 개발 미리보기 버전입니다.
