# 곰 성체·여우 새끼 걷기 후속 수정

## 적용 범위

두 동물의 전신 60프레임을 v12 점검판에 반영했다. 전체 16종/새끼·성체/다른 행동의 완료나 최종 자연스러움 승인이 아니다. 토끼 성체 v9와 직전 부엉이 개선본은 유지한다.

## 곰 성체

기존 중간 자세는 들린 발이 뒤로 갔다가 급히 따라오고, 반대 걸음에서 몸이 더 높이 올라갔다. VARCO로 낮은 전신 자세 2장을 생성한 후, builtin 이미지 생성으로 발 위치를 수정했다. 몸·얼굴·색을 유지한 두 전신 후보 사이를 RIFE로 연결해 적절한 중간 지지 자세를 선택했다. 파츠 절단/조립이나 수동 신체 변형은 사용하지 않았다.

최종 계획 `design/walk-v12/bear/adult/low-between-plan.json`, 제작 `low-between-build/`, 자산 `low-between-assets/`. 중간 원화의 출처와 보간 비율은 `low-passing-interpolation.json`. 원래 자산은 `low-runtime-backup/`에 보관한다.

| 확인 항목 | 기존 | 이번 반영본 |
|---|---:|---:|
| 양발 회수 전반 이동 비율 | 88.3% / -14.2% | 45.9% / 62.6% |
| 각 발 최소 4프레임 전진량 | -0.466 / -1.533px | +0.291 / +0.058px |
| 양쪽 passing 원화의 상승량 | 5.5 / 22.5 source px | 6.5 / 8.5 source px |
| 게임 머리 상대 가로 변동 | 1.231px | 0.479px |
| 게임 머리 상대 세로 변동 | 1.441px | 0.814px |
| 게임 윤곽 높이 | 114~118px | 114~116px |
| 실제 이동 속도 | 약 4.67px/s | 약 4.72px/s |

발끝 실루엣 좌표는 발 회전에 따라 달라진다. 위 수치가 발의 해부학적 정확성이나 자연스러움 자체를 증명하지 않는다. 전신 60장·발 확대판에서 발 수/가림/연결을 함께 확인했다. 15~25와 46~57 부근에는 착지 중 발끝의 각도와 폭 변화가 남으며, 가방·팔의 후속 반응도 더 보완할 수 있다.

새 전신 원화의 이마/배 고정 영역도 비교했다. 이마 대표 [237,171,118], 후보 [243,171,109]; 배 대표 [254,238,212], 후보 [253,237,207]. 이전 짙은 주황 후보보다 안정적이나, 모든 위치와 다른 나이/행동의 색 일치를 승인한 것은 아니다. `refinement-fixed-colors.json`에 영역과 결과를 보관한다.

## 여우 새끼

기존 보폭/접지 불균형 후보에서 걸음 경로를 줄인 전신 원화를 사용하고 양쪽 passing의 주황색을 builtin 이미지 생성으로 맞췄다. 첫 색 후보는 너무 옅어 제외했다. 최종 `swing-left-palette-exact.png`와 기존 `swing-right-builtin-palette.png`를 연결했다.

최종 계획 `design/walk-v12/fox/baby/exact-palette-plan.json`, 제작 `exact-palette-build/`, 자산 `exact-palette-assets/`. 원래 자산은 `exact-runtime-backup/`에 보관. 성체 자산과 성체 manifest 항목은 유지했다.

| 확인 항목 | 기존 적용본 | 이번 반영본 |
|---|---:|---:|
| 머리 상대 가로 변동 | 2.385px | 1.271px |
| 심한 느림 진단 구간 | 1.06% | 0% |
| 한 주기 보폭 | 약 12.69px | 7.56px |
| 실제 이동 속도 | 약 7.88px/s | 약 4.71~4.73px/s |
| 양발 회수 전반 이동 | 약 51% / 53% | 약 52% / 53% |
| 지지 발 가로 변동 | 약 0.72px 최대 | 약 0.45 / 0.33px |

속도가 달라졌으므로 같은 속도에서 떨림만 줄였다고 설명하지 않는다. 주기 1.6초/60장과 표시 배율은 유지했다. 머리 상대 세로 변동은 0.462→0.748px, 윤곽 높이는 94~95→95~97px로 늘었다. 양쪽 passing의 몸 상승과 꼬리 반응을 추가로 맞춰야 한다. 발 회수와 멈칫함 개선을 반영한 중간 단계다.

이마 고정 영역의 대표색 [253,167,82] 대비 최종 왼쪽 [253,166,76], 오른쪽 [253,170,86]. 배 고정 영역은 대표 [254,254,241], 왼쪽 [254,253,241], 오른쪽 [254,252,239]. 기존 넓은 cream 색 마스크는 밝은 흰색을 제외하여 다른 영역까지 집계하므로, 그 중앙값 하나로 배 색이 변했다고 판정하지 않았다. 전신 시각 비교와 동일한 내부 영역을 함께 사용했다.

## 실제 게임 검수

- 곰 성체 우향 335 + 좌향 335 = **670장**.
- 여우 새끼 우향 335 + 좌향 335 = **670장**. 성체 대조 우향 335 + 좌향 336 = **671장**.
- 합계 **2,011장**, Godot mobile/D3D12 실제 게임의 시작→세 주기→정지.
- 모두 60개 프레임 관측. 빈 화면·경계 잘림·걷기 중 배율 변화 없음.
- 곰 반복/정지 머리 변화 가로 약 0.046px 이하, 세로 약 0.053px 이하. 여우 새끼 가로 약 0.070px 이하, 세로 약 0.007px 이하.
- 전신 각 60장과 발 확대판을 시각 검토하고, 실제 재생의 대표 자세/정지 전환을 좌우 비교했다.
- 적용 후 이동 30건 및 도착/방향 전환 630건 통과.
- 설치 점검판을 다시 실행해 곰 성체/새 걷기 60프레임을 선택하고 걷기 반복을 켰다. 실제 바탕화면에서 전신·발 윤곽과 투명 배경을 확인했다. 실제 게임 캡처 오류 로그 4개는 비어 있다.
- 정상 속도 연속 영상을 끝까지 시청한 검수는 미완료다. 프레임별 시각 비교와 실제 재생의 시간·위치 자료가 이번 판정 근거다.

실제 근거는 각 동물 폴더의 `native-low-right/left`, `native-exact-right/left`. 생성 출처는 `design/walk-v12/bear/low-passing-generation.json`, `bear-fox-refinement-generation.json`. 외부 생성 작업은 모두 종료했고 결과는 프로젝트에 저장했다.
