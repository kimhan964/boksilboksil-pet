# 마우스로 들 때 크기 변화·위치 튐 수정

## 발견과 변경

- 드래그 판정 전 이동량을 판정 순간 모두 적용하여 재현 경로에서 26px 이동했다. 드래그 판정에 필요한 거리만 제외하고 나머지 상대 이동을 적용하도록 변경했다. 빠른 한 번의 이동도 버리지 않는다. 누르기와 쓰다듬기를 구분하는 동안에는 캐릭터가 정지한다.
- 보행용 화면 경계에 잡힌 위치를 강제 제한하여 같은 경로에서 마우스와의 간격이 최대 38px 바뀌었다. 들고 있는 동안에는 그 제한을 적용하지 않는다.
- 작은 문지르기에서 `joy_left`가 켜지면 들기 전 표정/행동 그림이 바뀌었다. 포인터를 잡은 동안은 크기가 맞춰진 대기/들기 그림을 유지하고 쓰다듬기 피드백은 하트로 표시한다.
- 들고 이동하는 동안 작은 투명 창을 반복 이동시키지 않는다. 모니터 전체와 바깥 여백을 담는 고정 투명 창에서 캐릭터만 이동한다. 이 구간의 `Outline.fit` 자동 축소도 제거했다. 창 좌표 결정 후 그림의 좌표를 한 번만 보정한다.
- 빠른 드래그도 놓치지 않도록 이동 이벤트와 버튼을 놓는 시점에도 현재 바탕화면 마우스 좌표를 읽는다. 오래된 창 내부 좌표는 사용하지 않으며 잡기 시간은 프레임 처리에서만 증가한다.
- 놓기·낙하·해롱거림 동안에는 같은 창을 유지하고 끝난 후 작은 창으로 돌아간다. 잡는 중 중복 누르기 이벤트는 현재 잡기를 초기화하지 않는다.

## 검수 기준과 증거

- `tests/pointer_carry_stability_test.gd`: 16종 × 새끼/성체, 11,520개 이동 시점. 들기 전 문지르기, 상하좌우 큰 이동, 3초 이후 버둥거림, 커서 간격, 창/그림 기준점, 표시 배율을 검사한다.
- 수정 전 재현: 시작 이동 26px, 커서 간격 오차 약 38px. 수정 후: 26px 입력 중 판정 거리 24px를 제외한 2px만 이동, 커서 간격 오차 0.001px 미만, 추가 축소 없음.
- `tests/pointer_carry_native_review.gd`: 실제 D3D12 게임 창에서 토끼·수달·곰·코알라 양 나이 총 3,848개 시점 기록. 328장 캡처. 고정 창 크기 2432×1592, 잡고 이동하는 동안 창 위치 한 곳 유지, 배율 1.0, 캐릭터 잘림 0건.
- `pointer-carry-review/after/report.json`: 시간별 커서/발/창 좌표, 배율, 잘림 기록. `after/otter-review.jpg`: 시간순 검수판.
- `before` 캡처는 이전 작은 창 이동 방식을 재현한 비교 자료다. 해당 수달 경로에서는 잡고 있는 구간의 자동 축소가 실제 발생하지 않았다. 자동 축소가 모든 크기 변화의 원인이었다고 해석하면 안 된다.
- 기존 3초 반응/재잡기 검사 3,840개 자세, 놓기 전환 경계 800건도 통과했다.

## 범위와 후속 점검

실제 창 검수는 생산용 입력 처리 함수를 통한 일정한 경로 재생이다. 손으로 자유롭게 움직인 모든 경로를 검수했다는 뜻은 아니다. 현재 장비는 단일 모니터이므로 서로 다른 배율의 다중 모니터는 별도 실기 검수가 필요하다. 들고 있는 동안 넓은 투명 화면을 사용하므로 다중 4K 모니터에서는 메모리와 프레임 시간을 추가 확인한다.

캐릭터 전신 이미지를 새로 생성하거나, 승인된 토끼 깡총걸음·60장 버둥거림을 바꾸는 수정은 아니다. 재발 확인은 제자리 잡기만으로 끝내지 말고 큰 상하좌우 이동과 잡기 직전 작은 문지르기를 포함한다.

설치본 검사 시 확인판이 소품 없는 검사 전용 상태를 일반 게임처럼 초기화하던 오류도 분리했다. `--check-package`에서는 검사기만 실행한다.

## 빠른 실제 마우스 드래그 추가 재현

Windows 입력으로 누름·이동·놓기를 빠르게 보냈을 때, 누름 처리 시의 현재 마우스 위치가 이미 최종 위치여서 이동이 지워지는 문제를 확인했다. 누름은 버튼 이벤트에 저장된 위치, 이후 이동은 현재 바탕화면 좌표를 사용하도록 수정했다. 실제 입력 재검사에서 시작 발 위치 (900,550), 누른 위치 (908,502), 최종 마우스 (1080,400), 최종 발 위치 (1041.035,466.363)으로 이동했으며 `drag=true`가 확인됐다. 드래그 판정 거리 36px를 제외한 이동량과 일치한다. `tests/pointer_interactive_probe.gd`로 재현할 수 있다.
