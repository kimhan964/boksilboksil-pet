# 3초 이상 잡기: 내려달라는 전신 제스처

## 적용 기준

- 왼쪽 버튼을 누른 시점부터 시간을 잰다. 드래그 시작 시 시계를 다시 시작하지 않는다.
- 3초 전에는 차분한 들기 자세, 3초 이상이면 앞발 뻗기·뒷발 교대 차기·내려달라는 표정과 `내려줘~!` 말풍선이 나온다.
- 마우스를 움직이지 않는 긴 누르기도 적용한다. 메뉴 열기·공 잡기는 별개다.
- 놓으면 제스처와 말풍선이 즉시 끝나고 기존 낙하·해롱 동작으로 이어진다. 다시 잡으면 시간은 0초부터 시작한다.
- 한 주기 1.4초, 60개의 전신 이미지. 60fps라는 뜻이 아니다. 렌더링 속도와 무관하게 경과 시간으로 재생한다.

## 그림과 재생

16종 × 새끼·성체, 32세트 / 1,920장. 각 세트는 직접 이미지 생성한 전신 자세 4장과 오프라인 RIFE 연결 프레임으로 만들었다. 새·양의 팔다리는 날개·물갈퀴·발굽을 유지한다.

- 원화·참조·프롬프트: `design/struggle-v1/<species>/`
- 게임 자산: `assets/struggle-v1/<species>/`
- 추출·전신 위치 맞춤·연결 도구: `tools/build_struggle_v1.py`
- 재생 경로: `scripts/struggle_art.gd` → `generated_species_art.gd` → `desktop_pet_view.gd`
- 잡기 시간/상태: `desktop_pet_motion.gd`, `desktop_pet.gd`

전신 이미지 크기는 주기 안에서 고정한다. 발을 접는 프레임을 매번 키우지 않는다. 몸 전체의 작은 흔들림만 상체 기준점 주위에 더한다. 런타임 이미지 겹치기나 해부학적 파츠 회전은 사용하지 않는다. 추가 의상은 기존 의상 표시 경로를 유지하며, 버둥거릴 때 옷 크기를 바꾸지 않는다.

## 재현/후속 작업

`tests/hold_struggle_test.gd`는 실제 Pet의 입력 처리 함수와 표시 코드를 검사한다. `--capture-holds` 확인판은 60Hz 입력 기록을 같은 처리 함수에 재생하고 실제 네이티브 창의 렌더링을 저장한다. OS 마우스를 직접 7초간 누른 수동 검사와는 구별한다. 새끼는 움직이지 않는 누르기, 성체는 위로 들고 멈추기, 6초에 놓기를 사용한다.

후속 수정 때 3초 판정·기존 낙하 조건·걷기 v14를 보존한다. 참고 자산을 VARCO로 다시 생성하지 않는다. 이미지 변경은 직접 이미지 생성 후 전신 원화, 연결부, 게임 화면 순으로 확인한다.
