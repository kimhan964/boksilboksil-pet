# 복슬복슬펫 0.32.0 · 2026-10-07 개발 버전

## 다운로드와 실행

ZIP 전체를 새 폴더에 압축 해제하고 `DesktopFriends.exe`를 실행하세요. `DesktopFriends.pck`와 `addons` 폴더를 함께 유지하세요. 이전 설치 폴더의 파일과 섞지 마세요. 기존 플레이 저장은 유지됩니다.

[Windows ZIP 다운로드](https://github.com/kimhan964/boksilboksil-pet/releases/download/v0.32.0-preview.20261007/BoksilboksilPet-0.32.0-Windows.zip)

## 포함된 최신 수정

- 수달 새끼·성체 감정표현 8개를 새 이미지로 제작. 둥근 몸통과 짧은 발 유지, 실행 중 몸통 폭 보정 제거.
- 토끼 깡총걸음과 나머지 15종의 최신 60프레임 걷기 자료 포함. 구형 걷기 대체 경로 제거.
- 동물은 가구 앞에 표시. 가구 위에 놓으면 착지한 뒤 이동·상호작용.
- 가구 크기를 숫자/슬라이더로 60~160% 조절하고 가구 간 앞뒤 순서와 좌우반전 설정.
- 새 당근 장난감·장난감 바구니 그림. 생쥐·실타래를 클릭해 밀거나 드래그 후 놓아 굴리기.
- 간결한 가구 배치 UI, 가구·놀이감 중심 해금과 생활 상호작용.

## 용량 최적화와 검증

수정 과정에서 남은 이전 PCK 데이터 약 81.7MB를 제거했습니다. 등록된 리소스 4,634개를 모두 보존하고 각 파일의 바이트 해시를 검사했습니다. 이미지 품질과 프레임 수는 줄이지 않았습니다. 실행 패키지는 1,911,699,092바이트에서 1,829,994,772바이트로 정리했습니다. ZIP에 개발용 로그·미리보기·수정 이력 파일을 포함하지 않았습니다.

배포 폴더 자체에서 소스 프로젝트를 참조하지 않고 다음 검사를 통과했습니다: 최신 16종 걷기, 가구 앞 이동, 가구 놓기 1,344건 및 16종 높은 위치 착지, 장난감 이동·감속·반응, 수달 새 표정 8개와 고정 표시 배율.

Windows 64비트용 개발 버전입니다. 간헐적 깜빡임은 완전 해소를 확정하지 않았으며 환경별 추가 확인이 필요합니다. 타자친구는 별도 게임으로 이 ZIP에 포함되지 않습니다.
