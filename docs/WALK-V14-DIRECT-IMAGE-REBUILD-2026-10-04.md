# 직접 이미지 생성으로 다시 만든 걷기 v14

## 요청과 적용 범위

VARCO를 연결하지 않고 내장 이미지 생성으로 걷기 원화를 새로 제작했다. 15종 새끼·성체와 새끼 토끼, 총 31개 새 세트다. 성체 토끼는 사용자가 승인한 v9의 낮은 깡총걸음 그림과 높이 12를 보존했다. 나머지 행동과 추가 의상 원화는 이번 재제작 범위에 포함하지 않는다.

각 새 세트는 **직접 생성한 전신 핵심 자세 4장 + 오프라인 RIFE 연결 프레임으로 구성한 60장**이다. 새끼 부엉이는 검수에서 발견한 발 겹침을 줄이기 위해 전신 중간 자세를 추가해 핵심 자세 5장을 사용한다. 60장을 각각 새로 그린 것으로 기록하지 않는다. 런타임 파츠 분리, 다리 회전, 두 그림을 겹치는 페이드는 사용하지 않는다. 60장은 한 걸음 주기의 그림 수이며, 초당 걸음을 60번 움직인다는 뜻이 아니다.

## 발견하고 수정한 문제

- 토끼 기본 선택이 예전 v5를 참조하고, 다른 종 선택 후 깡총걸음이 비활성화되는 경로를 고쳤다. 일반 게임/점검판 모두 v9를 기본으로 사용한다.
- 반려동물 우클릭 메뉴로 종을 바꿨을 때 점검판 선택 상태도 동기화한다.
- 이전 걷기의 매 프레임 높이 맞춤과 홀수 프레임 너비 보정은 제거했다. 한 나이/동작 전체에 같은 배율과 기준점을 사용한다.
- 새 전신 원화는 귀여운 둥근 몸통, 얼굴, 종별 장식과 새끼/성체 팔레트를 기준으로 제작했다. 잘못된 발 순서의 초기 생성안은 제외했다.
- 발이 지지하는 구간에 맞춰 전신 위치를 정렬했다. 네 발 동물은 앞뒤 발의 높이가 다른 원근을 고려해 별도 측정한다.
- 전체 실루엣 단위로 이미지를 추출해 옆 칸의 꼬리 조각이 섞이는 오류를 수정했다.
- 연결 프레임의 투명 배경 복원식을 수정해 발 주변의 보라색 배경 오염을 줄였다.
- 이동 중 주기 고정, 이동 거리/보폭 연동, 한 주기 완료 후 정지, 고정 크기 투명 창을 유지한다.
- 일반 게임도 검수판과 같은 D3D12 렌더러를 사용한다. 현재 Windows/RTX 3070 환경을 기준으로 검수한다.

- 발 이동량이 큰 것으로 측정된 고양이 양 나이·펭귄 성체는 발 확대 60장을 확인했다. 새끼 부엉이에서는 실제 중간 발 겹침을 찾아 전신 원화를 추가 생성했다.
- 실제 게임 좌우 재생 캡처 결과는 아래 최종 검수에 기록한다.

## 후속 작업에서 지켜야 할 기준

1. 대표 원화의 귀여움, 몸통 비율, 색을 확인한 뒤 행동을 확대한다.
2. 지지 발과 회수 발이 번갈아야 한다. 겹치는 다리 형태가 잘못되면 원화를 다시 생성한다.
3. 프레임별 크기 맞춤, 파츠 변형, 런타임 크로스페이드로 결함을 숨기지 않는다.
4. 그림 수뿐 아니라 실제 게임 크기에서 좌우 이동, 시작/정지, 반복 경계를 확인한다.
5. 세대 전환, 식사·수면·감정표현, 추가 의상도 별도 원화/전환 검수가 필요하다. 걷기 수정만으로 전체 게임 애니메이션 완료 처리하지 않는다.

## 최종 게임 검수

- 16종 × 새끼/성체 × 좌우 방향 = 64회 재생 세트, 최종 **28,912장** 검수.
- 모든 32세트/양 방향에서 60개 걷기 프레임 확인, 빈 화면 0, 창 가장자리 잘림 0, 걷기 배율 변화 0.
- 최종 부엉이 수정 전 기록은 `native-right-initial`에 남긴다. 최종 판단에는 `native-owl-right`, `native-owl-left`의 재검수 결과로 대체한 `native-final/summary.json`을 사용한다.
- 실제 창 스크린샷으로 고슴도치·고양이·판다 등 바탕화면 위 표시도 확인했다. 원본 크기의 실제 게임 연속 캡처와 확대 발 프레임을 함께 검수했다.
- 전신 연결 프레임은 광류 보간을 포함하므로 손으로 그린 60장과 동일하다고 설명하지 않는다. 다른 행동 및 추가 의상 검수 상태는 별도로 유지한다.
