# 걷기 자연스러움 상세 재점검 — 2026-10-04

최신 후속 적용: `design/walk-v12/otter/adult/TOE-REPAIR-REVIEW.md`. 수달 성체는 다섯 자세 시범으로 교체했고 좌우 672장 성체 캡처에서 머리 변동 약 1.01px·윤곽 높이 71~72px를 확인했다. 아래 표의 수달 성체 값은 교체 전 기록이다. 나머지 동물 값은 유지한다. 발끝 작은 잔상과 몸통/발 회수 표현은 계속 수정 중이다.

후속 수달 성체 검수: `design/walk-v12/otter/adult/TRIAL-REVIEW.md`. 새 후보의 양방향 실제 재생을 추가로 검사하여 머리 변동 감소를 확인했지만, 7~11번 발끝 잔상으로 적용을 보류했다. 아래 표는 **현재 설치판의 기존 자산**을 대상으로 한 최초 점검 결과이며, 새 후보 수치를 덮어쓰지 않는다.

## 결론

**새 걷기 10개 모두 최종 자연스러움 승인은 보류한다.** 화면이 비거나 크기가 갑자기 바뀌는 문제는 이번 재생에서 발견하지 못했다. 남은 핵심은 양발 보폭/들림 불균형, 약한 체중 이동, 상체·팔·꼬리가 발걸음을 따라 움직이지 않는 표현이다. 단순히 프레임 수를 늘려 해결할 단계는 아니다.

현재 화면에서 선택된 동물은 여우 성체였다. 그 동작을 포함해 수달·다람쥐·여우 새끼/성체와 너구리·곰·부엉이·펭귄 성체를 같은 조건으로 조사했다. 토끼 승인 v9와 나머지 기존 동작은 이번 10개 검사에 포함하지 않았다. 전체 16종/다른 행동이 통과했다는 뜻이 아니다.

## 직접 확인한 증거와 한계

- 실제 Godot D3D12 게임을 두 번 실행했다. 각 동작은 오른쪽 세 주기→정지, 왼쪽 세 주기→정지를 각각 기록했다. **오른쪽 3,351장 + 왼쪽 3,351장 = 6,702장**.
- 20개 경우 모두 한 주기의 60개 이미지가 관측됐다. 빈 화면·창 경계 잘림 없음, 각 동작의 표시 배율 고정. 좌우 이동 방향은 실제 위치 변화로도 확인했다. 두 실행의 오류 로그는 비어 있다.
- 10개 자산의 전신 600개를 연속 배열로 확인했다. 발 확대, 실제 원래 크기의 좌우 주요 자세 80개, 일부 정지 전후 연속 화면도 직접 비교했다. 추가 발이나 좌우 발의 갑작스러운 교환은 이 자료에서 발견하지 못했다.
- Windows 창 직접 조작 도구는 `foreground window did not report a process id` 오류로 재선택 후에도 실패했다. 따라서 이번 결과는 **게임 자체가 출력한 연속 렌더와 프레임별 확인**이다. 직접 마우스로 플레이하거나 정상 속도 영상을 눈으로 시청한 검수를 완료했다고 주장하지 않는다. 재생용 GIF는 각 방향 폴더에 저장했다.
- 기록 간격 95백분위는 약 16.67ms, 최대 약 30.26ms였다. 이는 캡처 시점의 게임 시간 간격으로, 모니터 실제 표시 지연이나 모든 환경의 프레임 성능을 보증하지 않는다.

## 반복·정지·크기

- 10개 모두 idle 이미지와 걷기 0번 이미지가 동일하다. 걷기→idle 때 다른 체형으로 교체되는 문제는 이번 대상에 없다.
- 정지 직전/직후 머리 위치 변화는 X 최대 약 **0.219px**, Y 최대 약 **0.241px**. 큰 위치 점프는 확인되지 않았다. 이는 다른 행동으로의 전환 검사와 별개다.
- 고정 배율이어도 자세 실루엣은 변한다. 수달 성체의 실제 윤곽 높이는 71~77px였다. ‘배율 고정’을 ‘외형 크기 변화가 전혀 없음’으로 보고하지 않는다.
- 한 주기 60개 이미지/1.6초이므로 평균 이미지 교체는 **37.5장/초**다. 화면 렌더가 약 60회여도 고유 동작 60fps와 같지 않다.
- 좌우는 같은 원화를 뒤집어 재생한다. 왼쪽에서만 생기는 누락/큰 계측 차이는 없었다. **움직이다 방향을 전환하는 연결 동작**은 별도 미검수다.
