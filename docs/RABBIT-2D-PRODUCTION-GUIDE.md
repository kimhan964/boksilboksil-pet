# 토끼 2D 전신 애니메이션 제작 지침

## 사용자 확정 조건

1. 3D 모델을 만들지 않는다.
2. 파츠를 분리·조립·리깅해서 토끼를 움직이지 않는다. 이전 파츠 시도는 폐기한다.
3. 바르코 MCP 이미지 생성/편집으로 **완전한 토끼 전신 프레임**을 만든다.
4. 새끼와 성체는 별도 기준 원화, 별도 행동별 연속 프레임으로 제작한다.
5. 사용량보다 품질·일관성을 우선한다. 부족한 결과는 재생성한다.
6. 실제 게임에 연결하고 새 실행본으로 검수한다.

## 기준 원화와 파일

- 새끼: `design/rabbit-v3/baby/master.png` — 큰 둥근 눈과 머리, 짧고 통통한 몸, 짧은 귀·팔다리.
- 성체: `design/rabbit-v3/adult/master.png` — 새끼와 같은 털색·목 장식, 성체 고유 비율.
- 단계별 행동 원본: `design/rabbit-v3/{baby,adult}/{action}.png`.
- 런타임 프레임과 좌표: `assets/rabbit-v3/`.
- 생성 기록: `design/rabbit-v3/generation.json`. 모델·원화·노드·프롬프트를 보존한다.

같은 단계의 모든 행동은 해당 master를 직접 참조한다. 다른 단계의 원화를 섞거나 첫 결과와 다른 디자인으로 바꾸지 않는다.

## 행동별 제작

대기/눈깜빡임, 걷기, 쓰다듬기, 먹기, 마시기, 잠들기/수면/기상, 들기/착지, 뛰기, 바라보기, 킁킁, 인사, 몸단장, 기지개, 부비기, 장난감 씹기, 앉아 쉬기를 단계별로 구분한다.

기본은 4열×2행의 전신 8프레임 시트다. 각 칸은 토끼 한 마리의 완전한 자세다. 행동 시간과 포즈 수에 맞춰 프레임별 표시 시간을 지정한다. 반복 프레임의 복제만으로 새 자세를 만들었다고 하지 않는다.

## 고정할 요소

- 털·귀 안쪽·볼·초록 목 장식·외곽선 색상, 그림자 단계.
- 머리/몸 비율, 눈 두 개의 크기·간격·높이, 귀 밑동과 길이, 팔다리 수.
- 같은 카메라 시점, 방향, 제작 배율, 공통 캔버스와 원점.
- 모션별 손·입 좌표, 발바닥 접지선, 점프의 실제 상승량.

눈을 감는 자세는 허용하지만 눈 한쪽이 누락되거나 잘못 붙은 결과는 불합격이다. 낮은 포즈를 서 있는 키까지 확대하지 않는다.

## 허용되는 후처리

배경 제거·알파 정리, 프레임 자르기, 공통 캔버스 배치, 시퀀스 전체의 일정한 크기 보정, 팔레트 검수·보정, 원점/입/손 메타데이터 기록. 눈·머리·몸통·귀를 분리해 움직이는 후처리는 하지 않는다.

음식과 장난감은 토끼 신체와 별개의 게임 오브젝트이므로 손 좌표에 합성할 수 있다. 음식 크기를 토끼 배율 계산에 포함하지 않는다.

## 게임 통합과 검수

- 모든 토끼 상태를 새 단계별 전신 에셋으로 연결한다. 예전 토끼 또는 폐기한 파츠 결과가 노출되지 않아야 한다.
- 공통 기준 높이·발 원점으로 표시하고 모션마다 현재 불투명 영역에 맞춰 재확대하지 않는다.
- 독립 포즈 사이 긴 교차 페이드를 사용하지 않는다. 눈과 팔다리 잔상을 만들지 않는다.
- 수면은 진입→수면 반복→기상, 들기는 들기→공중 반복→착지를 각각 재생한다.
- 새끼/중간/성체, 양방향, 같은 경험치에서 전 행동을 연속 재생한다.
- 정지 이미지와 실제 크기 애니메이션을 모두 보고 얼굴·색상·체격·접지·잘림·손과 음식 접점을 확인한다.
- 코드 검사 통과와 시각 품질 확인을 구분해 기록한다. 검사하지 않은 항목을 완료라고 하지 않는다.
