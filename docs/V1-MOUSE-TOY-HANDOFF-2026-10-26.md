# v1 쥐 장난감 이동

## 적용 대상

- 기존 16종 v1: `0.33.0-small-preview/DesktopFriends.exe`와 동봉 PCK.
- 소스: `C:/Users/rlagk/Documents/바탕화면 친구/scripts`.
- v2 및 GitHub 공개 0.33.4는 변경하지 않았다. 이번 수정은 로컬 적용이다.

## 사용과 동작

- 함께하기에서 이미 해금된 리넨 생쥐 놀이감을 꺼내고 클릭하거나 끌어 놓는다.
- 기존 우클릭 이용 및 동물이 자율적으로 찾아오는 경로에서도 작동한다.
- 약 22초 동안 바닥에서 짧게 이동하고, 동물이 따라잡으면 1초간 살핀 뒤 반대 방향으로 움직인다.
- 쥐는 동물 이동량에 종속되지 않는 시간 기반 이동을 사용한다. 한 구간의 펫 목표 위치는 고정해 추적 떨림을 방지한다.
- 구간별 90~114px 이동, 최대 12초 기다림. 화면 경계에서는 안쪽으로 방향을 바꾼다. 바닥 Y 좌표를 유지한다.
- 가구는 배경으로 취급해 가구가 있다는 이유로 모든 이동이 취소되던 상황을 없앴다.
- 펫 들기, 쥐 드래그, 치우기, 다른 행동으로 전환, 동물 변경, 배치 모드에서는 중단한다. 메뉴가 열리면 일시 정지한다.
- 공 장난감은 기존 관성 이동 방식을 유지한다. 기존 쥐 그림, 구매 권한, 해금 조건, 저장 구조를 변경하지 않았다.

## 변경 및 검증

- `scripts/mouse_toy_motion.gd`: 독립 이동·대기·잡기 반응·방향 전환.
- `scripts/toy_play.gd`: 쥐 이벤트를 새 동작으로 연결.
- 16종 × 새끼/성체, 32개 추적·잡기 검사 통과. 동물 이동을 멈춘 상태에서도 쥐가 스스로 이동함을 확인.
- 바닥 고정, 순간이동 방지, 구간 내 목표점 고정, 경계 방향 전환, 클릭/드래그 신호 및 일반 이용 진입, 중단, 공 동작 회귀 검사 통과.
- 로그: `output/v1-mouse-toy/check.log`.
- 설치본 재실행 정상 응답, `installed-error.log` 비어 있음.
- 실제 Windows 화면의 클릭·시각 검수는 Computer Use의 `failed to write kernel assets` 오류로 완료하지 못했다. 초기화 후 재시도도 같은 오류였다.
- 복구용 원본: `output/v1-mouse-toy/toy_play-before.gd`.
- 설치 복구 기록: `DesktopFriends.pck.v1-mouse-motor-20261026-journal.json`.
