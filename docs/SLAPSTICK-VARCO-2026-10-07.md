# 엉뚱한 생활 행동 · VARCO 2D 프레임

## 행동

- 살짝 꽈당: 평상시 산책 중 발을 헛딛고 낮게 엎어진 다음 머쓱하게 일어나 원래 목적지로 계속 걷는다. 2.8초.
- 간질간질 코: 코를 찡긋하고 작은 재채기를 한 뒤 머쓱하게 웃는다. 2.4초.
- 첫 자동 행동은 시작 후 최소 50초, 이후 90~150초 간격. 허기·갈증·피로가 심하면 하지 않는다.
- 식사, 물, 가구 접근·이용, 공을 든 상태, 다른 교감 행동을 끊지 않는다. 마우스 잡기·새 행동 요청으로 취소할 수 있다.
- 토끼는 기존 낮은 깡총걸음을 유지하며 접지 순간에만 꽈당을 시작한다. 나머지 동물도 보행 접지 위상에서 시작한다.
- 우클릭 → 교감하기에서 두 행동을 직접 볼 수 있다. 해당 체형의 검수된 파일이 없으면 기능을 활성화하지 않는다.

## 제작과 적용

VARCO MCP 워크플로 `44a1d43a-43ca-4d63-93ad-a6b85c3b3f94`의 새 노드에서 제작했다. 기존 타자 액세서리 노드는 수정하지 않았다. 기준은 현행 게임의 종별·성장 단계별 대기 이미지다. 원화는 분리된 신체 부품이 아닌 완성된 동물 이미지다.

VARCO 키 포즈에서 로컬 RIFE v4.6으로 중간 프레임을 보간한다. 행동당 재생 프레임은 60장이며 모든 프레임이 독립 생성 원화인 것은 아니다. 시작과 끝은 기존 대기 이미지와 픽셀 단위로 일치시킨다. 전체 동작에 하나의 배율을 쓰고 프레임마다 몸 크기를 재계산하지 않는다. 기존 걷기 파일은 바꾸지 않는다.

- 원본·생성 노드·프롬프트: `design/slapstick-varco-v1/`
- 게임용 아틀라스: `assets/slapstick-varco-v1/<species>/<age>-<action>.png`
- 생성 후 처리: `tools/build_slapstick.py`
- 상태 전환 검사: `tests/slapstick_test.gd`
- 게임 렌더 및 크기 검사: `tests/slapstick_render.gd`
- 새 행동 상태: `silly`. 종별 텍스처 캐시는 다른 동물로 전환할 때 정리한다.

현재는 기본 복장에서 활성화한다. 추가 망토·조끼·스웨터를 착용한 경우 엎어진 자세용 의상 원화가 없으므로 자동 발생과 메뉴 실행을 막는다. 의상이 비정상적으로 얼굴이나 바닥에 걸쳐지는 것을 방지한다. 추가 의상 적용에는 별도 원화와 검수가 필요하다.

## 검증 완료

- 16종 × 2체형 × 2행동 = 64개 아틀라스, 총 3,840개 재생 프레임. 동작당 고유 프레임은 꽈당 53장, 재채기 54장(나머지는 자연스러운 멈춤과 중립 끝점).
- 모든 아틀라스 잘림 0. 기존 중립 이미지와 시작·끝 일치.
- D3D12 게임 렌더에서 32개 체형의 프레임별 배율 고정 검사 통과. `builds/slapstick-review/`에 검수 이미지 저장.
- 새끼 코알라의 넓은 엎드림은 투명 캔버스만 늘려 해결. 몸 배율을 축소하지 않았다.
- 행동 중 순간이동 없음, 산책 목적지 복구, 반복 대기, 식사·물·가구 이용 보호, 마우스 잡기/취소 검사 통과.
- 로컬 0.30.3 설치 PCK 적용. 설치본에서 SLAPSTICK 및 HOME PROGRESSION 검사 통과. GitHub 배포본은 이 작업에서 갱신하지 않았다.
