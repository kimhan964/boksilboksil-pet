# 행동별 표시 크기 보정 — 2026-10-04

## 원인과 변경

걷기·대기, 기존 행동, 표정, 잡기에서 서로 다른 높이/얼굴 너비 기준을 사용했다. 표정 이미지를 기존 대기 샘플에 덮어쓰면 원래 이미지의 보정 정보까지 남았다. 기존의 얼굴 너비 검사만으로는 몸 전체가 커지는 현상을 검출하지 못했다.

`scripts/character_size.gd`에서 종·연령별 기준 대기 이미지의 불투명 면적을 공통 기준으로 사용한다. 투명 여백을 제외한 알파값의 합을 측정하고, 가로·세로를 같은 비율로 보정한다. 잠자는 자세를 서 있는 높이에 맞춰 늘리지 않는다. 기존 걷기와 대기의 카메라·토끼 낮은 깡총걸음은 유지한다.

- 표정·먹기·물 마시기·수면·휴식·그루밍·기지개·잡기·버둥거림·어지러움에 공통 보정 적용.
- 해롱거림/표정 교체 시 행동과 바닥 기준을 명시해 대기 전용 보정을 잘못 상속하지 않도록 수정.
- 행동 중 가로/세로를 서로 다르게 늘리는 보정 제거.
- 잡기 전용 얼굴 너비 보정의 중복 적용 제거. 발 기준·창 위치를 유지하면서 전체 이미지에 적용.
- 측정 결과는 캐시하고 주요 이미지들은 등장 전에 계산.
- 클릭을 유지한 뒤 2초부터 버둥거림, 3초 이상 잡은 뒤 놓으면 낙하하는 조건 유지.

## 검증 근거

- 16종 × 새끼/성체 × 19가지 상태 = 608개 대표 화면을 비교.
- 수정 전 최대 차이: 대기 대비 면적의 제곱근 기준 약 31%. 이 수치는 바운딩박스 높이 차이가 아니다.
- 실제 게임의 Pet 창과 View를 D3D12로 표시하여 608개 화면 캡처. 검수 하네스에서 AI가 요청한 자세를 대기로 되돌리지 않도록, 포즈 비교 중에는 AI를 진행하지 않고 실제 창/렌더러를 사용했다.
- `tests/hold_transition_test.gd`: 놓기 경계 800건 통과.
- `tests/pointer_carry_stability_test.gd`: 11,520개 경로 표본 통과. 커서 오차 약 0.000043px.
- `tests/action_size_review.gd --sweep`: 37,088개 중간 포즈 측정. 보정하는 일반 행동은 면적 기준이 일치했다. 기존 대기 프레임은 최대 2.684%, 걷기는 최대 5.794%의 투영 면적 차이가 남는다.
- 처음 사용한 0.1% 공통 기준에서는 기존 대기/표정 시작·끝의 대기 프레임 49건이 실패했다. 원래 카메라를 보존하는 대기/걷기를 별도 허용 범위(3%/8%)로 명시했다. 이 예외를 크기 차이 0이라고 보고하지 않는다.

## 남아 있는 한계 / 다음 제작 지침

알파 면적은 눈에 보이는 덩어리 크기의 지표이며 해부학적 머리 크기 자체는 아니다. 원본 그림의 얼굴·몸 비율이 다른 문제를 새 그림 없이 모두 없애지는 않는다. 현재 검수는 기본 외형 32종 조합이다. 모든 의상·색 조합의 시각 검수를 완료했다고 간주하지 않는다.

새 행동 제작 시 종·연령의 기준 이미지를 함께 사용하고, 얼굴 너비·몸통 부피·발 접지를 눈으로 비교한다. 전체 높이 또는 얼굴 너비 단독 검사로 완료 처리하지 않는다. 행동별 비교 시트와 실제 재생을 모두 확인한다. 걷기 카메라를 추가 보정하려면 토끼 깡총걸음과 발 접지가 유지되는지 별도로 검수한다.

## 자료

- `action-size-review/before/`: 수정 전 원본 셀, 실제 표시 배율, 비교 시트.
- `action-size-review/final/`: 수정 후 실제 창 캡처 `native-*.png`, 셀/배율, 비교 시트.
- `action-size-review/sweep/sweep.json`: 최초 엄격 기준의 전체 중간 프레임 측정 및 실패 목록.
- `tools/review_action_sizes.py`: 비교용 시트 생성. 게임 원본 이미지는 변경하지 않음.

일반 설치본 및 `전체동물-움직임점검-v12`의 패키지에 반영했다. 점검 폴더 이름은 v12지만 걷기 자산은 v14이며 토끼는 기존 v9 경로를 사용한다.
