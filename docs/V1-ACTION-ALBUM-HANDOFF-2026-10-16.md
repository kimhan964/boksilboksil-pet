## 참고 자료와 적용

참고: `C:/Users/rlagk/Downloads/ChiikawaDesktop-1.5.0-win` 및 사용자가 제시한 행동 분류표.
참고한 부분은 행동을 종류별로 모으고 움직임과 발생 상황을 함께 보여주는 구성이다. 참고 게임의 캐릭터 그림을 가져오지 않았다.

| 참고 구성 | 기존 v1에 적용한 내용 |
| --- | --- |
| 행동 종류별 목록 | 일상 / 교감 / 식사·휴식 / 가구·놀이 / 깜짝 행동 |
| 움직이는 미리보기 | v1의 실제 원본 동물 이미지로 재생, 일시 정지, 방향 전환 |
| 동물별 보기 | 현재 선택한 동물, 새끼·성체 미리보기 |
| 발생 상황 설명 | 쓰다듬기, 들기, 식탁, 소파, 책장 등 실제 행동 진입 조건 |
| 이용 조건 확인 | 실제 교감 수치·가구 해금 조건과 가구 배치 바로가기 |

16개 항목: 대기, 걷기, 둘러보기, 기지개, 쓰다듬기, 들기, 버둥거리기, 먹기, 마시기, 잠, 소파, 독서, 음악, 놀이, 넘어짐, 재채기.

## 사용 방법

동물 우클릭 → 함께하기 또는 생활 기록 → **행동 도감 · 움직임과 만나는 방법**.
동물을 바꾸려면 기존 친구 바꾸기를 이용한다. 도감의 새끼·성체 선택은 미리보기만 바꾼다.
도감은 실제 펫에게 행동을 강제로 시키거나 성장·해금 저장값을 수정하지 않는다.

## 변경 파일

- `scripts/v1_action_album_data.gd`: 행동 분류, 원본 움직임 연결, 해금 조건.
- `scripts/v1_action_album.gd`: 독립된 도감 창과 미리보기.
- `scripts/friend_menu.gd`: 도감 메뉴 연결.
- `scripts/main.gd`: 도감 창의 표시 순서 관리.

설치본과 소스가 기존부터 달랐으므로, 소스의 main/friend_menu를 설치본으로 덮어쓰지 않고 각 버전에 필요한 연결 부분만 추가했다.
이번 작업은 기존 움직임의 도감 연결이다. 새 걷기 프레임 생성, 의상 애니메이션 교체, 욕조 추가 작업은 포함하지 않는다.
