# 가구 좌우 배치와 TV·LP 장식

## 사용법
- 가구 배치 창의 각 가구 아래 `←` / `→`: 24px씩 이동.
- 같은 줄의 `좌우 반전`: 그림 방향을 뒤집고 저장. 배치하지 않은 가구에는 비활성화.
- 가구 우클릭에도 좌우 이동과 반전 메뉴가 있다.
- 바닥 모드에서는 드래그 중에도 높이가 고정된다. 화면 전체 모드에서는 상하 이동도 가능하다.
- 새로 배치하는 가구는 가능한 빈 가로 자리를 찾는다. 가구가 매우 많아 화면에 빈자리가 없다면 직접 정리해야 한다.

## 새 가구와 그림
- 고양이 원목 TV장: `assets/furniture-v3/tv.png`, 최대 158×138px 표시.
- 곰 LP 리스닝 테이블: `assets/furniture-v3/turntable.png`, 최대 132×112px 표시.
- 기존 음악 장식장도 계속 선택 가능하며, 이번 두 가구를 추가해 총 12종이다.
- built-in `image_gen`으로 각각 생성. RGBA 원본을 프로젝트로 복사했고 투명도 0~255를 확인했다. 생성 PNG는 편집하지 않았다.
- 전체 제작 프롬프트: `docs/FURNITURE-V3-PROMPTS.json`.
- TV 옆에서 쉬기는 기존 전신 rest 동작, 새 LP 감상은 기존 music 동작을 재사용한다. 새 동물 프레임이나 실제 방송·음원 재생을 추가한 작업은 아니다.

## 반전 시 정합성
- 그림과 클릭 판정 영역을 함께 반전한다. 이미지 크기는 바꾸지 않는다.
- `art_point()`에서 정규화된 접점도 뒤집는다. 식탁의 음식 위치와 동물의 입 접점, 책장/TV/음악 가구의 접근 방향도 같이 맞춘다.
- 사용 중인 가구를 버튼으로 이동/반전하면 바뀐 위치로 다시 접근한다.
- 기존 `[x,y]` 저장을 읽으며, 반전한 가구만 `[x,y,true]`로 저장한다. 일반판과 점검판 모두 이 형식을 사용한다.

## 검증
- `furniture_placement_test.gd`: 12종 좌우 24px 이동, 드래그 높이 고정/해제, 접점 반전, 동물 방향, 기존 저장 호환, 재시작용 저장/로드 통과.
- `furniture_drop_test.gd`: 16종×새끼/성체×12가구×짧은/긴 들기 = 768건 통과.
- `living_space_test.gd` 통과.
- 실제 D3D12 실행에서 배치 UI, 화살표·반전 입력, TV/LP/소파의 렌더링과 투명 배경을 확인. 오류 로그 없음.
- 두 패키지는 새 PNG 바이트와 26개 주요 코드 파일을 소스와 비교한다.

## 패키징
기존 검증 PCK의 미변경 미술 자산을 재사용하면서 `--overlay-assets=assets/furniture-v3`로 새 그림 폴더를 명시적으로 소스에서 추가한다. 이 폴더는 기반 PCK 탐색에서 제외해 중복 등록을 막는다.

저장 공간 확보를 위해 이 작업자가 만든 오래된 `before-space-mode.pck` 백업 두 개를 제거했다. 현재 실행판과 `before-context-reactions.pck` 등 최근 복구본은 유지한다.

마지막 경계 검사: 새 자동 배치는 화면 양쪽 160px를 비우며, TV/LP가 가장자리에 놓이면 동물이 접근 가능한 반대쪽으로 가서 가구를 바라본다. 12종 배치 테스트에 TV 가장자리 접근 검사를 포함했다.
