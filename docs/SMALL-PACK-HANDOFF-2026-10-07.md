# 복슬복슬펫 소형 패키지 · 2026-10-07

## 적용한 네 단계

1. 현재 게임에서 쓰지 않는 species-v1/v2, 옛 걷기·아기·반응·식당 리소스, 분리된 타자 게임 자료, 제작 원본·import 설명을 **배포 팩에서 제외**했다. 원본 작업 파일은 보존한다. 제외 목록은 빌드 폴더의 `REMOVED-RESOURCES.json`.
2. 활성 PNG 1,887장을 무손실 WebP로 변환한다. WebP가 더 커지면 무손실 PNG를 사용하도록 빌드 도구가 지원한다. 이번 결과는 모두 WebP. 투명도를 포함한 잘라낸 RGBA가 원본과 같은지 변환 직후 비교한다.
3. 알파가 있는 영역 밖의 투명 여백을 저장할 때 제거한다. `assets/image-storage.json`에 원본 크기와 오프셋을 기록하고 `asset_images.gd`에서 원래 캔버스를 복원한다. 프레임 수, 셀 크기, 접지·입·손 좌표, 색·채도·몸통 비율은 바꾸지 않는다. 런타임 메모리는 원래 캔버스를 사용하므로 같은 비율로 줄어드는 것은 아니다.
4. 기본 팩에는 토끼와 공통 가구·먹이·UI만 넣고 다른 15종을 `pet-동물.pck`로 분리한다. 친구 선택 전에 해당 팩을 검증·마운트한다. 새끼·성체와 표정·들기·버둥거림·가구 행동·옷이 같은 종 팩에 포함된다.

## 크기

십진 MB 기준. 최종 ZIP의 정확한 크기와 SHA256은 빌드 폴더에서 확인한다.

| 항목 | 크기 |
| --- | ---: |
| 이전 공개 기본 ZIP | 1,843.7 MB |
| 소형 기본 ZIP | 약 183.5 MB, 약 90% 감소 |
| 새 기본 PCK | 약 151.0 MB |
| 추가 동물 15종 PCK 합계 | 771.4 MB |
| 오프라인 추가 동물 ZIP | 약 767.2 MB |
| 기본 + 전 동물 ZIP 총합 | 약 950.7 MB, 이전보다 약 48% 감소 |
| 미사용 배포 자료 제외 | 557.3 MB, 2,346개 |
| 활성 이미지 형식·여백 최적화 | 1,260.0 → 909.0 MB |
| 이미지 저장 픽셀 수 감소 | 약 14.8% |

동물 팩은 종당 약 43–60 MB. 처음 받은 종을 계속 사용하면 다시 다운로드하지 않는다. 전체 동물을 모두 받았을 때의 용량과 기본 다운로드 용량을 구분한다.

## 사용·설치

- `BoksilboksilPet-0.33.0-Windows-Small.zip`을 새 폴더에 전부 푼 뒤 `DesktopFriends.exe`를 실행한다.
- 인터넷 다운로드를 사용하려면 이 버전의 동물 PCK 15개가 GitHub 릴리스에 먼저 게시되어야 한다. **현재 게시 여부는 별도의 배포 기록을 확인한다. 빌드 성공을 게시 성공으로 보지 않는다.**
- 게시 전 또는 오프라인에서 전체 동물을 쓰려면 `BoksilboksilPet-0.33.0-AnimalPacks-Offline.zip`을 같은 폴더에 푼다. EXE 옆에 `animal-packs/pet-otter.pck`와 다른 동물 파일이 있어야 한다.
- 기본 토끼는 인터넷 없이 사용할 수 있다. 다른 동물은 EXE 옆 팩 → 검증된 사용자 캐시 → 다운로드 순서로 찾는다.
- 캐시: `user://animal-packs/storage-20261007-v1/`. 팩마다 고정된 크기·SHA256을 검사하고 `.part`가 검증되면 최종 이름으로 옮긴다. 손상 파일은 설치하지 않는다.
- 다운로드 중 현재 동물과 선택 저장을 유지한다. 실패 창에서 재시도·취소할 수 있다. 첫 실행에 저장된 동물의 팩이 없으면 해당 다운로드 창을 표시하며, 종료해도 선택을 다른 종으로 덮어쓰지 않는다.
- 친구 이용권 검사는 다운로드 전에 수행하고 완료 후 재확인한다. 다운로드했다고 잠긴 동물 이용권을 지급하지 않는다.
- 게임 저장 경로와 성장·교감·가구 배치는 기존과 같다. 초기화·마이그레이션으로 저장을 지우지 않는다.

## 코드와 재현

- `tools/build_small_packs.py build`: SHA256이 확인된 0.32.0 런타임 스냅샷을 읽고 활성 팩을 재구성한다. 설치 GL 설정·네이티브 모듈을 유지하며 현재 소스 스크립트를 명시적으로 덧씌운다. 스냅샷 위치: `builds/release-20261007/DesktopFriends.pck`.
- `tools/build_small_packs.py package`: 기본과 오프라인 ZIP 생성, 파일별 SHA256 기록, ZIP CRC 검사.
- 원본 PNG는 저장소에 남긴다. 런타임에서 직접 PNG 바이트를 읽던 로더는 `asset_images.gd`를 통해 읽도록 바꾸었다. 소스 프로젝트에는 최적화 인덱스가 없으므로 기존 PNG로 실행된다.
- 소품의 크기·간격 계산에서 옛 `assets/animals/*.res`를 읽던 의존성은 원래 가로세로 비율 16개를 `animal_catalog.gd.PROP_ASPECT`로 추출하여 제거했다. 크기 계산 수치는 같다.
- 현재 전신 행동은 species-v3만 사용하며 구버전으로 돌아가는 경로를 제거했다. 최신 걷기는 토끼 rabbit-frame-pilot-v9, 나머지 walk-v14, 새끼·성체 각 60장이다.
