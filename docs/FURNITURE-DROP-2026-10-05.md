# 동물을 끌어 가구에 놓아 이용하기

사용자 확인: 커서만 올리는 방식이 아니라 **동물을 끌어 가구에 놓는 방식**.

## 동작

- 배치된 가구 10종 모두 지원. 소파/벤치 휴식, 식탁 티타임, 의자/책장 독서, 데이베드/램프 낮잠, 화장대 단장, 음악 장식장 감상, 러그 놀이로 연결.
- 동물을 들고 가구 가까이 가져가면 해당 가구만 따뜻한 색으로 표시한다.
- 발 위치와 실제 잡은 지점 모두 판정한다. 머리/귀 쪽을 잡아도 놓기 가능. 가까운 가구 하나만 선택한다.
- 가구에 놓으면 현재 위치부터 이용 자리까지 이동하고 동작을 시작한다. 놓는 순간 위치를 강제 이동하지 않는다.
- 오래 들었더라도 가구에 내려놓는 경우에는 낙하/해롱을 생략한다. 빈 바닥에 오래 들었다 놓는 기존 낙하는 유지.
- 숨긴 가구, 이동 중인 가구, 메뉴가 열린 가구, 꾸미기/간식 찾기 중에는 잘못 연결하지 않는다.
- 놓는 순간 대상을 다시 검사한다. 앞서 강조했던 가구가 제거됐어도 그 가구로 이동하지 않는다.
- 가구 클릭, 가구 끌어서 배치, 우클릭 메뉴도 유지.

## 파일

- `scripts/furniture_room.gd`: 대상 선택/강조/놓기/이용 성공 반환.
- `scripts/furniture_window.gd`: 원본 그림 픽셀의 색으로 대상 표시. 창 밖 테두리나 잘리는 효과 없음.
- `scripts/main.gd`: 기존 소품 놓기보다 가구 판정 우선.
- `scripts/desktop_pet.gd`: 잡은 위치 좌표와 가구가 놓기를 수락했는지 확인.

## 검증

- `tests/furniture_drop_test.gd`: 16종 × 새끼/성체 × 10가구 × 짧게/길게 들기 = 640건 통과. 실제 `release_pointer`→시그널→가구 판정→이동→`home_use` 경로 검사.
- 빈 바닥 낙하, 숨김/이동 중 가구 제외, 머리 쪽 잡기, 꾸미기 제외도 검사.
- 기존 순차 도구 배달 검사 통과.
- Windows 자동화의 직접 드래그는 클릭 통과 창 선택 검사에서 차단되어 완료하지 못했다. 이를 성공한 수동 입력 검사로 표현하지 않는다.
- 실제 게임에서 동일한 들기/이동/놓기 메서드를 시간에 따라 재생: `OVERLAY_REPLAY_RESULT phase=home_use id=home_sofa accepted=true`. 화면에서 토끼가 소파 앞에 앉은 모습을 확인.
- 패키지 검증 및 설치판 교체 결과는 설치 인수인계서에 기록한다.
