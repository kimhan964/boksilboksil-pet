# 현재 체형 의상 재점검

## 판정

기존 의상은 현재 캐릭터 디자인에 완전히 맞지 않는다. 이번 작업은 원인 점검과 확실한 런타임 회귀 수정이다. **새 의상 그림 제작이나 전체 착용 품질 승인으로 간주하지 않는다.**

### 발견한 원인

1. `smooth_species_art.enabled()`가 옷을 입으면 false였다. 토끼 외 동물은 승인된 60장 걷기 대신 과거 체형의 그림을 사용했다.
2. 기본색만 `outfits-dressed-v2`의 과거 전신 그림을 사용했다. 다른 색상은 겹쳐 입히기 방식이라, 색 선택이 동물의 얼굴·체형·옷 디자인까지 바꿨다.
3. 토끼는 현재 깡총 프레임 위에 과거 긴 체형에 맞춘 옷을 올렸다. 귀·발·꼬리를 포함한 전체 외곽 크기를 매 프레임 기준으로 삼아 옷도 늘고 줄었다.
4. 의상 PNG 자체에 과거 팔·손·몸통 경계가 일부 남아 있다. 새 몸 위에 올리면 이중 팔, 엉뚱한 소매 구멍, 얇은 띠처럼 보이는 케이프가 생긴다. 특히 새로 통통해진 몸과 기존 스카프에 잘 맞지 않는다.
5. 가구 전용 `home_animation`은 의상 착용 시 비활성화되어 기존 휴식 동작으로 대체된다. 전용 착용 그림이 없는 현재 제한으로 남는다.

## 반영한 수정

- 옷/색과 관계없이 현재 동물 그림과 60장 걷기, 토끼 깡총걸음을 유지한다.
- 옛 전신 의상 그림으로 교체하는 경로와 불필요한 예전 의상 프레임 로딩을 제거했다.
- 새 물 마시기 프레임도 의상 때문에 과거 동작으로 돌아가지 않는다.
- 걷기 중 옷의 가로·세로 크기는 한 동작 전체의 중앙값으로 고정한다. 작은 몸통 이동만 따라간다.
- 누워 있을 때는 등 쪽에 옷을 배치하고 얼굴 영역을 가린다. 이는 안전한 겹침 보정이며 눕는 전용 의상 그림을 대신하지 않는다.
- 마스크는 실제 텍스처 크기를 사용하고 그림 영역 밖에서 알파가 반복되지 않도록 했다.
- 자유 생활 미리보기에서 동물 선택 시 의상을 강제로 기본 복장으로 돌리는 코드를 제한했다. 세션 안의 선택을 유지하며 기존 미리보기 저장 범위는 그대로다.

## 검증

- `tests/outfit_current_test.gd`: **10,752개 검사 통과**. 16종·새끼/성체·3종 의상·6색에서 동물 원본/기준 높이 유지, 의상 파일 존재, 60장 재생 경로, 걷기 중 의상 크기 고정.
- `tests/outfit_current_review.gd`: 16종 각각 24칸, 총 384개 비교 화면 생성. 3종 의상의 대기와 일부 걷기, 케이프의 먹기/잠/들기/표정 등을 비교한다. 모든 의상의 모든 행동을 눈으로 검수했다는 뜻은 아니다.
- `design/outfit-current-before/`: 토끼·수달·코알라 수정 전.
- `design/outfit-current-after/`: 16종 현재 렌더링 비교표. 원본 PNG를 새로 생성한 것이 아니라 실제 게임 렌더러로 찍은 점검 이미지다.
- 토끼·수달·코알라의 케이프/조끼/스웨터를 별도 Windows 검수 창에서 재생하고 관찰했다.

## 의상 재제작 기준

1. 토끼 새끼/성체 대표 착용 그림부터 승인한다. 현재 얼굴·통통한 체형·털색·스카프를 기준으로 사용한다.
2. 케이프는 목둘레와 어깨를 덮고 등이 드러나지 않도록, 조끼는 몸통에 맞춰 소매 구멍을 작게, 스웨터는 가슴·배에 맞추되 발/손을 가리지 않게 그린다.
3. 현재 몸을 바꾸는 과거 전신 프레임은 재사용하지 않는다. 의상 이미지에 과거 동물의 팔/털을 섞지 않는다.
4. 걷기·깡총걸음, 팔을 드는 동작, 누운 동작, 가구 이용은 다른 자세다. 서 있는 옷 한 장을 늘려 모든 자세를 통과시키지 않는다.
5. 색상만 바꿀 때 옷 재단·동물 체형·얼굴은 동일해야 한다. 현재 세이지/살구/하늘/라벤더/딸기/크림 선택을 유지한다.
6. 토끼 대표 동작 승인 후 수달·코알라 → 여우·고양이 등 꼬리가 큰 동물 → 둥근 몸/날개형 동물 순으로 확대한다.

**남은 시각적 문제:** 토끼의 공중 자세에서 목 아래에 뜨는 옷, 수달/펭귄의 얇은 띠처럼 보이는 케이프, 옛 팔 윤곽이 남은 조끼. 현재 보정만으로 완성되었다고 판정하지 않는다.
