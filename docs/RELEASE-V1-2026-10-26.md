# 복슬복슬펫 v1 · 0.33.5

ZIP을 새 폴더에 모두 풀고 **DesktopFriends.exe**를 실행하세요. 계정을 연결하면 구매·수령한 동물만 이용할 수 있습니다. 기존 성장·가구 저장은 유지됩니다.

## 쥐 장난감과 함께 놀기
- 해금된 리넨 생쥐 놀이감을 클릭하거나 끌어 놓으면 약 22초 동안 스스로 움직입니다.
- 동물이 따라잡으면 잠깐 살핀 뒤 쥐가 반대 방향으로 달립니다.
- 가구가 있어도 이동이 취소되지 않으며, 화면 끝에서는 안쪽으로 방향을 바꿉니다.
- 동물 들기, 쥐 드래그·치우기, 다른 행동 선택 시 중단하고 메뉴가 열리면 잠시 멈춥니다.
- 기존 공 장난감, 행동 도감, 생활 행동 20초대 설정과 구매 동물 제한을 유지합니다.

검증: 16종·새끼/성체 32개 추적·잡기, 바닥·경계·중단 및 공 회귀 검사와 구매 권한 검사 통과. 실제 Windows 화면의 최종 클릭·시각 검수는 화면 제어 도구 오류로 완료하지 못했습니다. 실제 결제는 수행하지 않았습니다.

기존 16종 v1 업데이트이며 v2와 타자 모드는 포함하지 않습니다. 인터넷 연결이 필요하며, ZIP 다운로드 자체로 동물 이용권이 생기지는 않습니다.
