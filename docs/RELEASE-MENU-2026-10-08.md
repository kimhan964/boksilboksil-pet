# 복슬복슬펫 0.33.1 · 함께하기 정리와 도토리 놀이

## 다운로드 및 실행

[Windows 소형판 다운로드](https://github.com/kimhan964/boksilboksil-pet/releases/download/v0.33.1-preview.20261008/BoksilboksilPet-0.33.1-Windows-Small.zip)

Windows 64비트용 미리보기 버전입니다. ZIP 전체를 새 폴더에 풀고 `DesktopFriends.exe`를 실행해 주세요. EXE 옆의 `DesktopFriends.pck`와 `addons` 폴더가 필요합니다. 이전 게임은 종료한 뒤 새 폴더의 EXE를 실행하세요. 기존 플레이 저장은 유지됩니다.

토끼는 기본 포함하며, 다른 동물은 게임에서 종을 선택할 때 다운로드합니다. 추가 동물 15종의 파일과 검증 해시는 이전 0.33.0과 같고, 기존 공개 다운로드를 그대로 사용합니다. 모든 종의 파일을 ZIP에 넣은 대용량 묶음은 아닙니다. 인터넷이 없는 경우 기존 동물 팩을 새 실행 폴더의 `animal-packs`에 옮겨 사용할 수 있습니다.

## 이번 업데이트

- 함께하기: 놀이감 꺼내기, 마우스 따라오기, 놀이 방법과 해금 안내.
- 집 꾸미기: 가구 선택과 배치, 활동 공간 설정. 놀이감 목록 분리.
- 식탁 준비: 음식 선택. 생활 기록: 성장과 해금 기록.
- 의상과 색상 선택 메뉴를 숨기고 추후 업데이트 안내 표시.
- 포근한 크림·월넛·세이지 색의 새 도토리 오뚝이 이미지. 놀이감 창에서 꺼내기와 치우기.
- 도토리·마우스 산책·러그 놀이는 기본 제공. 실뜨개 공은 교감 4, 생쥐는 교감 10에 열립니다. 놀이 방법, 현재 교감, 남은 조건 표시.
- 마우스 따라오기 버튼을 막던 이전 행동 차단 코드 수정.

## 확인한 내용

실제 설치 PCK에서 메뉴 분류, 버튼 연결, 놀이감 잠금·배치·제거, 마우스 따라오기, 교감 4·10의 해금 경계와 도토리 상호작용을 검사했습니다. 도토리가 흔들리는 181개 각도에서 그림이 고정 창 마스크 안에 있는지 검사했습니다. 네이티브 화면의 메뉴·놀이감 창도 렌더링해 확인했습니다. 사용자 플레이 저장을 초기화하지 않았습니다.

미리보기 버전이며 macOS에서는 실행할 수 없습니다.
