# 복슬복슬메이트 · UI 정리

- 사용자 지정 제품명은 띄어쓰기 없이 **복슬복슬메이트**. 게임 창/설정/튜토리얼/프로젝트 이름/실행 파일 제품 설명/README에 적용.
- 기존 저장 경로와 EXE 파일명은 호환성을 위해 유지한다. 설치 폴더에 새 제품명 실행 바로가기를 추가한다.
- 상단 정보 카드와 입력 불빛 트레이를 기본 180px 폭으로 정렬. APM/활동은 한 줄, 설정/선물은 동일 폭의 둘째 줄.
- 기존 설정 버튼 초기 문구가 최소 너비를 늘려 선물 버튼과 겹치던 문제를 고쳤다. 글씨 확대 시 상단 카드와 버튼 폭도 같이 늘어난다.
- 선물 문구는 항상 ‘선물’. 수령 개수 배지는 상자 그림 오른쪽 위 좌표(29,5)에 고정한다. 글자 위로 배치하지 않는다.
- 크림 카드/로즈 선물/세이지 설정, 작은 아이콘, 구분선, 펫과 가까운 입력 트레이를 사용한다.
- 설정 상단의 빈 공간을 친구 프로필·소장 수·스탬프 카드로 바꾸고, 이동 안내와 크기 컨트롤의 불필요한 행을 줄였다.
- 참고: https://store.steampowered.com/app/3419430/Bongo_Cat/ 및 https://game.kakao.com/games/2oQDJ0O1 . 각 게임의 활동 중심 구성과 카페 분위기를 참고해 자체 UI로 구성했다.
- 검증: 세 가지 크기/130% 글씨에서 버튼 비겹침, 드래그/크기 변화/알림/해금 회귀 검사, 게임 자체 렌더 확인. Windows 실제 클릭 자동화의 기존 도구 제한은 유지된다.
