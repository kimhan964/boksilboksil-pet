# 생활로 여는 가구·놀이감 — 2026-10-09

## 정책

식탁·소파·놀이 러그, 기본 도토리 오뚝이·바구니·동물 전용 놀이감은 기본 제공이다. 식사·물·표정·기본 교감 행동은 잠그지 않는다. 아래 18개 물품은 실제 활동 완료 횟수로 열린다. 교감 점수는 친밀도 표시로 유지하며 해금 조건으로 사용하지 않는다.

모든 동물의 활동을 합산한다. 같은 교감 행동은 8초, 식사·물·가구 이용은 45초 간격의 기존 보상 제한을 적용한다. 해금 횟수는 차감되지 않으며 열린 물품은 영구 보유한다. 사용자 저장을 초기화하지 않는다.

| 활동 | 물품과 필요한 완료 횟수 |
| --- | --- |
| 함께 놀기 | 실뜨개 공 3회, 생쥐 8회, 음악 장식장 15회 |
| 쓰다듬기·토닥이기 | 도토리 책장 5회, 원목 서랍장 15회, 화장대 20회 |
| 식사·물 마시기 | 벽시계 4회, 화분대 8회, 창가 벤치 15회, 수조장 24회 |
| 가구에서 휴식 | 리넨 램프 5회, 자명종 8회, 데이베드 12회, 벽난로 20회, TV장 30회 |
| 가구에서 독서 | 벽 선반 4회, 독서 의자 8회 |
| 음악 감상 | LP 리스닝 테이블 12회 |

놀이에는 기본 러그·도토리·전용 놀이감 등의 활동, 돌봄에는 식탁 식사·물·먹여주기·티타임, 교감에는 쓰다듬기·토닥이기·부비기가 포함된다. 독서는 기본 교감으로 열린 책장에서 시작하며 음악 감상은 놀이로 열린 음악 장식장에서 시작한다. 해금할 물품을 먼저 사용해야 하는 순환 조건은 없다.

해금은 자동 배치와 별개다. 자동 도착은 이전에 구현한 공통 최대 5개 제한을 유지한다. 나머지는 가구 배치·놀이감 메뉴에서 직접 꺼낸다.

## 저장 호환

`home_unlock_rules_version: 1`을 저장한다. 이전 버전 저장에서는 기존 교감 기준으로 이미 열렸던 물품과 배치/보유한 물품을 유지한다. 저장된 활동 횟수는 새 조건에 그대로 합산한다. 새 저장은 활동별 조건만 적용한다.
