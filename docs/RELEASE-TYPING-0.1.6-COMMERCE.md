# 복슬복슬메이트 0.1.6 · 판매용

Windows 64비트용입니다. ZIP 전체를 풀고 TypingFriends.exe를 실행하세요.

1. 홈페이지에서 원하는 동물 이용권을 구매합니다.
2. 주문 화면의 이용권 등록 링크를 열어 사용할 ChatGPT 계정에 등록합니다. 선물할 경우 해당 이용권 링크만 전달하세요.
3. 게임에서 계정 연결을 눌러 같은 계정으로 연결합니다.
4. 구매·등록한 동물만 설정에서 선택할 수 있습니다. 다른 동물은 잠깁니다.

인터넷 연결이 필요합니다. 이용권은 45초마다 갱신하며 확인이 끊기면 최대 60초 후 잠깁니다. 테스트 결제는 실제 이용권을 지급하지 않습니다. 환불된 동물도 잠깁니다.
저장된 꾸미기·보상은 보존됩니다. 기존 전체 동물 미리보기와는 별도 판매용 배포입니다.
