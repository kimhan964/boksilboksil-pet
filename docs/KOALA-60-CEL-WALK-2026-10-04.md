# 코알라 새끼·성체 60프레임 걷기 수정

## 적용 내용

- 기본 복장의 코알라 새끼·성체를 각각 별도 전신 60장으로 교체했다. 각 나이마다 생성 원화 4장과 RIFE 연결 프레임으로 구성했다. 60장을 각각 독립 생성했다는 뜻은 아니다.
- 양발의 접지, 들어 올리기, 앞쪽 회수, 착지를 다시 그렸다. 발 교차와 과도한 다리 연장은 제외했다.
- 한 주기는 양발 두 걸음, **60장 / 2.45초**다. 화면 갱신율 60Hz와 애니메이션 원화 수를 혼동하지 않는다.
- 이동 거리는 그림의 지지 발 이동에서 측정했다. 성체 약 8.76px, 새끼 약 7.25px/주기다. 기존 코알라의 임의 62.48px/주기보다 짧아서 발 그림과 실제 이동이 맞는다.
- 머리·몸의 배율은 고정한다. 정지는 같은 걷기 묶음의 접지 자세를 사용하며, 진행 중인 걸음을 마친 다음 정지/방향 전환한다.
- 일반 게임에서도 코알라 기본 복장에 v13을 활성화했다. v12 확인판은 코알라만 v13을 읽고 다른 동물은 기존 묶음을 유지한다. 의상은 기존 의상 묶음을 사용한다.

## 이후 제작 지침

1. 귀여운 대표 원본에서 시작하고 카메라·색·머리 크기를 유지한다.
2. 양쪽 접지 자세부터 만들고, 지지 발의 뒤쪽 이동량이 양쪽에서 비슷한지 확인한다.
3. 중간 자세는 한 번에 바꿀 부위를 작게 지정해 전신 이미지를 수정한다. 12장 일괄 요청의 잘못된 순서를 그대로 연결하지 않는다.
4. 발을 든 자세에서도 지지 발은 바닥에 남아야 한다. 들린 발은 바닥을 스치지 않고 앞쪽으로 회수돼야 한다.
5. 그린 보폭에 실제 이동 거리를 맞춘 뒤 60장으로 연결한다. 원화 수, 보간 방식, 최종 서로 다른 이미지 수를 따로 기록한다.
6. 전체 전신/발 60장, 원래 게임 크기, 좌우 걷기·정지·왕복, 새끼·성체를 확인한다.

이번 완료 범위는 **코알라 기본 복장의 걷기·접지 정지**다. 나머지 동물과 코알라의 의상 걷기·먹기·물 마시기 등 다른 행동은 전체 진행표의 기존 미완료 항목을 유지한다. 전체 16종 완료로 기록하지 않는다.
