# 복슬복슬펫 0.31.0 · 현재 개발 스냅샷

2026-10-05까지의 작업을 담은 Windows 64비트 미리보기 릴리스입니다.

## 다운로드

- **Windows.zip**: 일반 플레이. 성장·교감·행동별 해금이 저장됩니다. 압축을 모두 풀고 `DesktopFriends.exe` 실행.
- **AllPets-Preview-Windows.zip**: 전체 동물 확인판. 압축을 모두 풀고 `Start-Preview.cmd` 실행. 모든 생활 기능이 열려 있으며 일반판 성장 기록과 분리됩니다.
- 실행 파일, `DesktopFriends.pck`, `addons` 폴더를 같은 위치에 유지하세요. 서로 다른 실행판의 PCK나 이전 백업을 섞지 마세요.

## 포함된 변경

- 16종 새끼·성체 걷기, 토끼 깡총걸음과 이동 주기 조정.
- 마우스 잡기/놓기·2초 후 버둥거림·표정과 상황 반응, 표시 크기·투명 창 깜빡임 관련 보정.
- 가구 12종, TV·턴테이블, 좌우 배치/반전, 동물을 끌어 가구에 놓아 이용하기.
- 기본 바닥 활동과 선택형 화면 전체 활동.
- 함께하기·돌보기·내 공간·성장/선물 UI, 행동 완료에 따른 해금 경로와 순차 알림.
- 의상/색 선택이 과거 동물 그림과 걷기로 되돌리던 오류 수정.

## 현재 제한

- 일부 옷은 예전 체형 기준 그림입니다. 토끼 공중 자세의 뜨는 옷, 얇은 띠처럼 보이는 케이프, 과거 팔 윤곽 등이 남습니다. 의상 전체의 시각적 완성을 보증하는 버전이 아닙니다.
- 의상 착용 시 가구 전용 애니메이션은 기존 휴식 동작으로 대체됩니다.
- TV·턴테이블은 장식과 시각적 상호작용이며 실제 방송·음원 재생은 포함하지 않습니다.
- 이 다운로드는 개발용 일반/미리보기 실행본입니다. MBTI 선물 이용권을 검사하는 전용 배포본은 별도입니다.

## 확인한 항목

- 행동별 해금 847개 검사, 상황 반응 640개 검사 통과.
- 현재 동물과 의상 재생 경로·자산·걷기 중 옷 크기 10,752개 검사 통과.
- 두 PCK의 핵심 스크립트 31개와 관련 자산이 현재 소스와 일치함을 확인.
- 실제 Windows UI와 대표 의상 검수 창을 확인했으며, 남은 시각적 문제는 위 제한에 명시했습니다.
- 각 ZIP에는 소스 커밋 번호와 파일별 SHA-256 목록이 있습니다. 릴리스의 `SHA256SUMS.txt`로 ZIP 자체도 확인할 수 있습니다.
