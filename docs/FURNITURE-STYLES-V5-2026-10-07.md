# 가구별 디자인·색상·마감 선택

- 총 19종 가구. 큰 탁상 자명종을 새로 추가했다(교감 18).
- 자명종은 토끼·고양이·곰의 귀와 벨 형태를 각각 새 이미지로 제작했다. 기본 제공 image_gen 도구를 사용했고 원본은 `assets/furniture-v5/`, 최종 프롬프트는 `docs/FURNITURE-V5-PROMPTS.json`에 보관했다.
- 모든 가구에서 원래 색 / 크림 / 세이지 / 더스티 로즈 / 안개 블루 / 월넛의 6개 색상, 원본 질감 / 원목결 / 리넨결 / 매끈한 무광의 4개 마감을 개별 선택한다.
- 자명종의 동물 디자인 선택은 별도 3종 이미지로 교체한다. 다른 기존 가구의 동물 형태는 기존 디자인을 유지하며 색상·마감을 바꿀 수 있다.
- 마감은 원본 그림 위에 약한 렌더 질감을 적용하는 방식이며 원본의 모든 재질을 물리적으로 교체하는 것은 아니다. 식물·수조의 초록 식물과 파란 유리를 보호한다. 무광은 약한 색상 완화이며 원본 붓결을 지우지는 않는다.
- 집 꾸미기 목록에 선택 메뉴를 추가했다. 미리보기와 실제 가구는 같은 설정을 사용한다. 배치 전에 선택할 수 있으며 배치 후에도 바로 적용된다.
- 별도 저장 항목 `furniture_styles`로 개별 선택을 저장한다. 오래된 저장은 기본값으로 시작하고, 가구를 치워도 스타일은 보존한다. 성장과 교감, 소유, 가구 위치는 기존 구조를 유지한다.
- `tests/furniture_styles_test.gd`: 19종 선택 메뉴와 렌더 파라미터 적용, 자명종 3종 교체, 재배치 유지, 저장/로드 복원 통과. 소스 D3D12와 로컬 설치 OpenGL에서 실행했다.
- `tests/home_progression_test.gd` 소스 통과, 로컬 설치의 `tests/furniture_front_test.gd` 통과. 실제 게임 렌더 검수 이미지: `builds/furniture-style-review/`, 원본 디자인 비교: `builds/alarm-designs.jpg`.
- 로컬 `복슬복슬펫/0.30.3/DesktopFriends.pck`에 적용했다. GitHub 배포 파일은 이번 작업에서 갱신하지 않았다.
