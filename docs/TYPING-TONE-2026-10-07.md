# 타자친구 색감 통일 · 여우 기준

## 기준

여우의 기본 원화는 변경하지 않는다. 다른 동물은 고유한 털색을 유지하면서 진한 중간색을 밝히고 과한 하이라이트와 채도를 줄인다. 갈색·회색 동물을 여우의 주황색으로 치환하지 않는다.

## 구현

- `catalog.gd`의 `TONES`에 16종 고정 보정값: 중간 밝기, 채도, 크림 하이라이트, 온기.
- 수달·고슴도치·너구리·레서판다의 중간 밝기를 올리고, 레서판다의 진한 적갈색 채도를 낮춘다.
- 토끼·양의 넓은 크림 면 하이라이트를 낮춘다. 강아지·햄스터의 밝은 황갈색도 소폭 낮춘다.
- 부엉이의 보랏빛은 차분하게, 코알라·펭귄은 따뜻한 회색으로 소폭 조정한다.
- `tone.gdshader`에서 매 프레임 동일한 보정값 사용. 원본 48개 PNG/알파/동작/위치는 그대로 보존한다.
- 눈·아주 어두운 외곽선은 밝기 마스크로 보호하고, 키보드 영역은 UV 마스크로 보호한다. 원래 색상 스킨은 기본 보정 이후 적용한다.
- 실제 펫과 설정 미리보기에 같은 값을 적용한다.

## 검수

- `tests/tone_review.gd`가 `builds/review/tones-before.png`와 `tones-after.png`를 생성한다. 16종을 같은 크기·배경으로 전후 비교했다.
- 렌더 픽셀 비교: 여우 전체 영역이 이전과 동일, 모든 동물의 키보드 영역이 이전과 동일.
- `tests/check.gd -- --capture`: 16종 실제 위젯 재생에서 색보정 값 적용 및 동작/크기/설정/선물 회귀 검사.
- 원본 이미지를 다시 생성하지 않고 게임 표시 단계에서 적용하여 얼굴과 프레임 일관성을 유지한다.
