# 이동 속도·투명 창·순차 도구 도착 — 2026-10-05

## 적용

- `gait_profile.gd`의 `TRAVEL_RATE=1.5`로 기존 이동 대비 약 1.5배. 16종 새끼/성체의 걷기, 토끼 깡총걸음, 의상/기존 걷기 경로에 적용했다. 이동 거리와 프레임 주기를 함께 바꿔 보폭을 유지한다. 행동 자체의 재생 시간, 잡은 뒤 2초 버둥거림 및 3초 낙하 조건은 별도다.
- 토끼는 승인된 낮은 깡총걸음과 점프 높이를 유지한다. 속도를 높이려고 보폭이나 높이를 늘리지 않는다.
- 캐릭터가 이동할 때 640×384 투명 창을 재배치하던 경로를 제거했다. 모니터 전체와 여백을 포함하는 고정 투명 창 안에서 그림 좌표만 움직인다. 잡기/놓기도 같은 창을 사용한다.
- Windows가 큰 창을 처음 표시할 때 위치를 (0,0)으로 바꾸는 현상을 실제 실행에서 확인했다. 첫 표시 직후 원점을 맞춰 기존의 2초 뒤 재배치가 발생하지 않도록 수정했다. 모니터 구성이 실제로 바뀔 때만 창 크기/원점을 갱신한다.
- 발 접지나 토끼 착지 순간의 속도 0을 정지로 오인해 네이티브 창 스타일을 갱신하지 않도록, 걷기/방문/추적/복귀 행동 전체 동안 갱신을 미룬다.

## 도구와 자율 활동

- 해금된 작은 도구 `acorn → basket → plant`를 하나씩 대기열에 넣는다. 도토리 오뚝이, 장난감 바구니, 식물 소품의 기존 이미지를 사용한다.
- 첫 도착 전 잠시 기다리고, 약 1.25초 낙하 및 작은 착지 반동 후 동물이 정상 보폭으로 접근한다. 현재 도구 방문과 반응이 끝나야 다음 도구가 출발한다.
- 사용자가 소품을 직접 선택하면 그 요청을 우선한다. 대기 중/공중에 있는 소품을 걷기 목적지로 선택하지 않는다.
- 새 소품은 동물 근처의 다른 소품과 겹치지 않는 위치를 우선한다. 사용자가 가까이에 둔 위치는 유지한다. 동물을 소품 위치로 순간이동시키지 않는다.
- 여유가 있으면 소품에 다시 관심을 보이며, 직전에 쓴 것과 다른 소품을 우선한다. 배고픔·목마름·낮은 에너지, 잡기·메뉴·꾸미기 중에는 배송/자율 놀이를 기다린다.
- 소품 가시성 예산, 종별 선물 해금, 구매 동물 제한을 유지한다. 점검판의 전체 해금 상태는 플레이어 저장 데이터를 쓰지 않는 기존 PreviewState에만 해당한다.

## 후속 검수 기준

1. 속도 조정은 공통 TRAVEL_RATE에서 하며 이동 픽셀 수만 따로 올리지 않는다.
2. 걷기·잡기 중 네이티브 창의 위치/크기/그리기 영역을 반복 변경하지 않는다.
3. 깜빡임 제보는 그림 프레임 변화와 Windows 합성 화면 문제를 구분해 캡처한다. 이번 1,080프레임 검사만으로 모든 동물·환경의 깜빡임이 영구히 해결됐다고 단정하지 않는다.
4. 고정 캔버스는 이전 작은 창보다 GPU가 그리는 면적이 크다. 다중 고해상도 모니터에서 성능을 추가 확인할 필요가 있다. 현재 검수 장치는 1920×1080, RTX 3070, D3D12이다.
5. 점검판 `자유 활동 · 도구와 놀기` 또는 `--free-play`로 배송과 자율 행동을 확인한다. `걷기 반복`은 일정 구간 왕복만 검사한다.
