# 복슬복슬메이트 0.1.4

Windows 64비트용 독립 타이핑 펫 게임의 공개 미리보기입니다.

## 다운로드와 실행

`BoksilBoksilMate-0.1.4-Windows.zip`을 다운로드하고 전체 압축을 푼 뒤 `TypingFriends.exe`를 실행하세요. EXE 옆의 PCK와 addons 폴더가 필요합니다. 기존 버전은 종료하고 교체하세요. 저장 위치를 유지하므로 기존 동물 선택·해금·설정은 이어집니다.

## 변경 사항

- 이름을 복슬복슬메이트로 통일하고 전용 실행 아이콘 적용.
- 크림·세이지 UI, 최소 12px 글자 및 글자 크기 조절, 부드러운 크기 조절, 기본 자유 이동.
- 선물 아이콘 위 개수 표시, 버튼 상태별 색상 수정.
- 처음 실행하는 사용자를 위한 도움말, 일일 카페 주문·스탬프·입력 불빛 보상.
- VARCO GPT Image 2.5 Flare로 제작한 입체적이고 코믹한 액세서리 총 14종.
- 신규 미니 헤드폰, 줄무늬 수면모자, 반숙 프라이 핀, 티타임 모자, 버섯 모자와 누적 해금 보상.
- 최소화된 설정 창 복원, 포커스 이탈·설정 열기 시 드래그 해제, 설정 버튼 중복 처리 수정.
- 동물별 색감 보정 및 타이핑 중 고정된 몸 크기 유지.

## 확인 범위

Godot 렌더·입력 주입 검사, 신규 5종 × 16마리 착용 검수, 해금·장착·저장 복원, 배포본 시작 검사를 통과했습니다. 실제 Windows 마우스의 간헐적 클릭 문제를 자동 재현한 것은 아닙니다.

## 판매 연동 상태

이 공개 미리보기에서는 16종 동물을 선택할 수 있습니다. boksilboksil.kr의 동물별 구매·선물 권한 검증은 아직 포함되지 않았으며 판매용 권한 제한 버전과 구분됩니다.
