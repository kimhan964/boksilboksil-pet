# Combo action sprites

Generated with built-in image_gen, transparent PNG. Reference: builds/review/expressions-all.png. Three action key poses per animal (feet, recline, cheer), with runtime motion and crossfade. Original atlases retained; import_actions.gd mechanically extracts and aligns keyboard baseline/width.

Create a production transparent PNG sprite atlas, 3 columns x 4 rows equal cells, 1536x2048 portrait. Reference shows 16 game animals in reading order; use ONLY these four animals in exact ROW order: rabbit, otter, squirrel, hedgehog. Each row SAME animal in 3 clearly different full-body actions: column1 seated leaning back using hind feet to type on keyboard, front paws raised; column2 lying on belly sideways beside keyboard, head turned toward viewer, forepaw reaching keyboard; column3 standing behind keyboard raising BOTH front paws overhead in joyful hooray. EXACT12 isolated sprites, no labels/text/effects/particles/dots/borders. Preserve reference species silhouette, fur palette, cream face, round plump body, brown eyes and scarf color. Soft warm brown outlines, polished cozy game illustration. All cells equal square with transparent gutters; each animal AND keyboard entirely inside its cell with 10% margin. Keyboard same cream/sage frontal perspective in every cell at x12%-88%, y76%-92%, consistent dimensions. Never crop ears/tails. Heads same scale as reference. Different poses must be anatomically clear, cute and readable. Actual alpha background.
