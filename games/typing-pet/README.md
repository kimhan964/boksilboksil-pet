# 복슬복슬 타자친구

데스크톱 펫과 분리된 Windows용 독립 게임입니다. Godot 4.7.2 프로젝트는 이 폴더의 `project.godot`입니다. 상위 데스크톱 게임 프로젝트나 설치 없이 실행됩니다.

## 실행과 사용

배포 ZIP을 전부 풀고 `TypingFriends.exe`를 실행합니다. PCK와 addons 폴더도 함께 있어야 합니다.

- 16종의 친구가 키보드와 마우스 클릭에 반응합니다. 머리·키보드·몸의 크기는 고정되고 완성된 왼손/오른손 그림을 번갈아 사용합니다.
- 동물 위에는 중앙 정렬된 APM·활동 시간, 아래에는 입력 직후 켜졌다 잦아드는 네모 불빛 8개가 있습니다.
- **설정 · 꾸미기**에서 친구, 화면 구석, 직접 위치 이동, 70~150% 크기 슬라이더, 입력 일시정지, 입력 불빛/선물 효과를 자유롭게 조절합니다. 펫 우클릭으로도 열립니다. 동물 또는 상단 APM 영역을 바로 잡아 끌면 설정 영역과 함께 이동합니다.
- 선물이 준비되면 위쪽 리본 상자가 통통 튀고 반짝입니다. 상자 버튼 → 선물 받기 → 상자 열기 순서로 아이템을 확인합니다.
- **선물 · 꾸미기**에서 조건을 채운 선물을 받고 장착합니다. 액세서리와 색상 스킨은 한 개씩 동시에 장착하며 동물별 선택을 저장합니다.
- 저장 위치: `%APPDATA%/BoksilTypingFriends/typing-friends.json`. 데스크톱 펫의 성장·가구·계정 저장 파일에 접근하지 않습니다.
- 누적 해금 진행은 5초마다 저장됩니다. APM·활동 시간 표시는 이번 실행 기준이며, 선물 진행은 여러 실행에 걸쳐 누적됩니다.
- Windows 64비트, D3D12. 한 번에 타자친구 프로세스 한 개만 실행됩니다.

## 작은 선물 기획과 구현

[Bongo Cat 공식 소개](https://store.steampowered.com/app/3419430/)의 입력 활동과 꾸미기 보상 흐름, [개발자 업데이트](https://steamcommunity.com/app/3419430/allnews/)의 영구 마일스톤 수집 구조를 참고했습니다. 설치 폴더의 `app.info`와 Unity 파일 구조도 확인했습니다. Bongo Cat의 이미지·스킨·코드는 가져오지 않았습니다.

우리 게임에서는 입력 횟수 **및** 활동 시간 조건을 모두 채우면 확정 해금합니다. 받기 버튼으로 소장·장착하며 소모나 중복 뽑기가 없습니다. 액세서리는 16종의 고정된 머리 옆 좌표에 부착합니다. 톤 스킨은 명암과 실루엣을 유지하는 은은한 색상 변형이며 새 전신 의상은 아닙니다.

| 선물 | 종류 | 누적 입력 | 누적 활동 |
|---|---|---:|---:|
| 로즈 리본 | 액세서리 | 60회 | 15초 |
| 클로버 핀 | 액세서리 | 300회 | 2분 |
| 데이지 브로치 | 액세서리 | 1,000회 | 5분 |
| 오트 라떼 | 톤 스킨 | 1,500회 | 10분 |
| 작은 별 핀 | 액세서리 | 3,000회 | 15분 |
| 로즈 밀크 | 톤 스킨 | 5,000회 | 30분 |
| 안개 세이지 | 톤 스킨 | 10,000회 | 60분 |

스타일: 크림·세이지 UI, 작고 차분한 핀, 낮은 채도의 색상 스킨. 기존 동물의 얼굴·눈·몸 비율을 유지합니다. 16종 공통 수집, 동물별 장착. 별도 게임으로 분리했으므로 데스크톱 게임 의상/MBTI 이용권과 연동하지 않습니다.

## APM의 정확한 정의

브루드 워용 도구 [APMAlert의 Main.pas](https://github.com/tec27/APMAlert/blob/321411a11ce649d47fd7c3f44b7ef5ed6271375b/Main.pas)에 공개된 수학식을 독립 구현했습니다. 블리자드 게임 내부 집계와 동일하다고 주장하지 않습니다.

```
tau = 57,000 ms (0.95 minutes)
weighted_count *= exp(-delta_ms / tau)
weighted_count += new_actions
factor = max(0.01, 1 - exp(-max(elapsed_ms, 10000) / tau))
APM = floor(weighted_count / (0.95 * factor))
```

원본의 게임 시계/게임 명령을 실제 관측 시간/키보드·클릭 횟수로 치환했습니다. 시작부터 숫자를 표시합니다. 사용자의 요청에 따라 “측정 중” 표시는 제거했으며, 최초 10초의 계산 분모를 10초 기준으로 고정해 초반 폭등을 줄였습니다. 이 시작 구간 안정화는 APMAlert 원식과 다른 우리 게임의 조정입니다. 10초 이후에는 공개 수학식의 분모를 그대로 사용합니다. 5회/초 지속 입력은 약 300 APM이며, 오랜 집계 후 입력 한 번은 약 1~2만 올립니다. 입력을 멈추면 과거 입력의 영향이 지수적으로 줄어듭니다. 이전 3초 × 20 계산은 사용하지 않습니다.

키보드 자동 반복·수식키 단독·마우스 이동·휠·버튼 놓기는 제외합니다. 입력 문자열, 프로그램 이름, 좌표를 수집/저장하지 않습니다. 관측 입력이 30초 없거나 일시정지/연결 끊김이면 활동 시간이 멈춥니다. 읽기만 하는 시간은 사용 시간으로 측정하지 못합니다.

## 개발·검증

```
godot --headless --path games/typing-pet --script tests/check.gd
godot --path games/typing-pet --script tests/check.gd -- --capture
godot --headless --path games/typing-pet --script tests/package.gd
```

검사: APM 계산/감쇠/초기 숫자 안정화/일시정지, 해금 경계/중복 수령 차단/다른 슬롯 장착 차단/저장 복원, 48개 전신 프레임, 16종 핀 접점, 크기·위치 고정, 세 가지 크기의 설정 버튼 입력, 설정/해금/선물 열기 화면 D3D12 렌더, 70%/150% 배율, 이동 도구 잡기/놓기 및 설정 토글.

0.1.1: 설정 영역은 불투명 네이티브 창이며 펫 창과 화면에서 겹치지 않습니다. 펫은 전체 3개 프레임을 포함하는 고정 Windows 영역을 사용하며 클릭 도중 입력 통과 플래그를 바꾸지 않습니다. 표시 영역 밖은 입력 대상에서 제외됩니다. 동물 및 상단 APM 영역을 직접 드래그할 수 있습니다. Windows 실제 마우스 도구가 연결 오류여서 물리적인 OS 클릭 자동화 검증은 완료하지 못했고, Godot 입력 주입으로 버튼→독립 설정 창 열림을 검증했습니다.

`addons/typing_input`의 C# 도우미는 실행 파일 밖에도 배치해야 합니다. 배포는 공식 Godot Windows release template + 자체 PCK + MIT 클릭 통과 확장 DLL을 사용합니다. 테스트는 사용자의 저장 파일을 쓰거나 입력 도우미를 실행하지 않습니다.
