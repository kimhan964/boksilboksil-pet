# VARCO 대표 캐릭터 4종

상태: VARCO3D MCP의 데스크톱팻 워크플로에서 GPT Image 2.5 Flare로 4장 생성 완료. 개별 PNG와 index.html 비교 페이지 저장. 실제 실행 프롬프트와 노드 ID는 varco-run.json 참고.

최우선 스타일: 실제 동물 일러스트가 아닌 강하게 캐릭터화된 카툰 마스코트. 굵고 일정한 외곽선, 선명한 단색 면, 과장된 머리와 짧은 손발, 종별로 기억에 남는 실루엣과 표정. 사실적인 털, 수채화, 복잡한 명암, 기존 게임의 반실사 묘사 제외. 4종에 동일한 스타일 적용.

공통 방향: 첨부 참고 이미지의 단순하고 둥근 실루엣, 큰 얼굴과 작은 몸, 선명한 색 블록, 또렷한 눈과 귀여운 표정. 기존 참고 캐릭터를 복제하지 않고 복슬복슬펫의 동물을 독립적인 마스코트로 디자인. 네 캐릭터의 선 두께와 머리/몸 비율을 통일. 각 이미지에 동물 한 마리만 전신 정면, 팔다리와 귀가 잘리지 않도록 여백. 글자, 상표, 태그, 배경 소품 제외. 결과물은 개별 대표 이미지 4개; 3D 모델 생성은 별도 요청 범위.
