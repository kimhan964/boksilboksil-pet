# 동물별 의상 v3 · 제작 인수인계

## 최신 · 16종 성체 의상 동작 확대

현재는 16종 × 3벌이 별도 실제 게임 검수 실행에 연결되어 있다. 최신 범위·검사 수·미완료 동작은 `motion/REVIEW.md`와 `motion/verified-preview.json`을 기준으로 한다. 토끼 걷기의 앞발 부착 위치를 재제작했고, 나머지 14종도 기존 동물 이동 주기를 유지한 전신 의상 프레임을 추가했다. 아래 토끼·고양이 단계는 이전 기록이다. 공개 구매판 장착 기능은 아직 활성화하지 않았다.

## 최신 구현 · 2026-10-09 의상 동작 연결

- 토끼·고양이 성체 각 3벌을 별도 실제 게임 검수 실행에 연결했다. 현재 범위와 미완료 항목은 `motion/REVIEW.md`를 우선 읽는다.
- 걷기/버둥거림 각 60셀, 들기·놓기 8구간 각 17셀. 원본 위치·배율·시계를 유지하고 마지막 표시 단계에서 전신 의상 셀을 교체한다.
- 실행: `design/wardrobe-v3/motion/launch.gd`. 기본 고양이, 토끼/고양이 및 3벌 선택. 메모리 상태를 사용해 기존 세이브를 변경하지 않는다.
- 공개 게임 장착/배포는 아직 아니다. 다른 14종·새끼·가구·수면·slapstick 의상은 미완료. 아래 최초 제작 기록의 '미적용'은 당시 상태다.

## 최신 비율 기준 · 2026-10-09 짧고 통통한 앞발

- 팔 복원 v2는 팔이 지나치게 길다는 사용자 피드백으로 교체한다. 현재 선택본은 `catalog-plan.json`의 `file`이 유일한 기준이다.
- `varco-short-arms-revision.json`의 `visually_reviewed_short_paws` 출력만 선택한다. 원본과 v2, 중간 수정안은 이력으로 보존한다.
- 팔은 몸 옆에 붙은 작고 둥근 콩 모양. 긴 상완·사람 같은 팔꿈치·가느다란 손목을 넣지 않는다. 팔을 보이게 한다는 이유로 동물의 체형을 늘리지 않는다.
- 고양이는 작은 두 앞발을 가슴 옆에 둔 대표 자세, 강아지와 양은 기존 네 발 자세를 유지한 짧은 앞다리로 정리한다. 대표 자세를 게임 걷기 자세로 그대로 대체하지 않는다.
- 동작 제작에서는 기존 게임의 자세·이동 주기·접지를 보존하며 짧은 앞발의 형태와 움직임을 함께 검수한다. 원화와 애니메이션의 검수 상태는 별도다.

## 이전 수정 이력 · 팔 복원 v2 (비율 교체 대상)

- 사용자 지적 후 앞발만 남고 팔 위쪽이 옷에 덮인 문제를 재검수했다. 고양이·토끼·다람쥐·고슴도치·너구리·여우·강아지·양 8종 24벌을 VARCO로 수정했다.
- v2 당시 수정한 8종은 `*-concepts-arms-v2.png`였다. 최신본은 catalog를 읽으며 파일명을 임의 조합하지 않는다.
- `varco-arms-revision.json`: 수정 노드, 입력, 프롬프트, 출력 URL. 기존 생성 기록은 보존했다.
- `build_gallery.py`는 선택 파일을 읽고 이미지 SHA로 캐시를 갱신한다. `finalize_catalog.py`도 수정본 선택을 유지한다.
- 팔 노출 재검수는 `REVIEW.md` 참조. 정지 원화만 수정 완료. 게임 장착은 아직 미적용이다.
- `motion/varco-jobs.json`: 토끼 성체 세 의상의 전신 동작 키 시트 생성 기록. `tools/bake_wardrobe_motion.py`의 후보 출력은 검수 전 게임에 연결하지 않는다.

## 최초 제작 기록

- 사용자가 토끼 산책 조끼·니트·카페 앞치마 대표안의 방향을 승인했다. 짧은 옷, 작은 액세서리, 파스텔 색감으로 16종 × 3종(48종)을 진행한다.
- `rabbit-concepts.png`는 builtin image_gen으로 생성한 승인 대표안. 이후 사용자가 VARCO MCP 생성으로 변경 요청. 2026-10-09 나머지 15종은 VARCO MCP `EditImage` / `gpt-image-2.5-flare`로 생성 완료. 총 16종 시트 / 48개 의상 대표 원화. 게임 장착/애니메이션은 미적용.
- 동물별 현재 원본 경로·스타일 프롬프트는 `catalog-plan.json`. 토끼 v9, 다른 동물 walk-v14의 현재 모습 기준. 기존 동물 그림과 모션을 바꾸지 말 것.
- 기존 outfits-varco-v1은 오래된 체형용 바운딩박스 피팅이며, outfits-dressed-v2는 구 동물 전신이라 재사용 금지. 새 의상이 걷기/착지/넘어짐/들기/수면/식탁/가구 이용에서 몸을 가리지 않는지 확인 후 장착한다. 현재 slapstick은 outfit_style>0이면 비활성화되므로 제대로 된 의상 동작을 마련한 뒤 함께 검수해야 한다.
- VARCO 서버는 `varco-3d`, https://3d.varco.ai/api/mcp. 기존 워크플로 `192f6fd8-83a5-4fc5-a978-ddce23f18d72`.
- 2026-10-09 `codex mcp login varco-3d` 실행 및 크롬 승인으로 Successfully logged in 확인. 직후에는 캐시된 Token expired 오류가 남았으나 resources/templates 재시도 후 도구가 다시 발견됨. list_workflow_sessions와 catalog/graph 조회 성공. 승인 토끼 스타일과 원래 수달 이미지를 업로드하고 수달3종 대표 시트를 EditImage로 생성 시작. 노드 ID는 varco-jobs.json. 기존 2278개 노드는 수정하지 않으며 새 노드만 실행 scope에 넣음.
- 기존 게임 변경은 별도 보존. 전체 동물 검수용 게임 실행 경로는 `design/local-full-review/launch.gd`이고 구매 배포에 이 진입점을 넣지 않는다. 이번 의상 작업 원격 배포 없음.

## 최종 결과

- `index.html`: 종별 산책복 · 홈웨어 · 카페복 비교 갤러리. 로컬 미리보기 http://127.0.0.1:4198/ (서버 실행 중에 사용).
- `*-concepts.png`: 16종 원본 시트. 토끼는 승인된 기존 생성물, 나머지 15종은 VARCO 생성물.
- `catalog-plan.json`: 종별 원본 참조, 최종 생성 프롬프트, 파일·해상도·진행 상태.
- `varco-jobs-current.json`: 최종 VARCO 노드 ID, 출력 URL, 프롬프트, 생성 상태. `varco-jobs.json`은 최초 수달 요청 당시의 기록이며 최종 현황에는 current 파일을 사용한다.
- `asset-report.json`: 최종 16개 PNG의 SHA-256과 게임 미적용 상태.
- `REVIEW.md`: 시각 검수 내용과 게임 적용 전 필요한 제작 순서.
- 양은 최초 생성 오류 뒤 해당 노드만 재실행하여 정상 이미지 저장. 다른 종은 완료된 결과를 보존. 작업 중 편집기 연결이 잠시 끊겼으나 기존 판다 입력 노드를 재사용해 이어서 생성했다.
- 검수: 전신 잘림, 옷의 위치, 얼굴·털색·체형, 귀·발·꼬리·가시·날개 노출을 시트별 확인했다. 작은 장식의 정확한 형태와 동작 중 피팅은 최종 게임용 프레임 제작에서 추가 검수한다. 지금 원화에는 종이 배경이 있으므로 런타임에 바로 교체하면 안 된다.
