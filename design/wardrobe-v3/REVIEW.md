# 의상 대표 원화 검수

## 범위

사용자가 승인한 토끼의 짧은 산책 조끼 · 포근한 니트 · 카페 앞치마를 다른 동물에 맞게 변형한다. 이 폴더는 대표 원화이며 게임 스프라이트나 장착 가능 의상 팩이 아니다.

## 확인 항목

- 2026-10-09 사용자 재교정: 팔은 짧고 뭉뚝한 작은 앞발이어야 한다. v2처럼 어깨부터 발까지 길게 노출하면 귀여운 비율이 무너진다. '팔이 보임'만으로 검수 통과시키지 않는다.
- 팔 길이와 폭의 비율, 몸 옆에 붙은 둥근 실루엣, 작은 게임 크기에서의 인상을 함께 확인한다. 긴 상완·팔꿈치 표현은 피한다.

- 동물당 세 가지 의상의 얼굴, 체형, 털색을 나란히 비교한다.
- 발과 귀가 잘리지 않고, 동물 고유의 꼬리·가시·날개가 드러나는지 확인한다.
- 옷이 몸통에 붙고, 앞치마 끈과 여밈이 연결되는지 확인한다.
- 파스텔 원단, 작은 장식, 짧은 옷 길이를 공통 기준으로 삼는다.

## 확인한 결과와 한계

### 최신 선택 · 짧고 통통한 앞발

- 고양이: `cat-concepts-short-arms-v4.png`. 긴 앞다리를 작은 둥근 앞발로 줄여 몸 옆에 붙였다. 양 앞발과 두 뒷발을 구분했다.
- 토끼·다람쥐·고슴도치: `*-concepts-short-arms-v3.png`. 팔이 옷 중간쯤에서 끝나는 짧은 타원형 앞발로 변경했다.
- 너구리·여우: `*-concepts-short-arms-v3.png`. 늘어진 팔을 줄이고 몸 쪽으로 둥글게 모았다. 추가 생성 v4는 색상/소매의 부작용 때문에 선택하지 않았다.
- 강아지·양: `*-concepts-short-arms-v3.png`. 네 발 자세와 발의 바닥 접촉은 유지하면서 길고 곧은 앞다리를 짧고 통통하게 낮췄다.
- 총 8종 24벌의 정지 원화 보정. 세 벌마다 두 앞발의 노출과 짧은 실루엣을 확인했다. 이 결과로 애니메이션 적용 완료를 주장하지 않는다.

### 2026-10-09 팔 누락 재검수 · 이전 검수 정정

이전 검수에서는 발이 보인다는 이유로 앞다리 전체가 보이는지 놓쳤다. 아래는 v2 복원 이력이다. 이후 사용자가 팔 길이를 지적해 `short-arms` 수정본으로 다시 교체했다. 최신 선택은 catalog의 `file`을 읽는다.

| 동물 | 발견한 문제 / 조치 | 세 의상 재검수 |
| --- | --- | --- |
| 고양이 | 앞발만 보이던 옷을 줄이고 어깨부터 앞발까지 앞다리 복원 | 양쪽 앞다리 확인 |
| 토끼 | 몸통에 묻힌 팔을 옷 앞으로 복원 | 양쪽 팔 확인 |
| 다람쥐 | 의상에 가려진 팔을 복원 | 양쪽 팔 확인 |
| 고슴도치 | 조끼·니트·앞치마 위로 팔 윤곽 분리 | 양쪽 팔 확인 |
| 너구리 | 어깨·팔꿈치·손의 연결을 복원 | 양쪽 팔 확인 |
| 여우 | 짧은 민소매 옷과 노출된 팔로 변경 | 양쪽 팔 확인 |
| 강아지 | 가려진 앞다리 윗부분과 옷의 경계 보강 | 양쪽 앞다리 확인 |
| 양 | 앞다리 전체 윤곽과 옷의 경계 보강 | 양쪽 앞다리 확인 |

8종 × 3벌 = 24개 의상 수정. 나머지 수달·곰·부엉이·햄스터·판다·레서판다·코알라·펭귄은 세 의상에서 팔/날개가 읽히는 것을 재확인했다. 수정 파일은 `*-concepts-arms-v2.png`, 실제 갤러리 선택 파일은 `catalog-plan.json`의 `file`이다. 종별 체형에 맞는 사지 수를 유지하며 네 발 동물에 별도 팔을 덧붙이지 않았다.

### 애니메이션에서 추가로 지켜야 할 사항

- 기존 `outfit_layer.gd`는 옷을 동물 위에 덮고 실루엣/얼굴만 마스킹하여 팔을 가릴 수 있다. 현재 대표 원화를 해당 레이어에 그대로 넣지 않는다.
- 기존 전신 동작 셀에 옷만 생성 편집한다. 가까운 팔은 옷 앞으로, 먼 팔은 자세에 맞게 노출하며 원래 팔 궤적을 유지한다.
- 걷기·들기·버둥거림에서 양팔이 정상적으로 가려지는 순간과 생성 누락을 구분한다. 중간 보간 프레임의 합쳐진 팔, 추가 팔, 녹아내리는 손도 실패로 처리한다.
- 토끼 성체 3벌의 원본 자세 16개를 의상 편집한 키 시트를 확보했다. 60프레임 가공과 게임 재생 검수는 별도 진행 중이다. 이 대표 이미지 수정 완료를 게임 애니메이션 적용 완료로 해석하면 안 된다.

### 최초 생성 기록

- 수달·다람쥐·고슴도치·너구리·여우: 전신 세 벌 구성이며 꼬리 또는 가시가 드러난다. 고슴도치는 등 전체를 옷으로 덮지 않는다.
- 곰·부엉이·고양이·강아지·햄스터: 세 벌의 몸색과 얼굴이 대체로 유지되고 의상이 화면 밖으로 잘리지 않는다. 부엉이는 날개가 드러나고 강아지는 네 발 체형에 맞춘 옷이다.
- 판다·레서판다·코알라·펭귄: 세 벌의 털색·얼굴 형태가 대체로 유지된다. 판다는 대나무, 레서판다는 단풍잎, 코알라는 유칼립투스, 펭귄은 눈꽃·아이스크림 장식을 사용한다. 코알라의 귀와 펭귄의 날개·발이 드러난다.
- 양: 재시도 결과를 확인했다. 세 벌 모두 귀·꼬리·발굽과 복슬한 털 실루엣이 드러나고, 데이지 장식을 포함한 짧은 옷으로 생성됐다.
- 작은 장식은 프롬프트와 정확히 일치하지 않을 수 있다. 다람쥐의 조끼 장식, 고양이 카페 모자의 장식 등은 최종 게임용 제작 때 종별 모티프로 다시 확인한다.
- 원화에 종이 배경과 바닥 그림자가 포함되어 있다. 바로 게임에 넣을 투명 스프라이트가 아니다.
- 정지 원화의 체형 유지와 동작 중 크기·접지·착용 위치의 일관성은 별도 검사다. 이 작업에서는 후자를 검증했다고 표시하지 않는다.

## 게임 적용 전 제작 순서

1. 이 대표 원화에서 각 의상의 색상·장식·길이를 확정한다.
2. 현재 원본 동물과 같은 크기·기준점으로 성장 단계별 게임용 투명 원화를 만든다.
3. 현재 걷기 주기와 접지 타이밍을 유지하며 동작별 착용 프레임을 제작한다.
4. 걷기, 착지, 넘어짐, 들기, 수면, 가구 이용에서 옷·신체 가림과 크기 변화를 실제 게임 화면으로 검사한다.
5. 이전 의상 좌표를 그대로 재사용하지 않고 새 자산 버전으로 연결한다. `slapstick`의 의상 착용 시 차단 조건도 새 프레임 준비 후 검수한다.
