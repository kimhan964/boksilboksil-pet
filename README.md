## 텃밭과 주방 (2026-10-10)

음식 → 텃밭에서 씨앗 선택/심기/물주기/수확, 우리 주방에서 재료로 요리 제작, 우리 냉장고에서 먹이기. 당근은 처음부터(2분, 씨앗 4도토리), 허브는 수확 2회(4분, 7도토리), 산딸기는 5회(6분, 10도토리), 버섯은 9회(8분, 12도토리). 수확당 재료 3개이며 첫 수확으로 작물별 요리 2개, 총 8개가 해금됩니다. 레벨과 기존 식당 해금으로 텃밭 요리법을 우회할 수 없습니다. 2번 밭은 수확 3회+40도토리, 3번 밭은 8회+80도토리. 물을 1회 주어야 수확 가능하며 경과 시간은 앱 종료 중에도 적용됩니다. 수확물/요리는 시들지 않고 재료·밭·요리법·냉장고가 기존 저장에 함께 저장됩니다. 기존 식당 32종은 유지됩니다. 첫 수확/첫 요리/요리 5접시 목표 추가.

방 상단 집/텃밭 버튼으로 독립 야외 화면 이동. 울타리/창고/산책길 배경, 밭 직접 누르기(심기/물주기/수확), 작물 씨앗 선택, 밭 확장/재료 현황/주방 연결, 현재 펫 동행 표시. 음식 메뉴의 텃밭도 같은 공간으로 이동합니다. 집에서 진행 중인 돌봄이나 꾸미기를 마친 뒤 이동하며, 식사·놀이·가구 사용은 집으로 돌아와 진행합니다. 기존 저장과 성장 시간/해금 조건을 보존합니다.
