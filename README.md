## Windows에서 바로 실행하기

[Windows 실행 파일 다운로드](https://github.com/kimhan964/boksilboksil-pet/releases/download/v0.24.2/BoksilboksilPet-0.24.2-Windows.zip)

ZIP 파일 전체를 압축 해제한 뒤 `DesktopFriends.exe`를 실행하세요. `DesktopFriends.pck`는 실행 파일과 같은 폴더에 있어야 합니다. 바탕화면에는 실행 파일의 바로가기를 만들어 사용하면 됩니다. 현재 테스트 버전으로 모든 해금 요소가 열려 있습니다.

Godot로 만든 바탕화면 반려동물 게임입니다. 프로젝트의 `project.godot`를 Godot 4.7.2에서 열어 실행할 수 있습니다. 소스와 게임 에셋을 포함하며, 생성된 실행 빌드와 Godot 캐시는 저장소에서 제외합니다.

## 0.23.3 새끼 식사 위치 보정

새끼 16종의 먹기·마시기 각 2자세에 손끝 위치를 따로 지정했습니다. 음식이 고정된 몸통 비율에 떠 있던 처리를 바꾸어 올린 손과 내린 손을 따라갑니다. 손끝을 음식 앞에 표시하는 영역도 새끼 전용으로 맞췄습니다. 성체로 전환하면 전용 처리를 해제합니다. 기존 그림과 성장 기록은 유지합니다.

64개 자세를 GPU 렌더링해 모아보기로 확인했으며 음식 영역의 경계 및 성체 전환 검사 오류는 0입니다. 실제 플레이에서 다양한 음식의 조작감 확인은 별도입니다.

## 0.23.2 소품 드래그 표시 수정

물그릇·먹이 그릇·소품을 이동하는 동안 매 프레임 동물 창의 표시 속성을 다시 적용하던 처리를 제거했습니다. 이동 종료 후 한 번만 표시 순서를 정리하며, 집어 든 음식과 간식 찾기 그릇도 드래그 보호 범위에 포함합니다. 그릇 갱신 시 클릭 영역을 원래 크기로 바꿨다가 축소하던 중간 변경을 없앴고, 커서가 멈추면 창 위치를 다시 지정하지 않습니다. 음식의 먹이기 표시도 상태가 바뀔 때만 다시 그립니다.

7종 소품의 여러 화면 좌표와 경계 이동 2,520표본, 이동 중 표시 순서 변경 요청 억제, 음식 추적 검사를 통과했습니다. Windows 화면의 흰색 깜빡임 해소 여부는 실제 드래그 확인이 필요합니다. 성장·친밀도 저장 자료는 변경하지 않았습니다.

## 0.18 함께 키우는 3단계 성장

16종에 새끼 → 중간 → 성체 성장을 추가했습니다. 기존 그림과 모션을 재사용하여 성체 대비 62%·82%·100% 크기로 표시하며, 단계별 새 그림을 생성한 버전은 아닙니다. 어린 동물은 걸음이 느리고 전용 침대·집·그릇도 함께 작아집니다. 돌보기 경험치 12에 중간, 36에 성체가 되며 먹여주기·공놀이·간식 찾기·토닥이기는 +2, 쓰다듬기·수면·휴식·성격 놀이·식사·물 마시기는 +1입니다. 기존 보상 간격을 적용하여 연속 입력을 중복 보상하지 않습니다. 꾸미기는 성장 경험치를 주지 않습니다.

우클릭 → 성장 기록에서 현재 단계와 다음 단계까지 남은 경험치를 확인합니다. 성장 시 알림이 나오고 동물마다 별도로 저장됩니다. 기존 저장의 친밀도·선물·소품 위치는 유지하고 성장 경험치만 0에서 시작합니다. 테스트 전체 해금과 성장은 독립적이며 방치로 퇴행하지 않습니다. 16종 성장 경계값·저장 복원·기존 저장 호환·보상 간격·동물별 독립 저장 검사와 48개 성장 모습 렌더링을 확인했습니다.

## 0.16.2 소품 이미지 분할 개선

새 동물 8종의 침대·집 이미지 분할을 실제 그림 사이의 빈 공간에 맞췄습니다. 강아지집 아래에 다음 줄 텐트의 막대가 떠 보이던 문제, 지붕 윗부분 잘림, 옆 소품의 조각이 섞이는 문제를 수정했습니다. 원본 그림은 유지했습니다.

## 0.16.1 이동 중 흰색 깜빡임 개선

동물 창의 외곽 영역을 프레임마다 재설정하던 처리를 제거했습니다. 투명 창의 모양을 유지하고, 현재·다음 그림의 외곽선으로 마우스 입력 통과 여부만 결정합니다. 귀·꼬리·앞발의 투명 표현을 유지하며 빈 곳의 클릭은 뒤쪽 화면으로 전달합니다. 0.16까지의 소품 상호작용·전체 해금·친밀도 완화·공놀이 변경을 모두 포함합니다.

## 0.16 소품에 데려다 놓기

동물을 잡아 소품 근처로 데려가면 대상 소품에 금빛 반짝임이 나타납니다. 마우스를 놓으면 그 소품으로 짧게 다가가 행동합니다. 가까운 소품 하나를 선택하며 숨기거나 해금하지 않은 소품, 꾸미기·간식 찾기 중에는 작동하지 않습니다.

| 소품 | 놓았을 때 반응 |
| --- | --- |
| 음식 그릇 | 음식을 먹거나 음료 마시기. 배부르면 부드럽게 사양 |
| 물그릇 | 그릇 옆으로 가서 물 마시기 |
| 침대 | 자리를 다듬고 잠들기. 클릭하면 깨어남 |
| 장난감 바구니 | 놀자는 손짓 후 직접 던질 공 꺼내기 |
| 화분 | 고개를 움직여 살펴보기 |
| 조명 | 눈을 감고 편안해하는 반응 |
| 집 | 집 앞에서 안심하고 기뻐하는 반응 |

완료한 상호작용은 기존 보상 간격에 따라 친밀도 +1을 줍니다. 중간에 동물을 다시 잡거나 다른 명령을 내리면 취소됩니다. 기존 생성 프레임과 화면 효과를 활용했습니다. 완료·중단 보상 로직을 검사했으며 직접 드래그하는 플레이 확인은 생략했습니다.

## 0.15.1 동물 표시 순서 개선

소품을 표시·이동·클릭·새로 그리거나 친구를 바꿀 때, 동물 창을 소품 앞쪽으로 배치합니다. 동물보다 앞에는 조작 중인 공·음식과 선물 안내를 표시합니다. 메뉴와 안내창을 열었을 때는 순서 갱신을 기다립니다. 테스트 전체 해금과 완화한 친밀도 조건을 유지합니다.

## 0.15 공 비율·친밀도 개선

공을 원본 가로세로 비율로 표시하여 납작해지는 문제를 수정했습니다.

일반 해금 조건: 음식 1, 물 2, 공놀이 3, 침대 5, 화분 7, 조명 9, 집 12. 이전 집 해금 60에서 12로 낮췄습니다. **현재 테스트 전체 해금은 유지합니다.**

- 공 회수 완료·직접 먹여주기 완료·간식 찾기 성공 후 식사·잠자리 토닥이기 완료: 친밀도 +2
- 쓰다듬기·직접 보낸 침대에서 3초 쉬기·쉼터 휴식 완료·직접 요청한 성격 행동 완료·소품 이동/색상 변경: +1
- 그릇에서 식사 또는 물 마시기 완료: +1

중단한 행동에는 완료 보상이 없으며, 같은 행동 보상은 8초 간격(자동 식사·물은 45초)으로 받을 수 있습니다. 쓰다듬기는 기존 간격을 유지합니다. 좋아하는 음식 첫 발견 +1도 유지합니다. 우클릭의 친밀도와 선물 메뉴에 획득 방법을 표시합니다.

## 테스트 전체 해금

테스트 기간에는 16종 모두 음식·물·공놀이·간식 찾기·꾸미기·침대·전용 집을 즉시 사용할 수 있습니다. 시작할 때 모든 소품을 표시하며 메뉴에도 전체 해금 상태를 표시합니다. 친밀도 수치는 그대로 기록하지만 기능 이용을 제한하지 않습니다. 기존 해금 단계로 돌아가려면 프로젝트의 `testing/unlock_all`을 false로 바꾸어 패키징하면 됩니다.

## 0.14 직접 던지는 공놀이

장난감 해금 후 동물 우클릭 → **공 꺼내기 · 잡아서 던지기**를 선택하세요. 나온 공을 마우스로 잡고 움직이다 놓으면, 놓기 직전 약 0.12초의 이동 방향과 속도로 날아갑니다. 빠르게 움직이면 멀리, 천천히 놓으면 그 자리에 놓입니다. 공은 화면의 활동 영역 경계에서 튕기고 점차 멈춥니다.

공이 멈추면 동물이 쫓아가 가져옵니다. 돌아온 공을 다시 잡아 연속으로 놀 수 있습니다. 공 우클릭은 공을 치우고, 동물 클릭이나 다른 행동 선택도 공놀이를 끝냅니다. 공을 잡는 동안 동물은 기다립니다. 기존 장난감 해금 조건을 유지했습니다.

방향·속도별 도착 위치, 화면 경계, 프레임 속도 차이, 천천히 내려놓기, 회수 후 재사용 검사를 통과했습니다. 직접 마우스로 던지는 감각은 플레이 검증하지 않았습니다.

## 0.13.2 애니메이션 외곽 잘림 개선

프레임을 섞어 재생할 때 현재·다음 그림의 외곽선을 모두 포함하도록 Windows 창 영역을 수정했습니다. 이동·회전·크기 변화에 따라 외곽선도 갱신합니다. 큰 동작은 창 안에 들어오도록 발 위치를 기준으로 맞춥니다. 원본 이미지와 흰 털 색은 변경하지 않았습니다.

## 0.13.1 그릇 가림 개선

밥그릇·물그릇은 동물 크기에 맞춰 폭 30~58픽셀로 줄였습니다. 친구를 바꾸면 그릇 크기도 갱신됩니다. 식사·마시기는 그릇 중앙 대신 옆에서 그릇을 바라보며 진행합니다. 그릇 위 음식도 줄여 얼굴과 앞발 동작이 더 잘 보이도록 했습니다. 코드 구문 확인을 통과했으며 화면에서의 확인은 생략했습니다.

## 잠드는 모습

GPT 이미지 생성으로 8종마다 잠들기·수면 두 장·깨어나기 네 프레임을 추가했습니다. 자동 낮잠에는 잠들기 → 눈을 감고 웅크린 수면 → 기지개/깨어나기 순서가 이어집니다. 수면 두 프레임은 느리게 전환됩니다. 토끼는 귀를 접고, 수달·너구리·여우는 꼬리를 감싸며, 곰은 옆으로 눕고, 부엉이는 날개에 얼굴을 묻습니다.

## 행동 빈도 조정

시작 후 약 1초 안에 행동을 고르며, 행동 사이 대기는 대체로 1~2초로 줄였습니다. 짧은 산책 비중을 높이고, 고유 애니메이션은 10~18초의 대기 간격이 지나면 다음 행동 선택 때 우선 재생합니다. 음식이나 집이 해금되지 않아도 움직입니다. 피곤하지 않을 때는 자동 낮잠과 긴 휴식을 덜 선택하고, 자동 낮잠 시간도 줄였습니다. 사용자가 직접 선택한 쉬기·꾸미기·먹여주기 대기는 유지합니다.
