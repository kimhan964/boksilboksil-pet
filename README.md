## 이전 개발 기록 · 16종 2D 펫 업데이트

- MBTI 홈페이지 선물용 실행본은 `tools/package_commerce.gd`로 따로 만듭니다. 받은 사람이 홈페이지에서 선물을 계정에 등록하고 게임에서 같은 계정을 연결하면, 서버가 확인한 동물만 표시·선택됩니다. 한 마리만 받았다면 ‘친구 바꾸기’ 버튼이 숨겨집니다. 새 이용권이나 환불 결과는 주기적으로 다시 확인하고, 확인이 끊기면 동물을 숨깁니다. 일반 개발 실행본에는 이 제한을 적용하지 않습니다.
- 선물용 실행본을 만들 때 `--site-url=https://your-mbti.rlagksv.chatgpt.site`와 필요하면 `--destination=...`을 지정합니다. `tools/check_gift_access.gd`는 한 마리·여러 마리·이용권 만료에 따른 선택 목록을 검사합니다. 홈페이지의 다운로드 주소가 설정되기 전에는 로컬 실행본만 사용할 수 있습니다.
- 16종의 새끼·성체용 16프레임 전신 애니메이션을 `assets/species-v3`에 적용했습니다. 총 8,192셀 검사에서 빈 프레임·경계 잘림·중복 프레임 관련 실패는 0건입니다.
- 자연 먹이와 작은 연못 음수, 새끼 크기 1.5배, 걷기·점프·말풍선 개선, 종별 의상 선택 기능을 포함합니다. 게임 패키지 검사에서 384개 대표 자세와 576개 의상 이미지의 로딩 실패는 0건입니다.
- 의상이 움직임에 어긋나는 문제를 해결하기 위해 동물과 옷을 한 장에 그린 전신 이미지를 제작 중입니다. 현재 1,536개 행동·성장·의상 시트 중 138개가 준비됐습니다. 완성되지 않은 조합은 이전 의상 레이어가 표시될 수 있습니다. 이 브랜치는 제작 진행본이며 배포판으로 표시하지 않습니다.
- 실행용 이미지와 코드, 생성 프롬프트·검수 기록은 GitHub에 포함합니다. 수백 MB 규모의 `design/` 생성 원본 PNG는 로컬 제작 폴더에 보존하며 Git에는 포함하지 않습니다. 작업 상태는 `design/outfits-dressed-v2/generation-plan.json`, 제작 절차는 `docs/ALL-SPECIES-2D-WORKFLOW-HANDOFF.md`에서 확인할 수 있습니다.

## 0.30.1 · 귀여운 비율 복원과 16프레임 모션

0.30.0 실제 화면 검수에서 확인된 성체의 긴 몸·다리와 걷기 미끄러짐을 수정했습니다.

- 16종 새끼·성체 대표를 다시 고정했습니다. 성체도 큰 머리, 넓고 짧은 몸통, 짧고 굵은 팔다리를 유지하며 새끼와 털색·무늬·목 장식·선·명암 톤을 공유합니다.
- 모든 행동을 4열×4행의 서로 다른 16개 완성 전신 프레임으로 다시 제작했습니다. 범위는 16종×2단계×16행동×16프레임, 총 8,192셀입니다.
- 걷기에 접지·체중 수용·밀기·통과·발 들기·앞으로 뻗기 자세를 넣고, 실제 이동 거리로 프레임 주기를 진행합니다. 완성 프레임 경로에서도 발 기준 상하·좌우 체중 이동이 적용됩니다.
- 행동마다 생성 카메라 거리가 달라도 중립 자세의 출력 높이를 같게 맞추고, 해당 행동 전체에는 하나의 고정 배율만 적용합니다.
- 파츠 분리, 리깅, 3D, 프레임 복제, 긴 교차 페이드는 사용하지 않습니다.
- 대표 원화와 검수 자료는 design/all-species-v3, 런타임 에셋은 assets/species-v3에 있습니다. 전체 검증 결과는 PRODUCTION_CELS=8192 FAILURES=0입니다.
- 배포 경로는 builds/DesktopFriends-0.30.1-release입니다.

## 0.30.0 · 16종 새끼·성체 전신 애니메이션 통일

토끼에 이어 수달, 다람쥐, 고슴도치, 너구리, 여우, 곰, 부엉이, 고양이, 강아지, 햄스터, 판다, 레서판다, 양, 코알라, 펭귄의 새끼·성체 2D 전신 애니메이션을 VARCO에서 다시 제작했습니다.

- 종마다 새끼 대표 원화를 먼저 만들고, 그 원화를 직접 참조해 같은 색·무늬·장식·외곽선 톤의 성체 대표 원화를 만들었습니다.
- 16종 대표 원화의 주요 팔레트 가중 색차는 모두 ΔE 3 이하이며, 종 혼입과 성장 단계별 색상 변경을 제거했습니다.
- 대표 원화 승인 후 대기·걷기·쓰다듬기 시범 모션을 먼저 검수하고 나머지 13행동을 생성했습니다.
- 16종×2단계×16행동×8프레임, 총 4,096개 완성 전신 프레임을 공통 256×256 캔버스와 발 원점에 맞췄습니다.
- 빈 프레임은 인접 프레임 복제로 넘기지 않고 VARCO에서 다시 생성했습니다. 파츠 분리, 리깅, 3D, 긴 교차 페이드는 사용하지 않습니다.
- 런타임 에셋은 assets/rabbit-v3와 assets/species-v2, 대표 원화와 검수 자료는 design/all-species-v2에 있습니다.
- 전체 프레임 검증 결과는 PRODUCTION_CELS=4096 FAILURES=0이며 배포 경로는 builds/DesktopFriends-0.30.0-release입니다.

## 0.29.0 · 토끼 새끼·성체 전신 애니메이션

바르코에서 새끼와 성체의 기준 원화를 각각 고정하고 행동별 2D 전신 이미지를 생성했습니다. 각 단계 16개 행동 시트, 총 256개 원본 포즈입니다. 파츠 조립과 3D는 사용하지 않습니다.

- 공통 캔버스와 원점, 성장 단계별 고정 기본 배율을 적용합니다. 귀를 접거나 누웠을 때 그림 전체 높이에 맞춰 다시 확대하지 않습니다. 행동 경계의 중립 자세는 같은 전신 프레임을 재사용합니다.

- 제작 지침: `docs/RABBIT-2D-PRODUCTION-GUIDE.md`. 생성 이력과 검수 자료: `design/rabbit-v3/`. 런타임 에셋: `assets/rabbit-v3/`.

## 0.28 · 먹이 해금과 식사 개선

## 0.16 소품에 데려다 놓기

동물을 잡아 소품 근처로 데려가면 대상 소품에 금빛 반짝임이 나타납니다. 마우스를 놓으면 그 소품으로 짧게 다가가 행동합니다. 가까운 소품 하나를 선택하며 숨기거나 해금하지 않은 소품, 꾸미기·간식 찾기 중에는 작동하지 않습니다.

| 소품 | 놓았을 때 반응 |
| --- | --- |
| 음식 그릇 | 음식을 먹거나 음료 마시기. 배부르면 부드럽게 사양 |
| 물그릇 | 그릇 옆으로 가서 물 마시기 |
| 침대 | 자리를 다듬고 잠들기. 클릭하면 깨어남 |
| 장난감 바구니 | 놀자는 손짓 후 직접 던질 공 꺼내기 |

| 조명 | 눈을 감고 편안해하는 반응 |
| 집 | 집 앞에서 안심하고 기뻐하는 반응 |

완료한 상호작용은 기존 보상 간격에 따라 친밀도 +1을 줍니다. 중간에 동물을 다시 잡거나 다른 명령을 내리면 취소됩니다. 기존 생성 프레임과 화면 효과를 활용했습니다. 완료·중단 보상 로직을 검사했으며 직접 드래그하는 플레이 확인은 생략했습니다.

## 0.15 공 비율·친밀도 개선

공을 원본 가로세로 비율로 표시하여 납작해지는 문제를 수정했습니다.

일반 해금 조건: 음식 1, 물 2, 공놀이 3, 침대 5, 화분 7, 조명 9, 집 12. 이전 집 해금 60에서 12로 낮췄습니다. **현재 테스트 전체 해금은 유지합니다.**

- 공 회수 완료·직접 먹여주기 완료·간식 찾기 성공 후 식사·잠자리 토닥이기 완료: 친밀도 +2
- 쓰다듬기·직접 보낸 침대에서 3초 쉬기·쉼터 휴식 완료·직접 요청한 성격 행동 완료·소품 이동/색상 변경: +1
- 그릇에서 식사 또는 물 마시기 완료: +1

중단한 행동에는 완료 보상이 없으며, 같은 행동 보상은 8초 간격(자동 식사·물은 45초)으로 받을 수 있습니다. 쓰다듬기는 기존 간격을 유지합니다. 좋아하는 음식 첫 발견 +1도 유지합니다. 우클릭의 친밀도와 선물 메뉴에 획득 방법을 표시합니다.

## 0.14 직접 던지는 공놀이

장난감 해금 후 동물 우클릭 → **공 꺼내기 · 잡아서 던지기**를 선택하세요. 나온 공을 마우스로 잡고 움직이다 놓으면, 놓기 직전 약 0.12초의 이동 방향과 속도로 날아갑니다. 빠르게 움직이면 멀리, 천천히 놓으면 그 자리에 놓입니다. 공은 화면의 활동 영역 경계에서 튕기고 점차 멈춥니다.

공이 멈추면 동물이 쫓아가 가져옵니다. 돌아온 공을 다시 잡아 연속으로 놀 수 있습니다. 공 우클릭은 공을 치우고, 동물 클릭이나 다른 행동 선택도 공놀이를 끝냅니다. 공을 잡는 동안 동물은 기다립니다. 기존 장난감 해금 조건을 유지했습니다.

방향·속도별 도착 위치, 화면 경계, 프레임 속도 차이, 천천히 내려놓기, 회수 후 재사용 검사를 통과했습니다. 직접 마우스로 던지는 감각은 플레이 검증하지 않았습니다.
